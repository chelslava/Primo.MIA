# Файл: Очистка по времени

> **Группа:** MIA → Утилиты  
> **Класс:** `FileCleanupBack`

## Назначение

Удаляет файлы и папки по временному критерию. Поддерживает пробный запуск (`DryRun`), фильтрацию по маске, ограничение количества удалений и накопление списка ошибок без остановки процесса.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Папка` | `string` | Корневая директория для очистки. |
| `Удалять файлы` | `bool` | Включает удаление файлов, подходящих под критерии. |
| `Удалять пустые папки` | `bool` | Удаляет пустые каталоги, в том числе освободившиеся после удаления файлов. |
| `Удалять папки целиком` | `bool` | Удаляет каталоги рекурсивно вместе с содержимым. Используйте осторожно. |
| `Атрибут времени` | `FileTimeAttribute` | `CreationTime`, `LastWriteTime` или `LastAccessTime`. |
| `Режим порога` | `CleanupThresholdMode` | `OlderThanDays`, `BeforeDate` или `Both`. |
| `Старше (дней)` | `int` | Используется в режимах `OlderThanDays` и `Both`. |
| `Пороговая дата` | `DateTime` | Используется в режимах `BeforeDate` и `Both`. |
| `Маска файлов` | `string` | Одна или несколько масок: `*.tmp`, `*.log;*.bak`. |
| `Рекурсивно` | `bool` | Обрабатывать подпапки. |
| `Минимальный размер (байт)` | `long` | Не удалять файлы меньше указанного размера. |
| `Максимум объектов` | `int` | Ограничение числа удалений за один запуск. `0` — без ограничения. |
| `DryRun` | `bool` | Только собирает кандидатов, ничего не удаляя. |
| `Игнорировать ошибки` | `bool` | Если `true`, ошибки копятся в выходном списке и очистка продолжается. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Количество удалённых` | `int` | В `DryRun` показывает число кандидатов на удаление. |
| `Список путей` | `List<string>` | Удалённые объекты или кандидаты в режиме `DryRun`. |
| `Освобождено байт` | `long` | Суммарный размер удалённого содержимого. |
| `Ошибки` | `List<string>` | Список ошибок в формате `путь: сообщение`. |

## Режимы порога

| Режим | Поведение |
|---|---|
| `OlderThanDays` | Удаляет объекты старше `N` дней от текущего момента. |
| `BeforeDate` | Удаляет объекты с датой раньше указанной даты. |
| `Both` | Удаляет только если выполнены оба условия одновременно. |

## Пример

```text
Папка: "C:\Temp"
Удалять файлы: true
Удалять пустые папки: true
Удалять папки целиком: false
Атрибут времени: LastWriteTime
Режим порога: OlderThanDays
Старше (дней): 30
Маска файлов: "*.tmp;*.log"
Рекурсивно: true
DryRun: true
```

## Примечания

- Для первого запуска рекомендуется включать `DryRun`, чтобы проверить список кандидатов.
- Если одновременно включены `Удалять файлы` и `Удалять пустые папки`, сначала удаляются файлы, затем пустые каталоги.
- `Удалять папки целиком` — необратимая операция, особенно в сочетании с `Рекурсивно`.
