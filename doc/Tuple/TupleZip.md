# TupleZip — Кортеж: Zip списков

Активность для объединения двух или трёх `List<string>` в список кортежей попарно по индексу в процессах Primo RPA.  
Обратная операция — **«Кортеж: Unzip списков»**.

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список A (Item1)** | `List<string>` | Всегда | Первый список — значения становятся `Item1` каждого кортежа |
| **Список B (Item2)** | `List<string>` | Всегда | Второй список — значения становятся `Item2` каждого кортежа |

### Опционально

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Тип кортежа** | `TupleKind` | Нет | `ClassicTuple` (по умолчанию) или `ValueTuple`. Определяет тип создаваемых кортежей |


| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список C (Item3)** | `List<string>` | Нет | Третий список. Если задан — создаются `Tuple<string,string,string>`. Если не задан — `Tuple<string,string>` |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Список кортежей** | `Object` | `List<Tuple<string,string>>` или `List<Tuple<string,string,string>>` в зависимости от наличия Списка C |
| **Количество** | `Int32` | Число кортежей = длина наименьшего из входных списков |
| **Арность кортежей** | `Int32` | `2` если Список C не задан, `3` если задан |

---

## Примеры использования

### Zip двух списков — пары «имя–значение»

Настройки активности:
```
Список A: ["Иванов", "Петров", "Сидоров"]
Список B: ["42", "37", "55"]
```

Результат → `Список кортежей`:
```
[("Иванов", "42"), ("Петров", "37"), ("Сидоров", "55")]
```
`Количество` = `3`, `Арность` = `2`

---

### Zip трёх списков — тройки «имя–отдел–статус»

Настройки активности:
```
Список A: ["Иванов", "Петров"]
Список B: ["ИТ", "Бухгалтерия"]
Список C: ["Активен", "В отпуске"]
```

Результат → `Список кортежей`:
```
[("Иванов", "ИТ", "Активен"), ("Петров", "Бухгалтерия", "В отпуске")]
```
`Количество` = `2`, `Арность` = `3`

---

### Списки разной длины — результат по минимуму

Настройки активности:
```
Список A: ["A", "B", "C", "D"]   (4 элемента)
Список B: ["1", "2", "3"]        (3 элемента)
```

Результат → `Список кортежей`:
```
[("A", "1"), ("B", "2"), ("C", "3")]
```
`Количество` = `3` — лишний элемент `"D"` из Списка A отброшен.

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список A или B = `null` | Ошибка выполнения |
| Любой из списков пуст | Возвращается пустой список кортежей, `Количество` = `0` |
| Списки разной длины | Результат обрезается по минимальному — без ошибки |
