# TupleInspect — Кортеж: Анализ

Активность для полной диагностики `System.Tuple` за один проход в процессах Primo RPA.  
Определяет арность, типы и значения элементов. Опционально сравнивает два кортежа.  
Входной кортеж не изменяется.

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Кортеж** | `Object` | Всегда | Анализируемый кортеж |

### Сравнение _(заполняются если задан Второй кортеж)_

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Второй кортеж (для сравнения)** | `Object` | Нет | Кортеж для сравнения с первым. Если не задан — выходы сравнения = `false` |

---

## Выходные параметры

### Структура

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Арность** | `Int32` | Количество элементов кортежа (1–7) |
| **Тип кортежа** | `String` | Имя типа: `"Tuple\`2"` для `Tuple<T,T>`, `"Tuple\`3"` для трёхэлементного |
| **Типы элементов** | `String` | Типы через запятую: `"String, Int32, Boolean"` |
| **Значения элементов** | `String` | Строковые значения через `"; "`: `"Иванов; 42; true"` |
| **Есть null элементы** | `Boolean` | `true` если хотя бы один элемент кортежа равен `null` |

### Сравнение _(заполняются только если задан Второй кортеж)_

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Равны** | `Boolean` | `true` если одинаковая арность И все значения равны через `object.Equals()` |
| **Одинаковая арность** | `Boolean` | `true` если число элементов обоих кортежей совпадает |
| **Совпадают типы** | `Boolean` | `true` если арность И типы всех элементов совпадают |

---

## Примеры использования

### Диагностика кортежа

Входной кортеж: `("Иванов", 42, true)`

Настройки активности:
```
Кортеж:                   personTuple
Второй кортеж:            (не задан)
```

Результат:
```
Арность:            3
Тип кортежа:        "Tuple`3"
Типы элементов:     "String, Int32, Boolean"
Значения элементов: "Иванов; 42; true"
Есть null:          false
```

---

### Сравнение двух кортежей

Кортеж A: `("Иванов", 42, true)`  
Кортеж B: `("Иванов", 42, true)`

Настройки активности:
```
Кортеж:                   tupleA
Второй кортеж:            tupleB
```

Результат — Сравнение:
```
Равны:               true
Одинаковая арность:  true
Совпадают типы:      true
```

---

### Обнаружение несовпадения типов

Кортеж A: `("Иванов", 42)`  — `Tuple<string, int>`  
Кортеж B: `("Иванов", "42")` — `Tuple<string, string>`

Результат — Сравнение:
```
Равны:               false
Одинаковая арность:  true    (оба арности 2)
Совпадают типы:      false   (Int32 ≠ String)
```

---

### Проверка наличия null перед деструктуризацией

Настройки активности:
```
Кортеж:        myTuple
Есть null:     varHasNulls
```

Использование: если `varHasNulls == true` → добавить ветку обработки `null`-значений перед дальнейшей работой с кортежем.

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Кортеж = `null` | Ошибка выполнения |
| Переданный объект не является `System.Tuple` или `System.ValueTuple` | Ошибка выполнения с именем типа |
| Второй кортеж = `null` (но поле заполнено) | Все выходы сравнения = `false` |
| Второй кортеж не является `System.Tuple` | Все выходы сравнения = `false` |
