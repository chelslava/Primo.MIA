# TupleUnzip — Кортеж: Unzip списков

Активность для разбора списка кортежей обратно в отдельные `List<string>` в процессах Primo RPA.  
Обратная операция к **«Кортеж: Zip списков»**.

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список кортежей** | `Object` | Всегда | Список кортежей для разбора. Поддерживаются `List<Tuple<string,string>>` и `List<Tuple<string,string,string>>`, а также любой `List<T>` где `T` — `Tuple` арности 2–7 |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Список A (из Item1)** | `List<string>` | Значения `Item1` всех кортежей. `null`-значения → `""` |
| **Список B (из Item2)** | `List<string>` | Значения `Item2` всех кортежей |
| **Список C (из Item3)** | `List<string>` | Значения `Item3`. Пустой список если арность кортежей < 3 |
| **Количество** | `Int32` | Число обработанных кортежей |
| **Арность кортежей** | `Int32` | Арность кортежей — определяется по первому элементу списка |

---

## Примеры использования

### Unzip пар — разобрать обратно в два списка

Входной список: `[("Иванов", "42"), ("Петров", "37"), ("Сидоров", "55")]`

Настройки активности:
```
Список кортежей: pairsList
Список A:        varNames
Список B:        varAges
```

Результат:
```
varNames = ["Иванов", "Петров", "Сидоров"]
varAges  = ["42", "37", "55"]
Количество     = 3
Арность кортежей = 2
```

---

### Unzip троек — три списка из трёхэлементных кортежей

Входной список: `[("Иванов","ИТ","Активен"), ("Петров","Бухгалтерия","В отпуске")]`

Настройки активности:
```
Список кортежей: tripletsList
Список A:        varNames
Список B:        varDepts
Список C:        varStatuses
```

Результат:
```
varNames    = ["Иванов", "Петров"]
varDepts    = ["ИТ", "Бухгалтерия"]
varStatuses = ["Активен", "В отпуске"]
Количество  = 2
```

---

### Частичный Unzip — только нужные столбцы

Если нужен только первый столбец из пар:

Настройки активности:
```
Список кортежей: dataList
Список A:        varKeys
(Список B и C — не заданы)
```

Результат → `varKeys` = значения всех `Item1`.

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список кортежей = `null` | Ошибка выполнения |
| Список пуст | Все выходные списки пусты, `Количество` = `0`, `Арность` = `0` |
| Элемент списка не является `System.Tuple` | Ошибка выполнения с именем типа |
| Арность кортежей = 1 | Ошибка: Unzip требует арность ≥ 2 |
| `null`-значение внутри кортежа | Записывается как `""` в выходной список |
| Ни один выходной список не задан | Ошибка валидации |
