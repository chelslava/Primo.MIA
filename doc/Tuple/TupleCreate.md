# TupleCreate — Кортеж: Создать

Активность для создания `System.Tuple` или `System.ValueTuple` из 1–7 элементов произвольных типов в процессах Primo RPA.  
Арность кортежа определяется автоматически по последнему заполненному полю `ItemN`.

> **Поддерживаются оба типа кортежей** — выбор через свойство «Тип кортежа»:  
> `ClassicTuple` — `System.Tuple` (по умолчанию, NuGet не нужен)  
> `ValueTuple`   — `System.ValueTuple` (требует NuGet `System.ValueTuple 4.5.0`)

> **Все активности группы прозрачно работают с обоими типами** — передавайте любой кортеж  
> в «Получить элемент», «Деструктуризация» и т.д. без дополнительных настроек.

> **ВАЖНО:** `System.Tuple` иммутабелен — изменить элемент после создания нельзя.  
> Для замены элемента используйте активность **«Кортеж: Заменить элемент»**.  
> `System.ValueTuple` формально мутабелен, но через рефлексию ведёт себя так же.  
> Подробнее — см. раздел [Tuple vs ValueTuple](#tuple-vs-valuetuple).

---

## Режимы работы (`Тип кортежа`)

| Значение | Тип .NET | NuGet | Применение |
|----------|----------|-------|------------|
| `ClassicTuple` | `System.Tuple<T1..T7>` | Не нужен | Универсальный выбор по умолчанию |
| `ValueTuple` | `System.ValueTuple<T1..T7>` | `System.ValueTuple 4.5.0` | Большие коллекции кортежей — меньше нагрузка на GC |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Тип кортежа** | `TupleKind` | Нет | `ClassicTuple` или `ValueTuple`. По умолчанию `ClassicTuple` |

### Элементы

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Item1 (обязателен)** | `Object` | Всегда | Первый элемент. Принимает любой тип: `string`, `int`, `bool`, `DateTime`, `List` и т.д. |
| **Item2** | `Object` | Нет | Второй элемент. Если не задан — создаётся кортеж с одним элементом |
| **Item3** | `Object` | Нет | Третий элемент |
| **Item4** | `Object` | Нет | Четвёртый элемент |
| **Item5** | `Object` | Нет | Пятый элемент |
| **Item6** | `Object` | Нет | Шестой элемент |
| **Item7** | `Object` | Нет | Седьмой элемент. Максимально допустимый |

> Заполняйте поля **без пропусков** по порядку: Item1, Item2, Item3...  
> Пустые поля после последнего заполненного игнорируются.

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Кортеж** | `Object` | Созданный кортеж. Тип зависит от «Тип кортежа» и арности |
| **Арность** | `Int32` | Количество элементов в созданном кортеже (1–7) |
| **Тип (имя)** | `String` | Имя типа: `"Tuple\`2"` или `"ValueTuple\`2"`. Для диагностики |

---

## Примеры использования

### ClassicTuple — пара «ключ–значение»

Настройки активности:
```
Тип кортежа: ClassicTuple
Item1:       "host"
Item2:       "localhost"
```

Результат → `Кортеж` = `("host", "localhost")`, `Тип (имя)` = `"Tuple`2"`, `Арность` = `2`

---

### ValueTuple — запись о сотруднике

Настройки активности:
```
Тип кортежа: ValueTuple
Item1:       "Иванов"
Item2:       42
Item3:       true
```

Результат → `Кортеж` = `("Иванов", 42, true)` как `ValueTuple<object,object,object>`,  
`Тип (имя)` = `"ValueTuple`3"`, `Арность` = `3`

---

### Передача ValueTuple в другие активности

Созданный `ValueTuple` передаётся в остальные активности группы без изменений:

```
[Кортеж: Создать]          Тип=ValueTuple, Item1="A", Item2=1  → myTuple
[Кортеж: Получить элемент] Кортеж=myTuple, Номер=Item2         → result (= 1)
[Кортеж: Деструктуризация] Кортеж=myTuple, Out:Item1=varA      → varA (= "A")
```

Все активности определяют тип автоматически и используют нужный механизм рефлексии.

## Tuple vs ValueTuple

| Характеристика | `System.Tuple` | `System.ValueTuple` |
|----------------|---------------|---------------------|
| Вид типа | Ссылочный (class) | Значимый (struct) |
| Размещение | Heap (куча) | Stack (стек) для локальных переменных |
| NuGet | Не нужен | `System.ValueTuple 4.5.0` |
| Мутабельность | Иммутабелен | Мутабелен в C#-коде |
| Мутабельность через рефлексию | Нет | **Также нет** — struct упакован в `object`, `SetValue` изменяет копию |
| Накладные расходы на GC | Есть (heap allocation) | Меньше при локальном использовании |
| Рекомендуется для | Общего использования | Больших коллекций (List, цикл обработки) |

> **Итог:** для большинства задач используйте `ClassicTuple`.  
> `ValueTuple` выгоден только при обработке тысяч кортежей в цикле, где важно снизить нагрузку на GC.

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| `Item1` не задан | Ошибка валидации |
| Выходная переменная «Кортеж» не задана | Ошибка валидации |
| Пропуск в последовательности (Item1, Item3 без Item2) | Item2 считается концом — арность = 1 |
| `ValueTuple` без NuGet `System.ValueTuple` | Ошибка выполнения: тип не найден |
