# TupleSort — Кортеж: Сортировка списка

Активность для сортировки `List<Tuple<...>>` по значению выбранного элемента `ItemN` в процессах Primo RPA.  
Возвращает новый список — оригинал не изменяется. Работает с кортежами любой арности.

---

## Режимы работы

Режим выбирается через свойство **Тип сортировки** (`TupleSortType`):

| Тип | Описание |
|-----|----------|
| `Alphabetical` | Строковая без учёта регистра. Используется по умолчанию |
| `Numeric` | Числовая — значения парсятся как `double`. Нечисловые элементы уходят в конец списка |
| `Natural` | Натуральная — числовые части внутри строки сравниваются как числа: `file2` < `file10` |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список кортежей** | `Object` | Всегда | Список кортежей для сортировки. Тип элемента — любой `Tuple` арности 1–7 |
| **Ключ сортировки** | `TupleItemIndex` | Всегда | По значению какого элемента сортировать: `Item1`–`Item7` |
| **Направление** | `TupleSortDirection` | Всегда | `Ascending` (A→Z, 1→9) или `Descending` (Z→A, 9→1) |
| **Тип сортировки** | `TupleSortType` | Всегда | Алгоритм сравнения значений |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Результат** | `Object` | Отсортированный список кортежей. Тот же тип что и входной |
| **Количество** | `Int32` | Количество кортежей в результате |

---

## Примеры использования

### Сортировка по имени (Item1) — алфавитная

Входной список: `[("Сидоров","55"), ("Иванов","42"), ("Петров","37")]`

Настройки активности:
```
Список кортежей: employeeList
Ключ:            Item1
Направление:     Ascending
Тип:             Alphabetical
```

Результат:
```
[("Иванов","42"), ("Петров","37"), ("Сидоров","55")]
```

---

### Сортировка по числовому полю (Item2) — числовая

Входной список: `[("Сидоров","55"), ("Иванов","42"), ("Петров","37")]`

Настройки активности:
```
Ключ:       Item2
Направление: Descending
Тип:         Numeric
```

Результат — от большего к меньшему:
```
[("Сидоров","55"), ("Иванов","42"), ("Петров","37")]
```

---

### Сортировка файлов по имени — натуральная

Входной список: `[("file10","1KB"), ("file2","5KB"), ("file1","3KB")]`

Настройки активности:
```
Ключ:        Item1
Направление: Ascending
Тип:         Natural
```

Результат:
```
[("file1","3KB"), ("file2","5KB"), ("file10","1KB")]
```

> **Сравнение с `Alphabetical`:**
> ```
> Alphabetical → [file1, file10, file2]
> Natural      → [file1, file2,  file10]
> ```

---

### Числовая сортировка с нечисловыми значениями

Входной список: `[("B","текст"), ("A","10"), ("C","3"), ("D","н/д")]`

Тип `Numeric`, Ключ `Item2`, Ascending:

Результат — числовые сначала, нечисловые в конец:
```
[("C","3"), ("A","10"), ("B","текст"), ("D","н/д")]
```

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список = `null` | Ошибка выполнения |
| Список пуст | Возвращается пустой список без ошибки |
| Ключ сортировки > арности кортежа | Все такие элементы получают ключ `""` — уходят в начало при `Ascending` |
| Нечисловые строки при `Numeric` | Получают значение `double.MaxValue` — уходят в конец при `Ascending` |
