# TupleDestructure — Кортеж: Деструктуризация

Активность для разложения всех элементов кортежа в отдельные переменные за один шаг в процессах Primo RPA.
Прозрачно работает с `System.Tuple` и `System.ValueTuple` — тип определяется автоматически.  
Аналог синтаксиса C# 7 `var (a, b, c) = tuple` — но для .NET Framework без ValueTuple.

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Кортеж** | `Object` | Всегда | Входной кортеж типа `Tuple<...>` для деструктуризации |

### Элементы _(задайте хотя бы одну переменную)_

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Out: Item1** | `Object` | Нет | Переменная для первого элемента кортежа |
| **Out: Item2** | `Object` | Нет | Переменная для второго элемента |
| **Out: Item3** | `Object` | Нет | Переменная для третьего элемента |
| **Out: Item4** | `Object` | Нет | Переменная для четвёртого элемента |
| **Out: Item5** | `Object` | Нет | Переменная для пятого элемента |
| **Out: Item6** | `Object` | Нет | Переменная для шестого элемента |
| **Out: Item7** | `Object` | Нет | Переменная для седьмого элемента |

> Заполнять все Out-переменные не обязательно — задайте только те, которые нужны.  
> Если номер переменной превышает арность кортежа — она пропускается без ошибки.

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Out: Item1 … Out: Item7** | `Object` | Значения соответствующих элементов кортежа |
| **Арность** | `Int32` | Реальное количество элементов в переданном кортеже |
| **Тип (имя)** | `String` | Имя типа: `"Tuple`3"` или `"ValueTuple`3"`. Для диагностики |

---

## Примеры использования

### Полная деструктуризация трёхэлементного кортежа

Входной кортеж: `("Иванов", 42, true)`

Настройки активности:
```
Кортеж:    myTuple
Out:Item1: varName
Out:Item2: varAge
Out:Item3: varActive
```

Результат:
```
varName   = "Иванов"
varAge    = 42
varActive = true
Арность   = 3
```

---

### Частичная деструктуризация — только нужные элементы

Входной кортеж: `("INV-001", "2025-01-15", "Петров", 15000.50, "Оплачен")`

Настройки активности — нужны только номер и статус:
```
Кортеж:    invoiceTuple
Out:Item1: varInvoiceId
Out:Item5: varStatus
(Item2, Item3, Item4 — не заданы)
```

Результат:
```
varInvoiceId = "INV-001"
varStatus    = "Оплачен"
Арность      = 5
```

---

### Деструктуризация пары из списка кортежей (внутри цикла)

Кортеж из списка `List<Tuple<string,string>>`:

Настройки активности:
```
Кортеж:    currentTuple
Out:Item1: varKey
Out:Item2: varValue
```

Результат на каждой итерации:
```
varKey   = значение Item1 текущего кортежа
varValue = значение Item2 текущего кортежа
```

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Кортеж = `null` | Ошибка выполнения |
| Переданный объект не является `System.Tuple` или `System.ValueTuple` | Ошибка выполнения с именем типа |
| Ни одна Out-переменная не задана | Ошибка валидации |
| `Out:Item3` задан, но арность кортежа = 2 | Переменная пропускается без ошибки |
