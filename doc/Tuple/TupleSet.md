# TupleSet — Кортеж: Заменить элемент

Активность для замены одного элемента кортежа в процессах Primo RPA.  
Поскольку `System.Tuple` иммутабелен — активность создаёт **новый** кортеж той же арности с заменённым элементом. Оригинальный кортеж не изменяется.
Для `System.ValueTuple`: несмотря на мутабельность struct, при передаче как `object` он упакован (boxed). В .NET Framework `SetValue` на упакованном struct изменяет временную копию, а не оригинал. Поэтому активность также создаёт новый кортеж — для обоих типов поведение одинаково.

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Кортеж** | `Object` | Всегда | Исходный кортеж. Не изменяется — на его основе создаётся новый |
| **Номер элемента** | `TupleItemIndex` | Всегда | Какой элемент заменить: `Item1`–`Item7`. Должен быть ≤ арности кортежа |
| **Новое значение** | `Object` | Всегда | Новое значение для указанного элемента. Принимает любой тип |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Новый кортеж** | `Object` | Кортеж с заменённым элементом. Имеет ту же арность что и исходный. Можно записать в ту же переменную что и исходный |

---

## Примеры использования

### Обновление статуса в кортеже-записи

Исходный кортеж: `("INV-001", 15000.50, "Ожидание")`

Настройки активности:
```
Кортеж:          invoiceTuple
Номер элемента:  Item3
Новое значение:  "Оплачен"
Новый кортеж:    invoiceTuple
```

Результат → `invoiceTuple` = `("INV-001", 15000.50, "Оплачен")`

> `Новый кортеж` записан в ту же переменную — эффект «изменения» записи.

---

### Обновление числового поля

Исходный кортеж: `("Иванов", 42, true)`

Настройки активности:
```
Кортеж:          personTuple
Номер элемента:  Item2
Новое значение:  43
Новый кортеж:    updatedTuple
```

Результат → `updatedTuple` = `("Иванов", 43, true)`, исходный `personTuple` = `("Иванов", 42, true)` — не изменён.

---

### Замена элемента внутри цикла обработки списка

Применение: обход `List<Tuple<string,string>>` и обновление второго поля.

Настройки активности (внутри цикла `Для каждого`):
```
Кортеж:          currentItem
Номер элемента:  Item2
Новое значение:  processedValue
Новый кортеж:    currentItem
```

После замены — записываем `currentItem` обратно по индексу в список.

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Кортеж = `null` | Ошибка выполнения |
| Переданный объект не является `System.Tuple` или `System.ValueTuple` | Ошибка выполнения с именем типа |
| Номер элемента > арности кортежа | Ошибка: `"Невозможно заменить Item4 в кортеже арности 2"` |
| Новое значение = `null` | Допустимо — элемент заменяется на `null` |
