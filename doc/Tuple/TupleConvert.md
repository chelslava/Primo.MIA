# TupleConvert — Кортеж: Конвертация

Активность для преобразования `System.Tuple` в другие структуры данных и обратно в процессах Primo RPA.  
В зависимости от режима заполняются разные выходные свойства.

---

## Режимы работы

Режим выбирается через свойство **Режим** (`TupleConvertMode`):

| Режим | Вход | Выход | Описание |
|-------|------|-------|----------|
| `ToList` | `Tuple` | `List<object>` | Каждый элемент кортежа становится элементом списка |
| `FromList` | `List<object>` | `Tuple` | Первые 1–7 элементов списка собираются в кортеж |
| `ToDictionary` | `Tuple` | `Dictionary<string,object>` | Ключи `"Item1"`, `"Item2"`… — значения элементов |
| `ToString` | `Tuple` | `String` | Строковое представление с настраиваемым разделителем |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Кортеж** | `Object` | `ToList`, `ToDictionary`, `ToString` | Входной кортеж |
| **Режим** | `TupleConvertMode` | Всегда | Тип конвертации |

### FromList _(только для режима `FromList`)_

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список (вход)** | `List<object>` | Всегда | Список для сборки в кортеж. Допустимо 1–7 элементов |

### ToString _(только для режима `ToString`)_

| Свойство | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| **Разделитель** | `String` | `"; "` | Строка вставляемая между элементами |
| **Включать ключи** | `Boolean` | `true` | `true` → `"Item1=Иванов; Item2=42"`, `false` → `"Иванов; 42"` |

---

## Выходные параметры

| Свойство | Тип | Режимы | Описание |
|----------|-----|--------|----------|
| **Кортеж (результат)** | `Object` | `FromList` | Собранный кортеж |
| **Список (результат)** | `List<object>` | `ToList` | Список значений из кортежа |
| **Словарь (результат)** | `Dictionary<string,object>` | `ToDictionary` | Словарь с ключами `"Item1"`…`"ItemN"` |
| **Строка (результат)** | `String` | `ToString` | Строковое представление |
| **Арность** | `Int32` | Все | Количество элементов в кортеже |

---

## Примеры использования

### Режим `ToList`

Входной кортеж: `("Иванов", 42, true)`

Настройки активности:
```
Кортеж:  personTuple
Режим:   ToList
```

Результат → `Список` = `["Иванов", 42, true]`, `Арность` = `3`

---

### Режим `FromList`

Настройки активности:
```
Список (вход): ["host", "localhost", 5432]
Режим:         FromList
```

Результат → `Кортеж` = `("host", "localhost", 5432)`, `Арность` = `3`

> Если список содержит более 7 элементов — ошибка выполнения.

---

### Режим `ToDictionary`

Входной кортеж: `("Иванов", 42, true)`

Настройки активности:
```
Кортеж: personTuple
Режим:  ToDictionary
```

Результат → `Словарь`:
```
"Item1" → "Иванов"
"Item2" → 42
"Item3" → true
```

---

### Режим `ToString`

Входной кортеж: `("INV-001", 15000.50, "Оплачен")`

#### С ключами (`Включать ключи` = `true`):
```
Кортеж:          invoiceTuple
Разделитель:     " | "
Включать ключи:  true
```
Результат → `Строка` = `"Item1=INV-001 | Item2=15000.5 | Item3=Оплачен"`

#### Только значения (`Включать ключи` = `false`):
```
Включать ключи:  false
```
Результат → `Строка` = `"INV-001 | 15000.5 | Оплачен"`

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Кортеж = `null` для `ToList` / `ToDictionary` / `ToString` | Ошибка выполнения |
| Список = `null` для `FromList` | Ошибка выполнения |
| Список пуст для `FromList` | Ошибка: невозможно создать пустой кортеж |
| Список > 7 элементов для `FromList` | Ошибка: максимум 7 |
| Переданный объект не является `System.Tuple` или `System.ValueTuple` | Ошибка выполнения с именем типа |
