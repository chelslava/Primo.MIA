# TupleGet — Кортеж: Получить элемент

Активность для извлечения одного элемента кортежа по его номеру (`Item1`–`Item7`) в процессах Primo RPA.  
Значение записывается в выходную переменную с сохранением исходного типа как `object`.
Прозрачно работает с `System.Tuple` и `System.ValueTuple`.

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Кортеж** | `Object` | Всегда | Входной кортеж типа `Tuple<...>` |
| **Номер элемента** | `TupleItemIndex` | Всегда | Какой элемент извлечь: `Item1`–`Item7` |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Значение** | `Object` | Извлечённое значение. Для работы с конкретным типом приведите переменную: `(string)myVar`, `Convert.ToInt32(myVar)` |
| **Тип значения** | `String` | Имя типа значения: `"String"`, `"Int32"`, `"Boolean"` и т.д. `"null"` если элемент равен `null` |

---

## Номера элементов (`TupleItemIndex`)

| Значение | Обращение | Описание |
|----------|-----------|----------|
| `Item1` | `.Item1` | Первый элемент кортежа |
| `Item2` | `.Item2` | Второй элемент |
| `Item3` | `.Item3` | Третий элемент |
| `Item4` | `.Item4` | Четвёртый элемент |
| `Item5` | `.Item5` | Пятый элемент |
| `Item6` | `.Item6` | Шестой элемент |
| `Item7` | `.Item7` | Седьмой элемент |

---

## Примеры использования

### Извлечение строки — имя из кортежа-записи

Входной кортеж: `("Иванов", 42, true)`

Настройки активности:
```
Кортеж:          recordTuple
Номер элемента:  Item1
```

Результат → `Значение` = `"Иванов"`, `Тип значения` = `"String"`

---

### Извлечение числа — сумма из кортежа-счёта

Входной кортеж: `("INV-001", 15000.50, "Оплачен")`

Настройки активности:
```
Кортеж:          invoiceTuple
Номер элемента:  Item2
```

Результат → `Значение` = `15000.5` (как `object`), `Тип значения` = `"Double"`

> Для арифметики: `Convert.ToDouble(varValue)` или `(double)varValue`

---

### Проверка типа перед использованием

Настройки активности:
```
Кортеж:          myTuple
Номер элемента:  Item3
Значение:        varResult
Тип значения:    varTypeName
```

Использование выхода `Тип значения` в условии: если `varTypeName == "Boolean"` → обработать как флаг.

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Кортеж = `null` | Ошибка выполнения |
| Переданный объект не является `System.Tuple` или `System.ValueTuple` | Ошибка выполнения с именем типа |
| Номер элемента > арности кортежа | Ошибка: `"Item3 не существует в кортеже арности 2. Доступны: Item1–Item2"` |
| Значение элемента = `null` | `Значение` = `null`, `Тип значения` = `"null"` |
