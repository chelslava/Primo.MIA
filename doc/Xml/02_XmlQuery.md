# XML: XPath запрос

> **Группа:** MIA → HTTP / Web  
> **Класс:** `XmlQueryBack`

## Назначение

Выполняет XPath-запрос к XML-документу и возвращает одно значение, список совпадений или их количество.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `XML-строка` | `string` | XML для запроса. |
| `XPath` | `string` | XPath-выражение. |
| `Режим` | `XmlQueryMode` | `SingleValue`, `List`, `Count`. |
| `Префикс namespace` | `string` | Настройка namespace, если требуется. |
| `URI namespace` | `string` | URI namespace. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Результат` | `object` | Первое значение или список значений. |
| `Количество` | `int` | Количество найденных совпадений. |

## Пример

```text
XML-строка: "<root><item>1</item><item>2</item></root>"
XPath: "//item"
Режим: List
```

## Примечания

- Namespace-параметры предусмотрены в интерфейсе, но основной сценарий рассчитан на простые XPath без сложной схемы пространств имён.
- Для предварительной проверки или форматирования XML используйте [01_XmlParse.md](01_XmlParse.md).
