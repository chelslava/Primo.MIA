# XML: Парсинг

> **Группа:** MIA → HTTP / Web  
> **Класс:** `XmlParseBack`

## Назначение

Разбирает XML-строку, проверяет её корректность или форматирует документ с отступами.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `XML-строка` | `string` | Исходный XML. |
| `Режим` | `XmlParseMode` | `ToStructure`, `Validate`, `Format`. |
| `Символы отступа` | `string` | Используется в режиме форматирования. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Результат` | `object` | Структура или отформатированный XML. |
| `Валиден` | `bool` | Признак корректного XML. |
| `Ошибка парсинга` | `string` | Текст ошибки, если XML некорректен. |

## Режимы

| Режим | Поведение |
|---|---|
| `ToStructure` | Преобразует XML в словарную структуру. |
| `Validate` | Только проверяет синтаксис XML. |
| `Format` | Возвращает красиво отформатированный XML. |

## Примечания

- В структурном представлении атрибуты обычно попадают в словарь с префиксом `@`.
- Для выборки по XPath используйте [02_XmlQuery.md](02_XmlQuery.md).
