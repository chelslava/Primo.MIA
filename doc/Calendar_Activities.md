## Обзор модуля

Модуль предоставляет набор активностей для работы с производственными календарями в роботизированных процессах Primo. Источник данных — [xmlcalendar.ru](https://xmlcalendar.ru). Поддерживаются регионы: Россия, Казахстан, Беларусь, Узбекистан.

Все активности работают с объектом `ProductionCalendar`, загруженным в кэш `RepoDict` и идентифицируемым по GUID. Первым шагом всегда должна быть активность **Календарь: Загрузить**.

### Типичная цепочка активностей

```
1. Календарь: Загрузить  →  получает calendarId (GUID)
2. Календарь: Операции   →  использует calendarId для расчётов
   (или другие активности модуля)
```

### Типы дней (DayType)

| Значение | Описание |
|---|---|
| `Workday` | Полный рабочий день |
| `ShortWorkday` | Сокращённый рабочий день (7 ч). Например: 31 декабря, 22 февраля |
| `Weekend` | Обычный выходной (суббота, воскресенье) |
| `Holiday` | Праздничный день. Имеет название из справочника праздников |

### Форматы файлов

| Формат | Особенности |
|---|---|
| `Xml` | Рекомендуемый. Содержит праздники с названиями, переносы, полную статистику |
| `Json` | Содержит месяцы, переносы и статистику. Названия праздников отсутствуют |
| `Csv` | Табличный формат с данными по месяцам и статистикой |
| `Txt` | Только список дат праздников. Переносы и статистика отсутствуют |

## 1. Календарь: Загрузить

Загружает производственный календарь из локального файла или скачивает с xmlcalendar.ru. Сохраняет объект в кэш `RepoDict` и возвращает GUID для использования в других активностях.

### Входные параметры

| Параметр | Тип | По умолч. | Описание |
|---|---|---|---|
| `Prop_CalendarPath` | `string` | | Путь к папке для хранения файлов календаря. При скачивании создаётся автоматически |
| `Prop_Year` | `int` | текущий год | Год календаря. Используется как fallback — если парсер нашёл год в файле, он имеет приоритет |
| `Prop_Format` | `CalendarFormat` | `Xml` | Формат файла: `Xml` / `Json` / `Csv` / `Txt` |
| `Prop_Region` | `CalendarRegion` | `Russia` | Регион: `Russia` / `Kazakhstan` / `Belarus` / `Uzbekistan` |
| `Prop_DownloadIfMissing` | `bool` | `true` | Скачать с xmlcalendar.ru если файл не найден локально |
| `Prop_ForceReload` | `bool` | `false` | Принудительно скачать заново, даже если файл существует. Имеет приоритет над `Prop_CacheAgeDays` |
| `Prop_CacheAgeDays` | `int` | `30` | Не скачивать если файл свежее N дней. `0` = всегда считать устаревшим |
| `Prop_DownloadTimeoutSeconds` | `int` | `30` | Таймаут HTTP-запроса при скачивании в секундах |

### Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Prop_CalendarId` | `string` | GUID загруженного календаря в кэше. Передаётся в другие активности |
| `Prop_CalendarLoaded` | `bool` | `true` если загрузка прошла успешно |
| `Prop_FilePath` | `string` | Полный путь к файлу календаря на диске |
| `Prop_LoadedFrom` | `string` | Источник: `"File"` \| `"Internet"` \| `"Cache"` |

### Имя файла

Файл сохраняется по шаблону:

```
calendar_{регион}_{год}.{расширение}

Пример: calendar_ru_2026.xml
```

### Логика выбора источника

| Условие | Действие | LoadedFrom |
|---|---|---|
| Файл свежий (< `CacheAgeDays` дней) И `ForceReload=false` | Читается локально | `"Cache"` |
| Файл есть, `DownloadIfMissing=false`, `ForceReload=false` | Читается локально | `"File"` |
| `DownloadIfMissing=true` ИЛИ `ForceReload=true` | Скачивается | `"Internet"` |
| Файл не найден, `DownloadIfMissing=false` | Ошибка выполнения | — |

### Ошибки

| Условие | Сообщение |
|---|---|
| `Prop_CalendarPath` пустой | `Путь к папке календаря обязателен` |
| `Prop_Year` не является целым числом | `Год должен быть целым числом` |
| Файл не найден и `DownloadIfMissing=false` | `Файл календаря не найден: {путь}` |
| Ошибка HTTP при скачивании | `Не удалось скачать календарь из интернета: {причина}` |
| Таймаут HTTP-запроса | `Превышено время ожидания ({N} с)` |
| Ошибка разбора файла | `Ошибка разбора файла календаря: {причина}` |

### Пример

```csharp
// Prop_CalendarPath = @"C:\Data\Calendars"
// Prop_Year         = 2026
// Prop_Format       = Xml
// Prop_Region       = Russia
// Prop_CacheAgeDays = 7
// Prop_CalendarId   → myCalendarId  (выходная переменная)
```

## 2. Календарь: Операции

Универсальная активность для выполнения операций с загруженным производственным календарём. Поддерживает шесть режимов работы.

### Режимы работы

| Режим | Описание |
|---|---|
| `AddWorkDays` | Прибавить N рабочих дней к входной дате |
| `SubtractWorkDays` | Вычесть N рабочих дней из входной даты |
| `CheckDayType` | Определить тип дня (`Workday` / `Weekend` / `Holiday` / `ShortWorkday`) |
| `CountWorkdays` | Подсчитать количество рабочих дней между двумя датами включительно |
| `NextWorkday` | Найти следующий рабочий день после входной даты (не включая её) |
| `PrevWorkday` | Найти предыдущий рабочий день до входной даты (не включая её) |

### Входные параметры

| Параметр | Тип | По умолч. | Описание |
|---|---|---|---|
| `Prop_CalendarId` | `string` | | GUID из активности «Календарь: Загрузить» |
| `Prop_OperationMode` | `BusinessCalendarMode` | `AddWorkDays` | Выбранный режим работы |
| `Prop_InputDate` | `DateTime` | | Входная дата. Для `CountWorkdays` — начало диапазона |
| `Prop_EndDate` | `DateTime` | | Конечная дата. Используется только в режиме `CountWorkdays` |
| `Prop_DaysCount` | `int` | `1` | Количество дней. Используется в `AddWorkDays` и `SubtractWorkDays` |

### Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Prop_ResultDate` | `DateTime` | Результирующая дата после операции |
| `Prop_DayType` | `string` | Тип дня: `Workday` \| `Weekend` \| `Holiday` \| `ShortWorkday` |
| `Prop_IsWorkday` | `bool` | `true` если день рабочий (`Workday` или `ShortWorkday`) |
| `Prop_HolidayName` | `string` | Название праздника. Пустая строка если день не праздничный |
| `Prop_WorkdaysInYear` | `int` | Рабочих дней в году по статистике календаря |
| `Prop_HolidaysInYear` | `int` | Праздничных и выходных дней в году |
| `Prop_WorkdaysBetween` | `int` | Рабочих дней в диапазоне. Заполняется только в режиме `CountWorkdays` |

### Важные замечания

> **⚠ Год входной даты** (и конечной даты в `CountWorkdays`) должен совпадать с годом загруженного календаря. Для работы с датами из разных лет загрузите каждый год отдельно.

> **✔** `AddWorkDays(date, 0)` возвращает входную дату без изменений.

> **✔** `CountWorkdays` считает оба крайних дня включительно.

### Ошибки

| Условие | Сообщение |
|---|---|
| `Prop_CalendarId` пустой | `ID календаря обязателен` |
| `Prop_InputDate` некорректный | `Некорректный формат входной даты. Ожидается значение типа DateTime.` |
| `Prop_DaysCount` не целое число | `Количество дней должно быть целым числом` |
| `Prop_EndDate` не указана (CountWorkdays) | `Конечная дата обязательна для режима «Рабочих дней в диапазоне»` |
| Год даты ≠ год календаря | `Дата {дата} не соответствует году календаря ({год})` |
| GUID не найден в кэше | `Календарь не найден в кэше по GUID: {guid}` |

## 3. Календарь: Рабочие дни списком

Возвращает `List<DateTime>` всех рабочих дней в заданном диапазоне дат с опциональной фильтрацией по типу дня и дню недели. Используется для генерации расписаний, заполнения таблиц задач и построения рабочих графиков.

### Входные параметры

| Параметр | Тип | По умолч. | Описание |
|---|---|---|---|
| `Prop_CalendarId` | `string` | | GUID из активности «Календарь: Загрузить» |
| `Prop_StartDate` | `DateTime` | | Начало диапазона включительно |
| `Prop_EndDate` | `DateTime` | | Конец диапазона включительно. При `StartDate > EndDate` порядок нормализуется автоматически |
| `Prop_IncludeShortDays` | `bool` | `true` | Включать сокращённые рабочие дни (`ShortWorkday`) в результат |
| `Prop_DayOfWeekFilter` | `DayOfWeekFilter` | `All` | Фильтр по дню недели (см. таблицу ниже) |
| `Prop_DayOfWeekMask` | `string` | | Маска для `CustomMask`: номера через запятую, Пн=1..Вс=7. Пример: `"1,3,5"` |

### Значения DayOfWeekFilter

| Значение | Описание |
|---|---|
| `All` | Все рабочие дни без фильтра по дню недели (по умолчанию) |
| `MondayOnly` | Только понедельники |
| `TuesdayOnly` | Только вторники |
| `WednesdayOnly` | Только среды |
| `ThursdayOnly` | Только четверги |
| `FridayOnly` | Только пятницы |
| `MondayAndFriday` | Только понедельники и пятницы |
| `CustomMask` | Пользовательская маска из `Prop_DayOfWeekMask` |

### Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Prop_ResultList` | `List<DateTime>` | Список рабочих дней диапазона |
| `Prop_Count` | `int` | Количество найденных рабочих дней |
| `Prop_FirstDate` | `DateTime` | Первый рабочий день. `DateTime.MinValue` если список пустой |
| `Prop_LastDate` | `DateTime` | Последний рабочий день. `DateTime.MinValue` если список пустой |

### Ограничения

> **⚠** Весь диапазон должен находиться внутри года загруженного календаря. Для многолетних диапазонов загрузите каждый год отдельно и объедините списки в скрипте.

### Пример: еженедельные задачи

```csharp
// Получить все рабочие понедельники I квартала 2026
Prop_StartDate       = 01.01.2026
Prop_EndDate         = 31.03.2026
Prop_DayOfWeekFilter = MondayOnly

// → [12.01, 19.01, 26.01, 02.02, ...]
// Каникульные понедельники 05.01 и 09.01 пропущены
```

## 4. Календарь: Nth рабочий день

Возвращает дату N-го рабочего дня в заданном периоде (месяц, квартал, полугодие или год). Поддерживает отсчёт с конца и фильтрацию по дням недели. Используется для автоматического определения дат плановых платежей, отчётов и регламентных операций.

### Входные параметры

| Параметр | Тип | По умолч. | Описание |
|---|---|---|---|
| `Prop_CalendarId` | `string` | | GUID из активности «Календарь: Загрузить» |
| `Prop_N` | `int` | `1` | Номер рабочего дня. Положительный — с начала (`1` = первый), отрицательный — с конца (`-1` = последний, `-2` = предпоследний). Ноль недопустим |
| `Prop_Period` | `NthWorkdayPeriod` | `Month` | Тип периода: `Month` / `Quarter` / `HalfYear` / `Year` |
| `Prop_Month` | `int` | текущий | Месяц (1–12). Используется при `Period=Month` |
| `Prop_Quarter` | `int` | текущий | Квартал (1–4) для `Period=Quarter` или номер полугодия (1–2) для `Period=HalfYear` |
| `Prop_Year` | `int` | из календаря | Год периода. Пустое значение — год загруженного календаря |
| `Prop_IncludeShortDays` | `bool` | `true` | Учитывать сокращённые рабочие дни в отсчёте N |
| `Prop_DayOfWeekFilter` | `DayOfWeekFilter` | `All` | Искать только среди указанных дней недели |
| `Prop_DayOfWeekMask` | `string` | | Пользовательская маска для `CustomMask` |

### Значения NthWorkdayPeriod

| Значение | Описание |
|---|---|
| `Month` | Месяц. Параметры: `Prop_Month` + `Prop_Year` |
| `Quarter` | Квартал (1–4). Q1 = янв–мар, Q2 = апр–июн, Q3 = июл–сен, Q4 = окт–дек |
| `HalfYear` | Полугодие. `Prop_Quarter=1` (янв–июн) или `2` (июл–дек) |
| `Year` | Весь год. Используется только `Prop_Year` |

### Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Prop_ResultDate` | `DateTime` | Найденная дата. `DateTime.MinValue` если `IsFound=false` |
| `Prop_TotalWorkdays` | `int` | Общее число рабочих дней в периоде с учётом фильтра |
| `Prop_IsFound` | `bool` | `false` если N выходит за пределы числа рабочих дней в периоде. `IsSuccess=true` — это не ошибка |

### Примеры (год 2026)

| Параметры | Результат |
|---|---|
| `N=1, Month=1` | `12.01.2026` — первый рабочий день января (каникулы 1–9 янв) |
| `N=-1, Month=12` | `30.12.2026` — последний рабочий день декабря |
| `N=3, Quarter=1` | `14.01.2026` — третий рабочий день I квартала |
| `N=1, Month=1, MondayOnly` | `12.01.2026` — первый рабочий понедельник января |
| `N=-2, Period=Year` | `29.12.2026` — предпоследний рабочий день года |

### Ошибки и особые случаи

| Условие | Поведение |
|---|---|
| `N = 0` | Ошибка: `N обязателен и не может быть равен нулю` |
| `Prop_Month` не указан при `Period=Month` | Ошибка: `Месяц обязателен при периоде Month` |
| `Prop_Quarter` не указан при `Quarter`/`HalfYear` | Ошибка: `Квартал / номер полугодия обязателен` |
| Год ≠ год календаря | Ошибка: `Год {N} не соответствует загруженному календарю ({год})` |
| `|N|` > рабочих дней в периоде | `IsFound=false`, `ResultDate=MinValue`, `IsSuccess=true` |

## 5. Календарь: Следующий день недели

Находит ближайшую дату указанного дня недели с учётом производственного календаря. Поддерживает три режима поиска.

### Режимы поиска

| Режим | Описание |
|---|---|
| `NextOccurrence` | Просто следующее вхождение дня недели без проверки его типа по календарю. Дата может оказаться выходным |
| `NextWorkingOccurrence` | Следующее вхождение, которое является рабочим днём. Пропускает выходные понедельники, праздничные пятницы и т.д. При исчерпании `MaxLookAhead` возвращает `IsFound=false` |
| `NearestWorkday` | Находит следующее вхождение дня недели. Если оно выходное — сдвигает на ближайший рабочий день согласно `Prop_IfWeekend` |

### Входные параметры

| Параметр | Тип | По умолч. | Описание |
|---|---|---|---|
| `Prop_CalendarId` | `string` | | GUID из активности «Календарь: Загрузить» |
| `Prop_StartDate` | `DateTime` | | Дата отсчёта поиска |
| `Prop_TargetDayOfWeek` | `TargetDayOfWeek` | `Monday` | Искомый день: `Monday` / `Tuesday` / `Wednesday` / `Thursday` / `Friday` / `Saturday` / `Sunday` |
| `Prop_Mode` | `DayOfWeekSearchMode` | `NextWorkingOccurrence` | Режим поиска (см. выше) |
| `Prop_IfWeekend` | `DeadlineWeekendBehavior` | `NextWorkday` | Поведение при выходном (только для `NearestWorkday`): `NextWorkday` / `PrevWorkday` / `AsIs` |
| `Prop_IncludeStartDate` | `bool` | `false` | Вернуть `StartDate` если она уже нужный день недели |
| `Prop_MaxLookAhead` | `int` | `30` | Максимум дней поиска вперёд. Защита от бесконечного цикла в режиме `NextWorkingOccurrence` |

### Значения DeadlineWeekendBehavior

| Значение | Описание |
|---|---|
| `NextWorkday` | Сдвинуть на следующий рабочий день. Стандарт для документооборота |
| `PrevWorkday` | Сдвинуть на предыдущий рабочий день. Стандарт для платёжных дедлайнов |
| `AsIs` | Не сдвигать — вернуть дату как есть |

### Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Prop_ResultDate` | `DateTime` | Найденная дата. `DateTime.MinValue` если `IsFound=false` |
| `Prop_DaysAhead` | `int` | Количество дней от `StartDate` до результата |
| `Prop_DayType` | `string` | Тип найденного дня: `Workday` \| `ShortWorkday` \| `Weekend` \| `Holiday` |
| `Prop_IsFound` | `bool` | `false` если не найдено в пределах `MaxLookAhead`. `IsSuccess=true` |

### Примеры (от 15.03.2026, воскресенье)

| Параметры | Результат |
|---|---|
| `Monday / NextWorkingOccurrence` | `16.03.2026` — ближайший рабочий понедельник |
| `Friday / NearestWorkday / PrevWorkday` | `20.03.2026` если рабочая, иначе ближайший рабочий день назад |
| `Wednesday / NextOccurrence` | `18.03.2026` — следующая среда без проверки типа |
| `Monday / NextWorkingOccurrence`, от `09.01.2026` | `12.01.2026` — перепрыгивает каникульный `05.01` |

### Ошибки

| Условие | Поведение |
|---|---|
| `Prop_CalendarId` пустой | Ошибка: `ID календаря обязателен` |
| `Prop_StartDate` некорректный | Ошибка: `Некорректный формат начальной даты` |
| Не найдено за `MaxLookAhead` дней | `IsFound=false`, `IsSuccess=true`, сообщение с рекомендацией увеличить `MaxLookAhead` |

## Справочник: типовые паттерны

### Передача GUID между активностями

Все активности модуля получают GUID через `Prop_CalendarId`. Типичная схема:

```csharp
string myCalendarId;  // переменная в скрипте

// В «Календарь: Загрузить»:   Prop_CalendarId → myCalendarId
// В «Календарь: Операции»:    Prop_CalendarId = myCalendarId
// В «Рабочие дни списком»:    Prop_CalendarId = myCalendarId
```

### Работа с несколькими годами

Если процесс охватывает несколько лет — загрузите каждый год отдельно:

```
Календарь: Загрузить (Year=2025) → id2025
Календарь: Загрузить (Year=2026) → id2026

Для дат 2025 года → Prop_CalendarId = id2025
Для дат 2026 года → Prop_CalendarId = id2026
```

> **⚠** Год входной даты должен совпадать с годом календаря. Смешивание дат из разных лет в одном вызове невозможно.

### Матрица настроек обновления данных

| Сценарий | Настройки |
|---|---|
| Скачивать при каждом запуске | `ForceReload = true` |
| Скачивать не чаще раза в день | `CacheAgeDays = 1` |
| Использовать только локальный файл | `DownloadIfMissing = false` |
| Скачать если файл старше недели | `CacheAgeDays = 7`, `DownloadIfMissing = true` |

### Фильтрация по дням недели

Одинаково работает в «Рабочие дни списком» и «Nth рабочий день»:

| Задача | Настройки |
|---|---|
| Все рабочие дни | `DayOfWeekFilter = All` |
| Только понедельники | `DayOfWeekFilter = MondayOnly` |
| Понедельник, среда, пятница | `DayOfWeekFilter = CustomMask`, `Mask = "1,3,5"` |
| Рабочие дни с пн по чт | `DayOfWeekFilter = CustomMask`, `Mask = "1,2,3,4"` |

### Коды регионов и URL

| `CalendarRegion` | Код | URL шаблон |
|---|---|---|
| `Russia` | `ru` | `xmlcalendar.ru/data/ru/{year}/calendar.xml` |
| `Kazakhstan` | `kz` | `xmlcalendar.ru/data/kz/{year}/calendar.xml` |
| `Belarus` | `by` | `xmlcalendar.ru/data/by/{year}/calendar.xml` |

### Переносы рабочих дней

Производственный календарь содержит переносы: выходной день переносится с одной даты на другую. Активности учитывают переносы автоматически при определении типа дня.

*Пример: если суббота 10.01 объявлена рабочей вместо пятницы 01.01 — `GetDayType(10.01)` вернёт `Workday`, несмотря на то что это суббота.*

## Приложение: модель ProductionCalendar

`ProductionCalendar` — основной объект, хранящийся в кэше `RepoDict`. Создаётся парсером при загрузке и передаётся между активностями по GUID.

### Свойства ProductionCalendar

| Свойство | Тип | Описание |
|---|---|---|
| `Year` | `int` | Год календаря |
| `CountryCode` | `string` | Код региона: `ru` / `kz` / `by` / `uz` |
| `Holidays` | `Dict<string, string>` | Праздники: ключ = ID, значение = название. Доступны только в XML/CSV-форматах |
| `SpecialDays` | `Dict<string, CalendarDay>` | Спец. дни: ключ = дата `dd.MM`, значение = тип/ID праздника/перенос |
| `Transitions` | `Dict<string, string>` | Переносы: выходной (`dd.MM`) → рабочий (`dd.MM`) |
| `TransferWorkdays` | `Dict<string, string>` | Обратный словарь переносов: рабочий (`dd.MM`) → откуда перенесён. O(1) поиск |
| `Statistics` | `CalendarStatistics` | Статистика: `Workdays`, `Holidays`, `Hours40`, `Hours36`, `Hours24` |

### CalendarDay

| Свойство | Тип | Описание |
|---|---|---|
| `Date` | `string` | Дата в формате `dd.MM` |
| `Type` | `int` | `1` = праздник/выходной, `2` = сокращённый рабочий |
| `HolidayId` | `int?` | ID праздника для ссылки на `Holidays`. `null` если нет названия |
| `TransferFrom` | `string` | Дата (`dd.MM`) откуда перенесён этот рабочий день |

### CalendarStatistics

| Свойство | Тип | Описание |
|---|---|---|
| `Workdays` | `int` | Рабочих дней в году |
| `Holidays` | `int` | Праздничных и выходных дней в году |
| `Hours40` | `double` | Рабочих часов при 40-часовой рабочей неделе |
| `Hours36` | `double` | Рабочих часов при 36-часовой рабочей неделе |
| `Hours24` | `double` | Рабочих часов при 24-часовой рабочей неделе |

> **⚠** Статистика доступна только в XML, JSON и CSV форматах. TXT-формат содержит только список праздничных дней, `Statistics.Workdays = 0`.
