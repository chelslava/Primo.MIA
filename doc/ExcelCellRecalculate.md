# Активность «Excel: Пересчёт ячейки»

**Класс:** `ExcelCellRecalculateBack`  
**Группа:** `MIA → Утилиты`  
**Иконка:** Excel

---

## Описание

Пересчитывает имя ячейки Excel на основе смещения от начальной ячейки. Поддерживает стандартную нотацию Excel (A1, B2, Z10, AA5 и т.д.) и позволяет вычислять координаты ячеек программно без необходимости работы с самим файлом Excel.

Активность полезна для динамического формирования адресов ячеек в циклах обработки данных, построения диапазонов и навигации по таблицам.

---

## Основные возможности

- ✅ Поддержка стандартной нотации Excel (A1, B2, Z10, AA5, AAA1 и т.д.)
- ✅ Смещение по строкам (вверх/вниз)
- ✅ Смещение по столбцам (влево/вправо)
- ✅ Автоматическая конвертация между буквенными и числовыми координатами
- ✅ Защита от выхода за границы (минимум A1)
- ✅ Поддержка отрицательных смещений
- ✅ Валидация формата входной ячейки

---

## Входные параметры

### Основные параметры

| Параметр | Тип | Обязательность | По умолчанию | Описание |
|----------|-----|----------------|--------------|----------|
| **Начальная ячейка*** | `string` | Да | - | Имя начальной ячейки в формате Excel (A1, B2, Z10, AA5) |
| **Смещение по строке (ΔR)** | `int` | Нет | `0` | Смещение по строкам. Положительное — вниз, отрицательное — вверх |
| **Смещение по столбцу (ΔC)** | `int` | Нет | `0` | Смещение по столбцам. Положительное — вправо, отрицательное — влево |

**Примечание:** Параметры, отмеченные звездочкой (*), являются обязательными.

---

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Целевая ячейка** | `string` | Вычисленное имя ячейки после применения смещений |

## Примеры использования

### Пример 1: Смещение вправо и вниз

```
Входные параметры:
- Начальная ячейка: "A1"
- Смещение по строке (ΔR): 2
- Смещение по столбцу (ΔC): 3

Результат:
- Целевая ячейка: "D3"

Объяснение:
A1 + 2 строки вниз (1→3) + 3 столбца вправо (A→D) = D3
```

### Пример 2: Смещение только по столбцам

```
Входные параметры:
- Начальная ячейка: "B5"
- Смещение по строке (ΔR): 0
- Смещение по столбцу (ΔC): 5

Результат:
- Целевая ячейка: "G5"

Объяснение:
B5 + 5 столбцов вправо (B→G) = G5
```

### Пример 3: Отрицательное смещение (влево и вверх)

```
Входные параметры:
- Начальная ячейка: "E10"
- Смещение по строке (ΔR): -3
- Смещение по столбцу (ΔC): -2

Результат:
- Целевая ячейка: "C7"

Объяснение:
E10 - 3 строки вверх (10→7) - 2 столбца влево (E→C) = C7
```

### Пример 4: Работа с многобуквенными столбцами

```
Входные параметры:
- Начальная ячейка: "Z1"
- Смещение по строке (ΔR): 0
- Смещение по столбцу (ΔC): 5

Результат:
- Целевая ячейка: "AE1"

Объяснение:
Z (26-й столбец) + 5 = 31-й столбец = AE
```

### Пример 5: Защита от выхода за границы

```
Входные параметры:
- Начальная ячейка: "B2"
- Смещение по строке (ΔR): -5
- Смещение по столбцу (ΔC): -3

Результат:
- Целевая ячейка: "A1"

Объяснение:
B2 - 5 строк = -3 (ограничено до 1)
B2 - 3 столбца = -1 (ограничено до A)
Минимальная ячейка = A1
```

## Алгоритм работы

### Общая схема

```
1. Получение и валидация параметров
   ├─ Проверка наличия начальной ячейки
   └─ Парсинг смещений (по умолчанию 0)
   ↓
2. Парсинг начальной ячейки
   ├─ Разделение на буквенную часть (столбец) и числовую (строка)
   ├─ Валидация формата через regex: ^([A-Z]+)(\d+)$
   └─ Конвертация буквенного столбца в число
   ↓
3. Вычисление новых координат
   ├─ Новая строка = max(1, текущая строка + ΔR)
   └─ Новый столбец = max(1, текущий столбец + ΔC)
   ↓
4. Формирование имени целевой ячейки
   ├─ Конвертация числового столбца в буквенный
   └─ Объединение: буквы + число
   ↓
5. Возврат результата
```

### Конвертация столбцов

**Из букв в число (A → 1, Z → 26, AA → 27):**
```
Алгоритм:
result = 0
для каждого символа c в columnName:
    result = result × 26
    result = result + (c - 'A' + 1)

Примеры:
A    → 1
B    → 2
Z    → 26
AA   → 27  (1×26 + 1)
AB   → 28  (1×26 + 2)
AZ   → 52  (1×26 + 26)
BA   → 53  (2×26 + 1)
ZZ   → 702 (26×26 + 26)
AAA  → 703 (1×26×26 + 1×26 + 1)
```

**Из числа в буквы (1 → A, 26 → Z, 27 → AA):**
```
Алгоритм:
result = ""
пока columnNumber > 0:
    columnNumber = columnNumber - 1  // сдвиг для корректной работы
    result = (char)('A' + (columnNumber % 26)) + result
    columnNumber = columnNumber / 26

Примеры:
1   → A
26  → Z
27  → AA
52  → AZ
53  → BA
702 → ZZ
703 → AAA
```

## Типовые сценарии использования

### 📊 Сценарий 1: Обход таблицы в цикле

```
Задача:
Прочитать данные из столбца B, начиная со строки 2

Решение:
Начальная ячейка: "B2"
Для каждой итерации i (0, 1, 2, ...):
  [Excel: Пересчёт ячейки]
    Начальная ячейка: "B2"
    ΔR: i
    ΔC: 0
    → Целевая ячейка: currentCell
  
  [Excel: Прочитать ячейку] currentCell
```

### 📝 Сценарий 2: Запись данных в диапазон

```
Задача:
Записать массив данных начиная с ячейки C5

Решение:
Начальная ячейка: "C5"
Для каждого элемента data[i]:
  [Excel: Пересчёт ячейки]
    Начальная ячейка: "C5"
    ΔR: i
    ΔC: 0
    → targetCell
  
  [Excel: Записать ячейку] targetCell = data[i]
```

### 🔄 Сценарий 3: Построение диапазона

```
Задача:
Создать диапазон A1:E10 программно

Решение:
startCell = "A1"
[Excel: Пересчёт ячейки]
  Начальная ячейка: "A1"
  ΔR: 9  // 10 строк - 1
  ΔC: 4  // 5 столбцов - 1
  → endCell  // "E10"

range = startCell + ":" + endCell  // "A1:E10"
```

### 📋 Сценарий 4: Навигация по таблице с заголовками

```
Задача:
Прочитать данные из 3-го столбца, пропустив заголовок

Решение:
headerCell = "A1"
[Excel: Пересчёт ячейки]
  Начальная ячейка: headerCell
  ΔR: 1  // пропустить заголовок
  ΔC: 2  // перейти к 3-му столбцу
  → dataCell  // "C2"
```

### 🎯 Сценарий 5: Динамическое формирование формул

```
Задача:
Создать формулу суммы для столбца

Решение:
Для строки 10, столбец B:
[Excel: Пересчёт ячейки] "B2" + ΔR=0, ΔC=0 → "B2"
[Excel: Пересчёт ячейки] "B2" + ΔR=8, ΔC=0 → "B10"
formula = "=SUM(B2:B10)"
```

### 📊 Сценарий 6: Обработка матрицы данных

```
Задача:
Прочитать матрицу 5×3 начиная с B2

Решение:
Для строки row (0..4):
  Для столбца col (0..2):
    [Excel: Пересчёт ячейки]
      Начальная ячейка: "B2"
      ΔR: row
      ΔC: col
      → cell
    
    [Excel: Прочитать ячейку] cell → matrix[row][col]
```

## Обработка ошибок

### Типичные ошибки и решения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `ArgumentNullException: Начальная ячейка обязательна` | Не указана начальная ячейка | Заполнить параметр "Начальная ячейка" |
| `ArgumentException: Неверный формат начальной ячейки` | Некорректный формат ячейки | Использовать формат A1, B2, Z10, AA5 и т.д. |
| Ячейка выходит за границы | Слишком большое отрицательное смещение | Результат автоматически ограничивается до A1 |

### Валидация формата ячейки

Активность принимает только стандартную нотацию Excel:

**✅ Корректные форматы:**
- `A1`, `B2`, `Z10`
- `AA5`, `AB10`, `AZ99`
- `AAA1`, `ZZZ999`

**❌ Некорректные форматы:**
- `1A` (число перед буквой)
- `A` (нет номера строки)
- `1` (нет буквы столбца)
- `A1:B2` (диапазон)
- `$A$1` (абсолютная ссылка)
- `Sheet1!A1` (ссылка с листом)

## Особенности работы

### 🎯 Защита от выхода за границы

Активность автоматически ограничивает результат:
- Минимальная строка: 1
- Минимальный столбец: 1 (A)
- Максимальные значения не ограничены

```
Пример:
A1 + ΔR=-10, ΔC=-10 → A1 (не выходит за границы)
A1 + ΔR=1000, ΔC=1000 → ALL1001 (корректно вычисляется)
```

### 📐 Математика смещений

```
Положительные смещения:
ΔR > 0 → движение вниз (увеличение номера строки)
ΔC > 0 → движение вправо (увеличение номера столбца)

Отрицательные смещения:
ΔR < 0 → движение вверх (уменьшение номера строки)
ΔC < 0 → движение влево (уменьшение номера столбца)

Нулевые смещения:
ΔR = 0, ΔC = 0 → ячейка не изменяется
```

### 🔤 Регистр букв

Активность работает с заглавными буквами (A-Z). Входные данные автоматически приводятся к верхнему регистру при парсинге.

### ⚡ Производительность

Активность выполняет только математические операции и работу со строками:
- Не открывает файлы Excel
- Не требует установленного Excel
- Выполняется мгновенно (< 1 мс)
- Не использует внешние библиотеки

## Технические детали

### Зависимости
- .NET Framework
- System.Text.RegularExpressions
- Не требует Microsoft Excel

### Regex паттерн для валидации

```regex
^([A-Z]+)(\d+)$

Где:
^ — начало строки
([A-Z]+) — одна или более заглавных букв (столбец)
(\d+) — одна или более цифр (строка)
$ — конец строки
```

### Алгоритмическая сложность

- Парсинг ячейки: O(n) где n — длина имени столбца
- Конвертация столбца: O(n) где n — длина имени столбца
- Общая сложность: O(n), обычно n ≤ 3

### Ограничения

- Максимальная длина имени столбца: не ограничена (теоретически)
- Excel поддерживает до 16384 столбцов (XFD)
- Excel поддерживает до 1048576 строк
- Активность не проверяет эти ограничения Excel
