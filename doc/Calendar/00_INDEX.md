# Активности для работы с производственным календарём

Этот раздел содержит документацию по активностям для работы с производственным календарём.

## Обзор

Активности позволяют:
- Загружать производственный календарь из файла или интернета
- Выполнять операции с датами с учётом рабочих/выходных дней
- Проверять тип дня (рабочий, выходной, праздничный, сокращённый)
- Получать списки рабочих дней за период
- Находить N-й рабочий день месяца, квартала или года
- Находить ближайший указанный день недели с учётом переносов

## Поддерживаемые регионы

| Регион | Код | Описание |
|--------|-----|----------|
| Россия | `ru` | Производственный календарь РФ |
| Казахстан | `kz` | Производственный календарь Республики Казахстан |
| Беларусь | `by` | Производственный календарь Республики Беларусь |
| Узбекистан | `uz` | Производственный календарь Республики Узбекистан |

## Поддерживаемые форматы файлов

| Формат | Расширение | Описание |
|--------|------------|----------|
| XML | `.xml` | Полный формат с праздниками, переносами и статистикой. Рекомендуется |
| JSON | `.json` | Формат с месяцами, переносами и статистикой |
| CSV | `.csv` | Табличный формат с данными по месяцам и статистикой |
| TXT | `.txt` | Простой список праздничных дней. Переносы и статистика отсутствуют |

## Именование файлов

Файлы календаря именуются по шаблону:
```
calendar_{регион}_{год}.{расширение}
```

Примеры:
- `calendar_ru_2026.xml` — календарь России за 2026 год
- `calendar_kz_2026.json` — календарь Казахстана за 2026 год
- `calendar_by_2025.xml` — календарь Беларуси за 2025 год

## Типы дней

| Значение | Описание |
|----------|----------|
| `Workday` | Полный рабочий день |
| `ShortWorkday` | Сокращённый рабочий день (например, 31 декабря — 7 часов вместо 8) |
| `Weekend` | Выходной день (суббота, воскресенье) |
| `Holiday` | Праздничный день с названием из справочника праздников |

## Источник данных

При загрузке из интернета используется сервис [xmlcalendar.ru](https://xmlcalendar.ru/), предоставляющий актуальные производственные календари для стран СНГ.

## Пример использования

```
1. Календарь: Загрузить
   - Путь к папке: "C:\Calendars"
   - Год: 2026
   - Регион: Россия
   - Результат (ID): calendarId

2. Календарь: Операции
   - ID календаря: calendarId
   - Режим: Прибавить рабочие дни
   - Входная дата: DateTime.Now
   - Количество дней: 5
   - Результат (дата): resultDate
```
