# Календарь: Загрузить

Загружает производственный календарь из файла или из интернета. Сохраняет объект в глобальный кэш и возвращает GUID для использования в других активностях.

## Параметры

### Входные параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| Путь к папке | String | Да | Директория для хранения файлов календаря. Создаётся автоматически при скачивании |
| Год | Int32 | Да | Год календаря (например, 2026). Используется как запасное значение — если год найден в файле, он имеет приоритет |
| Формат | CalendarFormat | Нет | Формат файла: XML, JSON, CSV или TXT (по умолчанию XML) |
| Регион | CalendarRegion | Нет | Регион календаря (по умолчанию Россия) |
| Загрузить из интернета | Boolean | Нет | Скачать с xmlcalendar.ru при отсутствии файла (по умолчанию true) |
| Принудительная перезагрузка | Boolean | Нет | Скачать заново, даже если файл уже существует (по умолчанию false). Имеет приоритет над параметром «Срок кэша» |
| Срок кэша (дней) | Int32 | Нет | Не скачивать если файл свежее указанного числа дней (по умолчанию 30). Значение 0 — всегда считать устаревшим |
| Таймаут скачивания (сек) | Int32 | Нет | Таймаут HTTP-запроса при скачивании в секундах (по умолчанию 30) |

### Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| ID календаря | String | GUID загруженного календаря. Передаётся в другие активности через параметр «ID календаря» |
| Календарь загружен | Boolean | Признак успешной загрузки |
| Путь к файлу | String | Полный путь к загруженному файлу на диске |
| Загружен из | String | Источник загрузки: `File`, `Internet` или `Cache` |

## Регионы

| Значение | Код | Описание |
|----------|-----|----------|
| Russia | `ru` | Россия |
| Kazakhstan | `kz` | Казахстан |
| Belarus | `by` | Беларусь |
| Uzbekistan | `uz` | Узбекистан |

## Форматы файлов

### XML
Полный формат с праздниками и переносами. Рекомендуется для использования, так как содержит полную информацию о календаре, включая названия праздников.

### JSON
Формат с месяцами, переносами и статистикой. Названия праздников отсутствуют.

### CSV
Табличный формат с данными по месяцам и статистикой.

### TXT
Простой список дат праздничных дней. Переносы рабочих дней и статистика отсутствуют.

## Именование файлов

Файлы календаря именуются по шаблону:
```
calendar_{регион}_{год}.{расширение}
```

Примеры:
- `calendar_ru_2026.xml` — календарь России за 2026 год
- `calendar_kz_2026.json` — календарь Казахстана за 2026 год
- `calendar_by_2025.xml` — календарь Беларуси за 2025 год
- `calendar_uz_2024.csv` — календарь Узбекистана за 2024 год

## Алгоритм работы

1. Формируется имя файла с учётом региона и года: `calendar_{регион}_{год}.{расширение}`
2. Определяется стратегия загрузки:
   - Если файл свежий (моложе «Срок кэша» дней) и «Принудительная перезагрузка» отключена — читается из файла (`Загружен из = Cache`)
   - Если файл существует, скачивание отключено и перезагрузка не нужна — читается из файла (`Загружен из = File`)
   - Если «Загрузить из интернета» включено или «Принудительная перезагрузка» включена — скачивается (`Загружен из = Internet`)
   - Если файл не найден и скачивание отключено — возвращается ошибка
3. В загруженный календарь устанавливается код страны (`CountryCode`)
4. Объект сохраняется в кэш, возвращается GUID

## Примеры использования

### Загрузка календаря России

```
Путь к папке: "C:\Calendars"
Год: 2026
Формат: XML
Регион: Россия
Загрузить из интернета: true
```

Результат:
- Файл: `C:\Calendars\calendar_ru_2026.xml`
- Сообщение: «Календарь за 2026 год (Россия) загружен из файла»

### Загрузка календаря Казахстана

```
Путь к папке: "C:\Calendars"
Год: 2026
Формат: JSON
Регион: Казахстан
Загрузить из интернета: true
```

Результат:
- Файл: `C:\Calendars\calendar_kz_2026.json`
- Сообщение: «Календарь за 2026 год (Казахстан) загружен из интернета»

### Загрузка с ограничением частоты скачивания

```
Путь к папке: "C:\Calendars"
Год: 2026
Регион: Россия
Загрузить из интернета: true
Срок кэша (дней): 7
```

Файл скачивается только если он старше 7 дней. При более свежем файле используется локальная копия (`Загружен из = Cache`).

### Загрузка без скачивания из интернета

```
Путь к папке: "C:\Calendars"
Год: 2025
Формат: XML
Регион: Беларусь
Загрузить из интернета: false
```

Если файл `calendar_by_2025.xml` не существует, активность вернёт ошибку.

## Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Не указан путь к папке | Параметр «Путь к папке» пустой | Укажите путь к папке |
| Год должен быть числом | Параметр «Год» не является числом | Укажите корректный год |
| Файл календаря не найден | Файл не существует и скачивание отключено | Включите скачивание или создайте файл вручную |
| Ошибка скачивания календаря | Нет доступа к интернету или сервер недоступен | Проверьте подключение к интернету |
| Превышено время ожидания | Истёк таймаут HTTP-запроса | Увеличьте параметр «Таймаут скачивания» |
| Ошибка разбора календаря | Файл повреждён или имеет неверный формат | Удалите файл и скачайте заново |

## Свойства объекта ProductionCalendar

После загрузки объект `ProductionCalendar` содержит:

| Свойство | Тип | Описание |
|----------|-----|----------|
| Year | Int32 | Год календаря |
| CountryCode | String | Код страны (`ru`, `kz`, `by`, `uz`) |
| Holidays | Dictionary | Словарь праздников (ID → название). Доступен только в XML-формате |
| SpecialDays | Dictionary | Специальные дни (дата `dd.MM` → информация о дне) |
| Transitions | Dictionary | Переносы рабочих дней (выходной `dd.MM` → рабочий `dd.MM`) |
| Statistics | CalendarStatistics | Статистика по году: рабочих дней, праздников, рабочих часов |

## Примечания

- Рекомендуется использовать формат XML, так как он содержит полную информацию о календаре
- Для работы с несколькими годами загружайте каждый год отдельно — каждый вызов возвращает отдельный ID
- Код страны (`CountryCode`) автоматически устанавливается из выбранного региона
- Статистика рабочих часов (`Hours40`, `Hours36`, `Hours24`) доступна только в XML, JSON и CSV форматах
