# Календарь: Следующий день недели

Находит ближайшую дату указанного дня недели с учётом производственного календаря. Поддерживает три режима поиска: просто следующее вхождение, следующее рабочее вхождение и вхождение с коррекцией при попадании на выходной.

## Параметры

### Входные параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| ID календаря | String | Да | GUID из активности «Календарь: Загрузить» |
| Начальная дата | DateTime | Да | Дата отсчёта поиска |
| День недели | TargetDayOfWeek | Нет | Искомый день недели (по умолчанию Monday) |
| Режим поиска | DayOfWeekSearchMode | Нет | Режим поиска (по умолчанию NextWorkingOccurrence) |
| При выходном | DeadlineWeekendBehavior | Нет | Поведение если найденный день выходной. Используется только в режиме NearestWorkday (по умолчанию NextWorkday) |
| Включать стартовую дату | Boolean | Нет | Вернуть начальную дату, если она уже является нужным днём недели (по умолчанию false) |
| Макс. дней поиска | Int32 | Нет | Максимальное количество дней поиска вперёд (по умолчанию 30). Защита от зависания в режиме NextWorkingOccurrence |

### Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| Результат (дата) | DateTime | Найденная дата. `DateTime.MinValue` если `Найден = false` |
| Дней вперёд | Int32 | Количество дней от начальной даты до результата |
| Тип дня | String | Тип найденного дня: `Workday`, `ShortWorkday`, `Weekend`, `Holiday` |
| Найден | Boolean | `false` если день не найден в пределах «Макс. дней поиска». Активность завершается успешно |

## Режимы поиска

### NextOccurrence
Возвращает следующее вхождение указанного дня недели без проверки типа дня по производственному календарю. Результат может оказаться выходным или праздничным.

Пример:
- Начальная дата: 15.03.2026 (воскресенье)
- День недели: Wednesday
- Результат: 18.03.2026 (среда) — без проверки рабочий ли день

### NextWorkingOccurrence
Возвращает следующее вхождение, которое является рабочим днём по производственному календарю. Если вхождение выходное — поиск продолжается на следующей неделе.

Пример:
- Начальная дата: 01.01.2026 (четверг, праздник)
- День недели: Monday
- Результат: 12.01.2026 — пропущен понедельник 05.01 (каникулы)

### NearestWorkday
Находит следующее вхождение дня недели. Если оно выходное — сдвигает на ближайший рабочий день согласно параметру «При выходном».

Пример:
- Начальная дата: 28.04.2026 (вторник)
- День недели: Friday
- Результат: 01.05.2026 (пятница, праздник)
- При выходном: PrevWorkday
- Скорректированный результат: 30.04.2026 (четверг)

## Поведение при выходном

Используется только в режиме `NearestWorkday`.

| Значение | Описание |
|----------|----------|
| `NextWorkday` | Сдвинуть на следующий рабочий день. Стандарт для назначения задач и встреч |
| `PrevWorkday` | Сдвинуть на предыдущий рабочий день. Стандарт для платёжных дедлайнов |
| `AsIs` | Не сдвигать. Вернуть дату как есть, даже если день выходной |

## Дни недели

| Значение | День |
|----------|------|
| `Monday` | Понедельник |
| `Tuesday` | Вторник |
| `Wednesday` | Среда |
| `Thursday` | Четверг |
| `Friday` | Пятница |
| `Saturday` | Суббота |
| `Sunday` | Воскресенье |

## Примеры использования

### Следующий рабочий понедельник

```
ID календаря: calendarId
Начальная дата: DateTime.Now
День недели: Monday
Режим поиска: NextWorkingOccurrence
```

Результат:
- Результат (дата): следующий понедельник, который является рабочим днём
- Дней вперёд: количество дней до результата
- Сообщение: «Следующий понедельник: 16.03.2026 (через 1 дн., Workday)»

### Ближайшая пятница с коррекцией

```
ID календаря: calendarId
Начальная дата: 28.04.2026
День недели: Friday
Режим поиска: NearestWorkday
При выходном: PrevWorkday
```

Результат:
- 01.05.2026 — праздник (День труда)
- Скорректировано на 30.04.2026 (предыдущий рабочий день)
- Сообщение: «Следующий friday: 30.04.2026 (через 2 дн., Workday) [перенесён назад из-за выходного]»

### Следующая среда без проверки

```
ID календаря: calendarId
Начальная дата: 15.03.2026
День недели: Wednesday
Режим поиска: NextOccurrence
```

Результат:
- Результат (дата): 18.03.2026 — следующая среда, тип дня не проверяется

### Проверить текущую дату

```
ID календаря: calendarId
Начальная дата: DateTime.Now
День недели: Monday
Включать стартовую дату: true
Режим поиска: NextWorkingOccurrence
```

Если сегодня рабочий понедельник — вернёт сегодняшнюю дату. Иначе — следующий рабочий понедельник.

## Алгоритм работы

1. Определяется начало поиска: следующий день после начальной даты (или сама дата при `Включать стартовую дату = true`)
2. Поиск продвигается по дням вперёд до достижения «Макс. дней поиска»:
   - При нахождении нужного дня недели — применяется логика выбранного режима
   - В режиме `NextWorkingOccurrence` при нерабочем вхождении поиск перепрыгивает на 7 дней вперёд
3. Если день найден в режиме `NearestWorkday` и он выходной — применяется коррекция по параметру «При выходном»
4. Если за `Макс. дней поиска` ничего не найдено — возвращается `Найден = false`

## Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| ID календаря не указан | Параметр «ID календаря» пустой | Загрузите календарь и передайте полученный ID |
| Календарь не найден в кэше | GUID не соответствует загруженному календарю | Загрузите календарь заново |
| Некорректная начальная дата | Параметр «Начальная дата» не является датой | Укажите корректную дату |
| Не найдено за Макс. дней поиска | Все вхождения в периоде выходные | Увеличьте параметр «Макс. дней поиска» |

## Примечания

- Активность требует предварительно загруженный календарь от активности «Календарь: Загрузить»
- В режиме `NextWorkingOccurrence` все январские понедельники во время каникул будут пропущены — убедитесь что `Макс. дней поиска` достаточно велико (рекомендуется не менее 30)
- Параметр «При выходном» игнорируется в режимах `NextOccurrence` и `NextWorkingOccurrence`
- Результат `Найден = false` не является ошибкой — активность завершается успешно
