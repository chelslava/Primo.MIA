# Календарь: Nth рабочий день

Возвращает дату N-го рабочего дня в заданном периоде. Поддерживает отсчёт как с начала периода, так и с конца. Используется для автоматического определения дат плановых платежей, отчётов и регламентных операций.

## Параметры

### Входные параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| ID календаря | String | Да | GUID из активности «Календарь: Загрузить» |
| N (номер рабочего дня) | Int32 | Да | Номер рабочего дня. Положительное число — отсчёт с начала (1 = первый). Отрицательное — с конца (-1 = последний, -2 = предпоследний). Ноль недопустим |
| Период | NthWorkdayPeriod | Нет | Тип периода: Month, Quarter, HalfYear, Year (по умолчанию Month) |
| Месяц (1–12) | Int32 | Для Month | Номер месяца от 1 до 12. Используется при периоде Month |
| Квартал / Полугодие | Int32 | Для Quarter/HalfYear | Номер квартала (1–4) или полугодия (1–2) |
| Год | Int32 | Нет | Год периода. Если не указан — используется год загруженного календаря |
| Включать сокращённые дни | Boolean | Нет | Учитывать сокращённые рабочие дни в отсчёте N (по умолчанию true) |
| Фильтр дней недели | DayOfWeekFilter | Нет | Искать только среди указанных дней недели (по умолчанию All) |
| Маска дней (Пн=1..Вс=7) | String | Для CustomMask | Пользовательская маска дней недели |

### Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| Результат (дата) | DateTime | Найденная дата. `DateTime.MinValue` если `Найден = false` |
| Рабочих дней в периоде | Int32 | Общее число рабочих дней в периоде с учётом фильтра |
| Найден | Boolean | `false` если N выходит за пределы числа рабочих дней в периоде. Активность завершается успешно |

## Типы периодов

| Значение | Описание | Необходимые параметры |
|----------|----------|-----------------------|
| `Month` | Месяц | Месяц (1–12) + Год |
| `Quarter` | Квартал. Q1 = янв–мар, Q2 = апр–июн, Q3 = июл–сен, Q4 = окт–дек | Квартал/Полугодие (1–4) + Год |
| `HalfYear` | Полугодие. 1 = янв–июн, 2 = июл–дек | Квартал/Полугодие (1–2) + Год |
| `Year` | Весь год | Год |

## Примеры использования

### Первый рабочий день месяца

```
ID календаря: calendarId
N: 1
Период: Month
Месяц: 1
Год: 2026
```

Результат:
- Результат (дата): 12.01.2026
- Рабочих дней в периоде: 17
- Сообщение: «1-й рабочий день января 2026: 12.01.2026 (понедельник)»

> Январские каникулы (1–9 января) пропущены

### Последний рабочий день месяца

```
ID календаря: calendarId
N: -1
Период: Month
Месяц: 12
Год: 2026
```

Результат:
- Результат (дата): 30.12.2026

### Третий рабочий день квартала

```
ID календаря: calendarId
N: 3
Период: Quarter
Квартал / Полугодие: 1
Год: 2026
```

Результат:
- Результат (дата): 14.01.2026
- Сообщение: «3-й рабочий день Q1 2026: 14.01.2026 (среда)»

### Первый рабочий понедельник месяца

```
ID календаря: calendarId
N: 1
Период: Month
Месяц: 1
Год: 2026
Фильтр дней недели: MondayOnly
```

Результат:
- Результат (дата): 12.01.2026 — первый рабочий понедельник января
- Рабочих дней в периоде: 4 (только рабочие понедельники)

### Предпоследний рабочий день года

```
ID календаря: calendarId
N: -2
Период: Year
Год: 2026
```

Результат:
- Результат (дата): 29.12.2026

## Алгоритм работы

1. Определяются границы периода по выбранному типу и параметрам
2. Строится список всех рабочих дней периода с учётом фильтров
3. Вычисляется индекс нужного элемента:
   - Положительный N: индекс = N − 1 (первый элемент = индекс 0)
   - Отрицательный N: индекс = Количество − |N| (последний = индекс Count−1)
4. Если индекс выходит за границы — возвращается `Найден = false`
5. Иначе возвращается дата по вычисленному индексу

## Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| ID календаря не указан | Параметр «ID календаря» пустой | Загрузите календарь и передайте полученный ID |
| N не может быть равен нулю | Параметр N равен 0 | Укажите положительное или отрицательное число |
| Месяц обязателен | Не указан месяц при периоде Month | Укажите номер месяца от 1 до 12 |
| Квартал / полугодие обязателен | Не указан квартал при периоде Quarter или HalfYear | Укажите номер квартала (1–4) или полугодия (1–2) |
| Год не соответствует календарю | Год параметра отличается от года загруженного календаря | Загрузите нужный год |
| Некорректная маска дней | Маска содержит недопустимые символы | Используйте числа 1–7 через запятую |

## Особый случай: N выходит за пределы периода

Если запрошенный N больше числа рабочих дней в периоде, активность **не возвращает ошибку**. Вместо этого:
- `Найден = false`
- `Результат (дата) = DateTime.MinValue`
- Активность завершается успешно (`IsSuccess = true`)

Это позволяет обработать ситуацию в скрипте:

```
Если Найден = false:
    Лог: "В периоде нет {N}-го рабочего дня"
Иначе:
    Использовать Результат (дата)
```

## Примечания

- Активность требует предварительно загруженный календарь от активности «Календарь: Загрузить»
- Год периода должен совпадать с годом загруженного календаря
- Сокращённые рабочие дни (ShortWorkday) учитываются в отсчёте при `Включать сокращённые дни = true`
- При использовании фильтра дней недели параметр «Рабочих дней в периоде» показывает количество дней, прошедших оба фильтра
