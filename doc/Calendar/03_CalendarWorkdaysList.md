# Календарь: Рабочие дни списком

Возвращает список всех рабочих дней в заданном диапазоне дат. Поддерживает фильтрацию по типу дня и по дню недели.

## Параметры

### Входные параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| ID календаря | String | Да | GUID из активности «Календарь: Загрузить» |
| Начальная дата | DateTime | Да | Начало диапазона включительно |
| Конечная дата | DateTime | Да | Конец диапазона включительно. Если конечная дата раньше начальной, порядок нормализуется автоматически |
| Включать сокращённые дни | Boolean | Нет | Включать в список дни типа `ShortWorkday` (по умолчанию true) |
| Фильтр дней недели | DayOfWeekFilter | Нет | Ограничить список конкретными днями недели (по умолчанию All — все дни) |
| Маска дней (Пн=1..Вс=7) | String | Для CustomMask | Номера дней через запятую. Пример: `1,3,5` — понедельник, среда, пятница |

### Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| Список рабочих дней | List\<DateTime\> | Все рабочие дни в диапазоне с учётом фильтров |
| Количество дней | Int32 | Количество найденных рабочих дней |
| Первый рабочий день | DateTime | Первый рабочий день в диапазоне. `DateTime.MinValue` если список пустой |
| Последний рабочий день | DateTime | Последний рабочий день в диапазоне. `DateTime.MinValue` если список пустой |

## Фильтр дней недели

| Значение | Описание |
|----------|----------|
| `All` | Все рабочие дни без фильтра (по умолчанию) |
| `MondayOnly` | Только понедельники |
| `TuesdayOnly` | Только вторники |
| `WednesdayOnly` | Только среды |
| `ThursdayOnly` | Только четверги |
| `FridayOnly` | Только пятницы |
| `MondayAndFriday` | Только понедельники и пятницы |
| `CustomMask` | Пользовательская маска из параметра «Маска дней» |

### Формат маски дней

При выборе `CustomMask` укажите номера дней недели через запятую:

| Номер | День |
|-------|------|
| 1 | Понедельник |
| 2 | Вторник |
| 3 | Среда |
| 4 | Четверг |
| 5 | Пятница |
| 6 | Суббота |
| 7 | Воскресенье |

Примеры:
- `1,3,5` — понедельник, среда, пятница
- `1,2,3,4` — с понедельника по четверг
- `5` — только пятницы

## Примеры использования

### Получить все рабочие дни января

```
ID календаря: calendarId
Начальная дата: 01.01.2026
Конечная дата: 31.01.2026
Включать сокращённые дни: true
Фильтр дней недели: All
```

Результат:
- Список рабочих дней: [12.01, 13.01, 14.01, 15.01, 16.01, 19.01, ...]
- Количество дней: 17
- Первый рабочий день: 12.01.2026
- Последний рабочий день: 30.01.2026

### Получить рабочие понедельники квартала

```
ID календаря: calendarId
Начальная дата: 01.01.2026
Конечная дата: 31.03.2026
Фильтр дней недели: MondayOnly
```

Результат:
- Список: [12.01, 19.01, 26.01, 02.02, ...]
- Каникульный понедельник 05.01 пропущен как выходной

### Получить рабочие дни с пн по ср

```
ID календаря: calendarId
Начальная дата: 01.03.2026
Конечная дата: 31.03.2026
Фильтр дней недели: CustomMask
Маска дней: 1,2,3
```

Результат:
- Список рабочих дней только по понедельникам, вторникам и средам

### Получить список без сокращённых дней

```
ID календаря: calendarId
Начальная дата: 01.12.2026
Конечная дата: 31.12.2026
Включать сокращённые дни: false
```

Результат:
- 31.12.2026 исключён из списка (сокращённый рабочий день)

## Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| ID календаря не указан | Параметр «ID календаря» пустой | Загрузите календарь и передайте полученный ID |
| Календарь не найден в кэше | GUID не соответствует загруженному календарю | Загрузите календарь заново |
| Некорректная начальная дата | Параметр «Начальная дата» не является датой | Укажите корректную дату |
| Некорректная конечная дата | Параметр «Конечная дата» не является датой | Укажите корректную дату |
| Диапазон выходит за пределы года | Год дат не совпадает с годом загруженного календаря | Загрузите нужный год |
| Некорректная маска дней | Строка маски содержит недопустимые символы | Используйте числа 1–7 через запятую |
| Маска дней не указана | Выбран CustomMask, но маска пустая | Укажите маску дней |

## Алгоритм работы

1. Генерируется последовательность всех дат от начальной до конечной включительно
2. Для каждой даты определяется тип дня по производственному календарю
3. Применяется фильтр по типу дня (`Workday` всегда включается, `ShortWorkday` — по параметру)
4. Применяется фильтр по дню недели (если задан)
5. Возвращаются все прошедшие фильтрацию даты в хронологическом порядке

## Примечания

- Весь диапазон должен находиться в пределах года загруженного календаря
- Для многолетних диапазонов загрузите каждый год отдельно и объедините списки в скрипте
- Список возвращается в хронологическом порядке
- Если рабочих дней в диапазоне не найдено, возвращается пустой список и `DateTime.MinValue` для первого и последнего дней
