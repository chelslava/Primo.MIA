# Календарь: Операции

Выполняет операции с производственным календарём: прибавить или вычесть рабочие дни, проверить тип дня, подсчитать рабочие дни в диапазоне, найти следующий или предыдущий рабочий день.

## Параметры

### Входные параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| ID календаря | String | Да | GUID из активности «Календарь: Загрузить» |
| Режим операции | BusinessCalendarMode | Да | Режим работы (см. раздел «Режимы операции») |
| Входная дата | DateTime | Да | Дата для операции. Для режима «Рабочих дней в диапазоне» — начало диапазона |
| Конечная дата | DateTime | Для CountWorkdays | Конечная дата диапазона. Используется только в режиме «Рабочих дней в диапазоне» |
| Количество дней | Int32 | Для Add/Subtract | Количество рабочих дней для прибавления или вычитания |

### Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| Результат (дата) | DateTime | Дата после операции |
| Тип дня | String | Тип дня: `Workday`, `Weekend`, `Holiday`, `ShortWorkday` |
| Рабочий день | Boolean | `true` если день рабочий (включая сокращённый) |
| Название праздника | String | Название праздника. Пустая строка если день не праздничный |
| Рабочих дней в году | Int32 | Количество рабочих дней в году по статистике календаря |
| Праздничных дней в году | Int32 | Количество праздничных и выходных дней в году |
| Рабочих дней в диапазоне | Int32 | Количество рабочих дней между двумя датами. Заполняется только в режиме «Рабочих дней в диапазоне» |

## Режимы операции

### Прибавить рабочие дни
Добавляет указанное количество рабочих дней к входной дате. Выходные и праздничные дни пропускаются.

Пример:
- Входная дата: 25.12.2026 (четверг)
- Количество дней: 3
- Результат: 29.12.2026 (вторник) — пропущены суббота 26.12 и воскресенье 27.12

### Вычесть рабочие дни
Вычитает указанное количество рабочих дней из входной даты. Выходные и праздничные дни пропускаются.

Пример:
- Входная дата: 29.12.2026 (вторник)
- Количество дней: 3
- Результат: 25.12.2026 (четверг) — пропущены воскресенье 27.12 и суббота 26.12

### Проверить тип дня
Определяет тип указанной даты и возвращает информацию о дне.

Пример:
- Входная дата: 01.01.2026
- Тип дня: `Holiday`
- Название праздника: «Новогодние каникулы»

### Рабочих дней в диапазоне
Подсчитывает количество рабочих дней между входной и конечной датами включительно.

Пример:
- Входная дата: 01.01.2026
- Конечная дата: 31.01.2026
- Рабочих дней в диапазоне: 17

### Следующий рабочий день
Возвращает первый рабочий день после входной даты. Сама входная дата не включается в результат.

Пример:
- Входная дата: 31.12.2026 (четверг)
- Результат: 11.01.2027 (следующий рабочий после новогодних каникул)

### Предыдущий рабочий день
Возвращает первый рабочий день до входной даты. Сама входная дата не включается в результат.

Пример:
- Входная дата: 09.01.2026 (пятница, каникулы)
- Результат: 31.12.2025 (предыдущий рабочий)

## Типы дней

| Значение | Описание |
|----------|----------|
| `Workday` | Обычный рабочий день |
| `Weekend` | Выходной день (суббота, воскресенье) |
| `Holiday` | Праздничный день с названием |
| `ShortWorkday` | Сокращённый рабочий день (например, перед праздником) |

## Примеры использования

### Прибавить 5 рабочих дней

```
ID календаря: calendarId
Режим операции: Прибавить рабочие дни
Входная дата: DateTime.Now
Количество дней: 5
```

Результат:
- Результат (дата): дата через 5 рабочих дней
- Сообщение: «Прибавлено 5 рабочих дней. Результат: 23.03.2026»

### Проверить тип дня

```
ID календаря: calendarId
Режим операции: Проверить тип дня
Входная дата: new DateTime(2026, 1, 1)
```

Результат:
- Тип дня: `Holiday`
- Рабочий день: `false`
- Название праздника: «Новогодние каникулы»
- Сообщение: «01.01.2026 — Праздничный день (Новогодние каникулы)»

### Подсчёт рабочих дней в квартале

```
ID календаря: calendarId
Режим операции: Рабочих дней в диапазоне
Входная дата: 01.01.2026
Конечная дата: 31.03.2026
```

Результат:
- Рабочих дней в диапазоне: 57
- Сообщение: «Рабочих дней с 01.01.2026 по 31.03.2026: 57»

### Вычесть 10 рабочих дней

```
ID календаря: calendarId
Режим операции: Вычесть рабочие дни
Входная дата: DateTime.Now
Количество дней: 10
```

Результат:
- Результат (дата): дата 10 рабочих дней назад
- Сообщение: «Вычтено 10 рабочих дней. Результат: 01.03.2026»

## Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| ID календаря не указан | Параметр «ID календаря» пустой | Загрузите календарь и передайте полученный ID |
| Календарь не найден в кэше | GUID не соответствует загруженному календарю | Загрузите календарь заново через «Календарь: Загрузить» |
| Некорректный формат входной даты | Параметр «Входная дата» не является датой | Укажите корректную дату |
| Количество дней должно быть целым числом | Параметр «Количество дней» не является числом | Укажите целое число |
| Конечная дата не указана | Режим «Рабочих дней в диапазоне» требует конечную дату | Укажите «Конечную дату» |
| Дата не соответствует году календаря | Год входной даты отличается от года загруженного календаря | Загрузите календарь нужного года |

## Учёт переносов

Календарь учитывает переносы рабочих дней, установленные законодательством. Если выходной день перенесён на другую дату, активность корректно определит тип дня.

Пример переноса:
- 1 марта объявлен выходным (перенос праздника)
- 1 сентября объявлен рабочим вместо него

При проверке 1 сентября активность вернёт `Workday`, несмотря на то что это суббота. При проверке 1 марта — `Weekend`.

## Работа с разными регионами

Календарь содержит код страны (`CountryCode`), который устанавливается при загрузке. Операции с датами выполняются в соответствии с производственным календарём выбранного региона.

Для работы с несколькими регионами одновременно загрузите каждый регион отдельно и используйте соответствующий ID:

```
Календарь: Загрузить (Россия)    → calendarRu
Календарь: Загрузить (Казахстан) → calendarKz

Для российских дат:       ID календаря = calendarRu
Для казахстанских дат:    ID календаря = calendarKz
```

## Примечания

- Активность требует предварительно загруженный календарь от активности «Календарь: Загрузить»
- Год входной даты должен совпадать с годом загруженного календаря
- При прибавлении 0 дней возвращается входная дата без изменений
- Подсчёт рабочих дней в диапазоне включает обе граничные даты
