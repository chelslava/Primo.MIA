# HTTP: Запрос с повторами

> **Группа:** MIA → HTTP / Web  
> **Класс:** `HttpRetryBack`

## Назначение

Выполняет HTTP-запрос с политикой повторных попыток. Полезно для нестабильных API, временных сетевых ошибок и ответов `5xx`/`429`.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `URL` | `string` | Адрес запроса. |
| `Метод` | `HttpMethodType` | HTTP-метод. |
| `Заголовки (JSON)` | `string` | Дополнительные заголовки. |
| `Тело запроса` | `string` | Для методов с телом. |
| `Таймаут (сек)` | `int` | Таймаут одной попытки. |
| `Максимум попыток` | `int` | Сколько раз повторять запрос. |
| `Задержка (мс)` | `int` | Базовая пауза между попытками. |
| `Стратегия задержки` | `HttpRetryDelayStrategy` | `Fixed`, `Linear`, `Exponential`. |
| `Коды для повтора` | `string` | Список HTTP-кодов через запятую, например `500,502,503,504,408,429`. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Код ответа` | `int` | Код последней попытки. |
| `Тело ответа` | `string` | Ответ последней попытки. |
| `Заголовки ответа (JSON)` | `string` | Заголовки последнего ответа. |
| `Количество попыток` | `int` | Сколько попыток реально было выполнено. |

## Примечания

- Для идемпотентных `GET` и `PUT` повторы обычно безопаснее, чем для `POST`.
- Если API возвращает `429 Too Many Requests`, стратегия `Exponential` обычно даёт лучший результат.
