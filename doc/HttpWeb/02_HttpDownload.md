# HTTP: Скачать файл

> **Группа:** MIA → HTTP / Web  
> **Класс:** `HttpDownloadBack`

## Назначение

Скачивает файл по HTTP/HTTPS потоковым способом. Подходит для больших файлов, умеет сохранять по указанному пути, перезаписывать существующие файлы и возвращать фактический размер загрузки.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `URL` | `string` | Адрес файла. |
| `Путь сохранения` | `string` | Может быть путём к файлу или к каталогу. |
| `Заголовки (JSON)` | `string` | Дополнительные заголовки, например `Authorization`. |
| `Таймаут (сек)` | `int` | Время ожидания загрузки. |
| `Перезаписать` | `bool` | Разрешает замену существующего файла. |
| `Размер буфера` | `int` | Размер буфера чтения, по умолчанию 8192. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Путь к файлу` | `string` | Итоговый путь сохранённого файла. |
| `Размер файла` | `long` | Размер в байтах. |
| `Код ответа` | `int` | HTTP status code. |
| `Успешно` | `bool` | Признак успешной загрузки. |

## Примечания

- Если в `Путь сохранения` передана папка, имя файла определяется автоматически.
- SSL и клиентские сертификаты наследуются из общего HTTP-базового класса так же, как в обычном HTTP-запросе.
