# HTTP: Пакетные запросы

> **Группа:** MIA → HTTP / Web  
> **Класс:** `HttpBatchBack`

## Назначение

Выполняет набор HTTP-запросов из `DataTable`. Поддерживает ограничение параллелизма, остановку на первой ошибке и возврат итоговой таблицы результатов.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Таблица запросов` | `DataTable` | Набор запросов. Ключевая колонка `Url`, остальные зависят от сценария. |
| `Макс. параллельных` | `int` | Ограничивает число одновременно выполняемых запросов. |
| `Остановить при ошибке` | `bool` | Прерывает обработку при первой ошибке. |
| `Таймаут (сек)` | `int` | Общий таймаут выполнения набора. |
| `Игнорировать ошибки SSL` | `bool` | Для тестовых сред. |

## Формат входной таблицы

Поддерживаются колонки:
- `Url` — обязательно
- `Method` — опционально, по умолчанию `GET`
- `Headers` — JSON-строка заголовков
- `Body` — тело запроса
- `ContentType` — content type тела

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Таблица результатов` | `DataTable` | Результаты по каждой строке: `Index`, `Url`, `StatusCode`, `Success`, `Response`, `Error`. |
| `Успешных` | `int` | Количество успешных запросов. |
| `Ошибок` | `int` | Количество неуспешных запросов. |

## Примечания

- Параллелизм ограничен сверху, что помогает не перегружать внешнее API.
- Если важен строгий порядок выполнения, задавайте `Макс. параллельных = 1`.
