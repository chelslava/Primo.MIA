# Webhook: Отправить

> **Группа:** MIA → HTTP / Web  
> **Класс:** `WebhookBack`

## Назначение

Отправляет `POST` на URL вебхука с JSON-payload. Поддерживает два способа формирования тела: готовый JSON или шаблон с плейсхолдерами и словарём переменных.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `URL вебхука` | `string` | Адрес входящего webhook endpoint. |
| `Payload (JSON)` | `string` | Готовое тело запроса. Игнорируется, если задан шаблон. |
| `Шаблон` | `string` | JSON-шаблон с плейсхолдерами `{{Ключ}}`. |
| `Переменные шаблона` | `Dictionary<string,string>` | Значения для подстановки в шаблон. |
| `Content-Type` | `string` | Обычно `application/json`. |
| `Доп. заголовки` | `Dictionary<string,string>` | Дополнительные HTTP-заголовки. |
| `Таймаут (сек)` | `int` | Таймаут одной попытки. |
| `Повторных попыток` | `int` | Сколько повторов сделать при ошибке. |
| `Пауза между попытками (мс)` | `int` | Пауза между повторными попытками. |
| `Игнорировать ошибки SSL` | `bool` | Для тестовых сред. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Код ответа` | `int` | HTTP status code. |
| `Тело ответа` | `string` | Ответ вебхука. |
| `Успешно (2xx)` | `bool` | `true`, если сервер вернул код `2xx`. |
| `Попыток выполнено` | `int` | Фактическое число попыток. |

## Примечания

- Если задан `Шаблон`, он имеет приоритет над `Payload`.
- Повторы выполняются при сетевых ошибках и ответах `5xx`.
- Активность хорошо подходит для Slack, Teams, Discord, Jira и похожих входящих webhook-интеграций.
