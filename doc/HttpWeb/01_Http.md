# HTTP: Запрос

> **Группа:** MIA → HTTP / Web  
> **Класс:** `HttpBack`

## Назначение

Выполняет одиночный HTTP-запрос к API или веб-сервису. Поддерживает основные методы, JSON-заголовки, тело запроса, клиентские сертификаты и игнорирование SSL-ошибок для тестовых сред.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `URL` | `string` | Полный адрес запроса. |
| `Метод` | `HttpMethodType` | Обычно `GET`, `POST`, `PUT`, `DELETE`, `PATCH`. |
| `Заголовки (JSON)` | `string` | JSON-объект с заголовками запроса. |
| `Тело запроса` | `string` | Полезно для `POST`, `PUT`, `PATCH`. |
| `Таймаут (сек)` | `int` | Максимальное время ожидания ответа. |
| `Использовать сертификат` | `bool` | Включает клиентский `.pfx` сертификат. |
| `Путь к сертификату` | `string` | Полный путь к `.pfx`. |
| `Пароль сертификата` | `string` | Пароль от сертификата. |
| `Игнорировать ошибки SSL` | `bool` | Только для тестовых сред. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Код ответа` | `int` | HTTP status code. |
| `Тело ответа` | `string` | Ответ сервера. |
| `Заголовки ответа (JSON)` | `string` | Заголовки ответа в JSON-виде. |

## Пример

```text
URL: "https://api.example.com/orders/42"
Метод: GET
Заголовки (JSON): "{\"Authorization\":\"Bearer ...\"}"
Таймаут (сек): 30
```
