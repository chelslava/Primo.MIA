# HTTP: Загрузить файл

> **Группа:** MIA → HTTP / Web  
> **Класс:** `HttpUploadBack`

## Назначение

Отправляет файл на сервер через `multipart/form-data`. Подходит для API загрузки документов, изображений и вложений, поддерживает дополнительные поля формы и произвольные заголовки.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `URL` | `string` | Endpoint для загрузки. |
| `Путь к файлу` | `string` | Локальный путь к файлу. |
| `Имя поля` | `string` | Имя `form-data` поля для файла, обычно `file`. |
| `Доп. поля (JSON)` | `string` | JSON с дополнительными полями формы. |
| `Заголовки (JSON)` | `string` | HTTP-заголовки запроса. |
| `Таймаут (сек)` | `int` | Верхняя граница ожидания ответа. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Код ответа` | `int` | HTTP status code. |
| `Тело ответа` | `string` | Ответ сервера. |
| `Заголовки ответа (JSON)` | `string` | Заголовки ответа. |
| `Успешно` | `bool` | `true`, если загрузка завершилась без ошибки. |

## Примечания

- Для нескольких файлов за один вызов нужно либо использовать API, принимающее массив, либо вызывать активность в цикле.
- Если сервер требует токен авторизации, передайте его через `Заголовки (JSON)`.
