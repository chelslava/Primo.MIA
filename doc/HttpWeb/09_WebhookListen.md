# Webhook: Получить

> **Группа:** MIA → HTTP / Web  
> **Класс:** `WebhookListenBack`

## Назначение

Поднимает локальный `HttpListener`, ждёт один входящий HTTP-запрос и возвращает его тело, заголовки, метод и query-параметры. После первого обработанного запроса активность завершается.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `URL-префикс` | `string` | Например `http://localhost:8080/webhook/`. Обязательно со слешем в конце. |
| `Таймаут ожидания (сек)` | `int` | Максимальное время ожидания запроса. |
| `Разрешённые методы` | `string` | Список через запятую: `POST,PUT`. Пусто — любой метод. |
| `Секретный токен` | `string` | Проверяется по заголовкам запроса. |
| `Код ответа отправителю` | `int` | Код, который вернётся вызывающей стороне. |
| `Тело ответа отправителю` | `string` | Текст или JSON ответа. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Тело запроса` | `string` | Полученное тело входящего запроса. |
| `Заголовки запроса` | `Dictionary<string,string>` | Заголовки входящего запроса. |
| `Метод запроса` | `string` | Например `POST`. |
| `URL запроса` | `string` | Полный адрес с query string. |
| `Query-параметры` | `Dictionary<string,string>` | Query-параметры. |
| `Таймаут истёк` | `bool` | `true`, если запрос не пришёл вовремя. Это не считается ошибкой выполнения. |
| `Токен валиден` | `bool` | Результат проверки секрета. |

## Примечания

- На Windows для некоторых префиксов может потребоваться регистрация URL ACL через `netsh`.
- Активность принимает один запрос и завершается; это не постоянный сервер.
- Удобный паттерн: отправить задачу во внешнюю систему, затем ждать callback этой активностью.
