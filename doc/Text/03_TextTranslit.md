# Текст: Транслитерация

> **Группа:** MIA → Утилиты  
> **Класс:** `TextTranslitBack`

## Назначение

Преобразует текст между кириллицей и латиницей по выбранной схеме транслитерации. Полезно для паспортных данных, логинов, имён файлов и URL.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Входной текст` | `string` | Исходная строка. |
| `Направление` | `TranslitDirection` | `CyrillicToLatin`, `LatinToCyrillic`, `AutoDetect`. |
| `Схема` | `TranslitScheme` | Выбранный стандарт транслитерации. |
| `Сохранять регистр` | `bool` | Сохраняет регистр исходного текста. |
| `Сохранять прочие символы` | `bool` | Оставляет цифры, пробелы и пунктуацию. |
| `В верхний регистр` | `bool` | Приводит результат к верхнему регистру. |
| `В нижний регистр` | `bool` | Приводит результат к нижнему регистру. |
| `Заменить пробелы` | `string` | Символ или строка для замены пробелов. |

## Основные схемы

| Схема | Назначение |
|---|---|
| `GOST7792000` | Официальный российский стандарт. |
| `Passport2013` | Схема загранпаспортов РФ. |
| `ICAOPassport` | Международные машиносчитываемые документы. |
| `ISO9` | Наиболее обратимая схема. |
| `BGN_PCGN` | Географические названия. |
| `Simplified` | Упрощённый ASCII-вариант для логинов, URL и имён файлов. |

## Примечания

- Для обратного направления наиболее предсказуемый результат даёт `ISO9`.
- Для файлов и URL чаще всего подходит `Simplified` вместе с заменой пробелов на `-` или `_`.
