# Текст: Разбор по шаблону

> **Группа:** MIA → Утилиты  
> **Класс:** `TextParseBack`

## Назначение

Извлекает именованные значения из текста по читаемой маске с плейсхолдерами. Удобен, когда хочется разбирать строки без ручного написания регулярных выражений.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Входной текст` | `string` | Строка или многострочный текст для разбора. |
| `Маска` | `string` | Шаблон с плейсхолдерами, например `Счёт №{Номер} от {Дата}`. |
| `Синтаксис маски` | `TemplateSyntax` | Синтаксис плейсхолдеров в маске. |
| `Учитывать регистр` | `bool` | Для литеральной части маски. |
| `Жадный режим` | `bool` | Включает жадный захват вместо ленивого. |
| `Многострочный режим` | `bool` | Разрешает сопоставление через переводы строк. |
| `Все совпадения` | `bool` | Искать все вхождения, а не только первое. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Результат` | `Dictionary<string,string>` | Первое найденное совпадение. |
| `Совпадение найдено` | `bool` | Есть ли совпадение. |
| `Количество совпадений` | `int` | Число найденных вхождений. |
| `Все результаты` | `List<Dictionary<string,string>>` | Заполняется при `Все совпадения = true`. |
| `Скомпилированный паттерн` | `string` | Диагностический regex-паттерн. |

## Примечания

- Если совпадения нет, это не считается ошибкой выполнения: активность возвращает `Совпадение найдено = false`.
- Для большинства шаблонов лучше оставлять ленивый режим, чтобы соседние поля не "съедали" текст друг друга.
