# Текст: Извлечь сущности

> **Группа:** MIA → Утилиты  
> **Класс:** `TextExtractEntitiesBack`

## Назначение

Находит в тексте типовые структурированные данные без ручного написания regex. Поддерживает email, телефоны, даты, суммы, ИНН, СНИЛС, URL, IP, GUID и другие сущности.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Входной текст` | `string` | Текст для анализа. |
| `Типы сущностей` | `string` | Список типов через запятую. Пусто — искать все встроенные типы. |
| `Пользовательский паттерн` | `string` | Regex для типа `Custom`. |
| `Удалять дубликаты` | `bool` | Не возвращать повторяющиеся значения. |
| `Сохранять исходный текст` | `bool` | Хранить исходные, а не только нормализованные значения. |
| `Минимальная уверенность` | `int` | Отсечь слабые совпадения по confidence. |

## Поддерживаемые типы

- `Email`
- `Phone`
- `Date`
- `Money`
- `INN`
- `SNILS`
- `Passport`
- `CarNumber`
- `URL`
- `IP`
- `GUID`
- `Custom`

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Результат` | `Dictionary<string,List<string>>` | Найденные значения, сгруппированные по типам сущностей. |
| `Количество` | `int` | Общее число найденных сущностей. |
| `Найдено` | `bool` | Есть ли хотя бы одно совпадение. |

## Примечания

- Для некоторых типов выполняется дополнительная нормализация: например телефоны приводятся к стандартному виду, ИНН проверяется по контрольным цифрам.
- Если нужен только один конкретный пользовательский шаблон, можно использовать `Custom` вместо набора встроенных типов.
