# Текст: Шаблонизатор

> **Группа:** MIA → Утилиты  
> **Класс:** `TextTemplateBack`

## Назначение

Подставляет значения словаря в текстовый шаблон. Поддерживает несколько синтаксисов плейсхолдеров, чтение шаблона из файла и поведение при отсутствии ключей.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Шаблон` | `string` | Текст с плейсхолдерами. |
| `Переменные` | `Dictionary<string,string>` | Значения для подстановки. |
| `Синтаксис` | `TemplateSyntax` | `DoubleBrace`, `SingleBrace`, `Percent`. |
| `Поведение при отсутствии ключа` | `MissingKeyBehavior` | `LeaveAsIs`, `ReplaceWithEmpty`, `ThrowError`. |
| `Учитывать регистр` | `bool` | Поиск ключей с учётом регистра. |
| `Файл шаблона` | `string` | Если задан, имеет приоритет над полем `Шаблон`. |
| `Кодировка` | `string` | Кодировка файла шаблона. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Результат` | `string` | Итоговая строка после подстановки. |
| `Количество замен` | `int` | Сколько плейсхолдеров было заменено. |
| `Отсутствующие ключи` | `List<string>` | Какие ключи не удалось заполнить. |

## Примечания

- По умолчанию используется синтаксис `{{Ключ}}`, который удобен для JSON и HTML.
- Поддерживаются суффиксы формата, например `{{Сумма:N2}}` или `{{Дата:dd.MM.yyyy}}`.
- Для обратной операции, когда нужно извлечь данные по маске, используйте [02_TextParse.md](02_TextParse.md).
