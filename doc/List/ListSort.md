# ListSort — Список: Сортировка

Активность для сортировки `List<string>` девятью способами в процессах Primo RPA.  
Возвращает новый список — оригинал не изменяется.

---

## Режимы работы

Режим выбирается через свойство **Способ сортировки** (`ListSortMode`):

| Режим | Описание |
|-------|----------|
| `Alphabetical` | A→Z с учётом регистра. Заглавные буквы перед строчными |
| `AlphabeticalDesc` | Z→A с учётом регистра |
| `CaseInsensitive` | A→Z без учёта регистра |
| `CaseInsensitiveDesc` | Z→A без учёта регистра |
| `ByLength` | По длине строки — сначала короткие. При равной длине — по алфавиту |
| `ByLengthDesc` | По длине строки — сначала длинные |
| `Natural` | Числовые части сравниваются как числа: `file2` < `file10` |
| `Reverse` | Обратный порядок текущего списка без пересортировки |
| `Random` | Случайное перемешивание по алгоритму Fisher-Yates |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список** | `List<string>` | Всегда | Входной список для сортировки |
| **Способ сортировки** | `ListSortMode` | Всегда | Алгоритм сортировки |

### Random _(только для режима `Random`)_

| Свойство | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| **Зерно** | `Int32` | *(случайное)* | Фиксированное зерно генератора. Одно зерно → всегда одинаковый результат. Пустое поле — новый порядок при каждом запуске |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Результат** | `List<string>` | Отсортированный список |
| **Количество** | `Int32` | Количество элементов в результате |

---

## Примеры использования

### Режим `Natural`

Настройки активности:
```
Список:           ["file10", "file2", "file1", "file20"]
Способ сортировки: Natural
```

Результат → `Список` = `["file1", "file2", "file10", "file20"]`

> **Сравнение с `Alphabetical`:**
> ```
> Alphabetical → ["file1", "file10", "file2", "file20"]
> Natural      → ["file1", "file2",  "file10", "file20"]
> ```

---

### Режим `ByLength`

Настройки активности:
```
Список:           ["banana", "cat", "apple", "ox"]
Способ сортировки: ByLength
```

Результат → `Список`:
```
["ox", "cat", "apple", "banana"]
```

---

### Режим `Random` с фиксированным зерном

Настройки активности:
```
Список:           ["A", "B", "C", "D", "E"]
Способ сортировки: Random
Зерно:            42
```

Результат → всегда одинаковый порядок при зерне `42`. Для воспроизводимых тестов.

---

### Режим `Reverse`

Настройки активности:
```
Список:           ["первый", "второй", "третий"]
Способ сортировки: Reverse
```

Результат → `Список` = `["третий", "второй", "первый"]`

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список пуст (`[]`) | Возвращает пустой список без ошибки |
| Список содержит `null`-элементы | `null` обрабатывается как `""` |
| Зерно не задано (режим `Random`) | Используется случайное зерно |
