# ListTransform — Список: Преобразование

Активность для трансформации каждого элемента `List<string>`.  
Возвращает новый список той же длины. Дополнительно сообщает сколько элементов реально изменилось.

---

## Режимы работы

Режим выбирается через свойство **Преобразование** (`ListTransformMode`):

| Режим | Группа параметров | Описание |
|-------|------------------|----------|
| `ToUpper` | — | Весь текст в верхний регистр |
| `ToLower` | — | Весь текст в нижний регистр |
| `Trim` | — | Удалить пробелы с обоих краёв |
| `TrimStart` | — | Удалить пробелы слева |
| `TrimEnd` | — | Удалить пробелы справа |
| `Replace` | Replace | Заменить подстроку на другую |
| `RegexReplace` | Replace | Заменить совпадения regex |
| `Prefix` | Prefix/Suffix | Добавить текст перед каждым элементом |
| `Suffix` | Prefix/Suffix | Добавить текст после каждого элемента |
| `Wrap` | Prefix/Suffix | Обернуть: Префикс + элемент + Суффикс |
| `PadLeft` | Pad/Truncate | Дополнить слева до нужной ширины |
| `PadRight` | Pad/Truncate | Дополнить справа до нужной ширины |
| `Truncate` | Pad/Truncate | Обрезать до N символов |
| `RemoveNumbers` | — | Удалить все цифры 0–9 |
| `RemoveNonAlpha` | — | Оставить только буквы, цифры и пробелы |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список** | `List<string>` | Всегда | Входной список для преобразования |
| **Преобразование** | `ListTransformMode` | Всегда | Тип трансформации |

### Replace _(для режимов `Replace` и `RegexReplace`)_

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Найти** | `String` | Всегда | Что искать — строка или regex-паттерн |
| **Заменить на** | `String` | Нет | На что заменить. Пустое значение — удалить найденное |
| **Учитывать регистр** | `Boolean` | Нет | По умолчанию `false` |

### Prefix/Suffix _(для режимов `Prefix`, `Suffix`, `Wrap`)_

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Префикс** | `String` | `Prefix`, `Wrap` | Текст добавляемый перед каждым элементом |
| **Суффикс** | `String` | `Suffix`, `Wrap` | Текст добавляемый после каждого элемента |

### Pad/Truncate _(для режимов `PadLeft`, `PadRight`, `Truncate`)_

| Свойство | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| **Ширина (Pad)** | `Int32` | `10` | Целевая длина строки. Строки длиннее ширины не обрезаются |
| **Символ заполнения** | `String` | `" "` (пробел) | Символ которым дополняется строка |
| **Макс. длина (Truncate)** | `Int32` | `50` | Максимальная длина строки — более длинные обрезаются |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Результат** | `List<string>` | Преобразованный список |
| **Количество** | `Int32` | Количество элементов |
| **Изменилось элементов** | `Int32` | Количество элементов реально изменившихся по сравнению с оригиналом |

## Примеры использования

### Режим `Trim`

Настройки активности:
```
Список:         ["  invoice  ", "  order  ", "  report  "]
Преобразование: Trim
```

Результат → `Список`:
```
["invoice", "order", "report"]
```
`Изменилось элементов` = `3`

---

### Режим `Replace`

Настройки активности:
```
Список:         ["Иванов Иван", "Петров Пётр", "Сидоров Сидор"]
Преобразование: Replace
Найти:          " "
Заменить на:    "_"
```

Результат → `Список`:
```
["Иванов_Иван", "Петров_Пётр", "Сидоров_Сидор"]
```

---

### Режим `RegexReplace`

Настройки активности:
```
Список:         ["Тел: +7(999)123-45-67", "Факс: +7(495)000-00-00"]
Преобразование: RegexReplace
Найти:          "\D"
Заменить на:    ""
```

Результат → `Список` (только цифры):
```
["79991234567", "74950000000"]
```

---

### Режим `Wrap`

Настройки активности:
```
Список:         ["apple", "banana", "cherry"]
Преобразование: Wrap
Префикс:        "["
Суффикс:        "]"
```

Результат → `Список`:
```
["[apple]", "[banana]", "[cherry]"]
```

---

### Режим `PadLeft`

Настройки активности:
```
Список:            ["1", "12", "123", "1234"]
Преобразование:    PadLeft
Ширина (Pad):      5
Символ заполнения: "0"
```

Результат → `Список`:
```
["00001", "00012", "00123", "01234"]
```

---

### Режим `Truncate`

Настройки активности:
```
Список:           ["Очень длинное название документа", "Краткий заголовок", "ОК"]
Преобразование:   Truncate
Макс. длина:      15
```

Результат → `Список`:
```
["Очень длинное н", "Краткий заголово", "ОК"]
```
`Изменилось элементов` = `2` (третий элемент короче 15 — не изменился)

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список пуст (`[]`) | Возвращает пустой список, `Изменилось` = 0 |
| Поле **Найти** пусто для `Replace` / `RegexReplace` | Ошибка валидации |
| Некорректный Regex в `RegexReplace` | Исключение с описанием ошибки паттерна |
| `null`-элементы | Обрабатываются как `""` |
| Строка уже нужной ширины (`PadLeft`/`PadRight`) | Не изменяется, учитывается в `Изменилось` как 0 |
