# ListFilter — Список: Фильтрация

Активность для разделения `List<string>` на два списка: **прошедшие** условие и **не прошедшие** (остаток).  
Оба списка заполняются всегда — ни один элемент не теряется.

---

## Режимы работы

Режим выбирается через свойство **Условие фильтрации** (`ListFilterMode`):

| Режим | Паттерн | Описание |
|-------|---------|----------|
| `Contains` | Да | Строка содержит подстроку |
| `NotContains` | Да | Строка не содержит подстроку |
| `StartsWith` | Да | Строка начинается с подстроки |
| `EndsWith` | Да | Строка заканчивается подстрокой |
| `ExactMatch` | Да | Полное совпадение строки |
| `Regex` | Да | Строка соответствует регулярному выражению |
| `NotRegex` | Да | Строка не соответствует регулярному выражению |
| `NotEmpty` | Нет | Непустые строки — не `null`, не `""`, не только пробелы |
| `EmptyOnly` | Нет | Только пустые — `null`, `""`, строки из одних пробелов |
| `LengthRange` | Нет | Длина строки в диапазоне \[Мин, Макс\] включительно |
| `NumericOnly` | Нет | Строки являющиеся числами — целыми или дробными |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список** | `List<string>` | Всегда | Входной список для фильтрации |
| **Условие фильтрации** | `ListFilterMode` | Всегда | Правило отбора элементов |
| **Паттерн / Подстрока** | `String` | Текстовые и Regex режимы | Строка сравнения или регулярное выражение |
| **Учитывать регистр** | `Boolean` | Нет | По умолчанию `false` — `"Hello"` содержит `"hello"` |

### LengthRange _(только для режима `LengthRange`)_

| Свойство | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| **Мин. длина** | `Int32` | `0` | Минимальная длина строки включительно |
| **Макс. длина** | `Int32` | `100` | Максимальная длина строки включительно |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Прошли фильтр** | `List<string>` | Элементы удовлетворяющие условию |
| **Не прошли фильтр** | `List<string>` | Элементы не удовлетворяющие условию |
| **Кол-во прошедших** | `Int32` | Размер списка прошедших |
| **Кол-во отсеянных** | `Int32` | Размер списка отсеянных |

## Примеры использования

### Режим `StartsWith`

Настройки активности:
```
Список:            ["apple", "APRICOT", "banana", "cherry", ""]
Условие:           StartsWith
Паттерн:           "ap"
Учитывать регистр: false
```

Результат:
```
Прошли фильтр:    ["apple", "APRICOT"]       (кол-во: 2)
Не прошли фильтр: ["banana", "cherry", ""]   (кол-во: 3)
```

---

### Режим `Regex`

Настройки активности:
```
Список:  ["ivan.petrov@mail.ru", "not-an-email", "test@company.com", "12345"]
Условие: Regex
Паттерн: "^[^@\s]+@[^@\s]+\.[^@\s]+$"
```

Результат:
```
Прошли фильтр:    ["ivan.petrov@mail.ru", "test@company.com"]
Не прошли фильтр: ["not-an-email", "12345"]
```

---

### Режим `LengthRange`

Настройки активности:
```
Список:     ["ok", "yes", "no", "maybe", "absolutely"]
Условие:    LengthRange
Мин. длина: 2
Макс. длина: 4
```

Результат:
```
Прошли фильтр:    ["ok", "yes", "no", "maybe"]
Не прошли фильтр: ["absolutely"]
```

---

### Режим `NumericOnly`

Настройки активности:
```
Список:  ["10", "abc", "3.14", "", "-5", "1,5", "text123"]
Условие: NumericOnly
```

Результат:
```
Прошли фильтр:    ["10", "3.14", "-5", "1,5"]   (точка и запятая поддерживаются)
Не прошли фильтр: ["abc", "", "text123"]
```

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список пуст (`[]`) | Оба выходных списка пусты, счётчики = 0 |
| Паттерн пуст для текстовых режимов | Ошибка валидации — паттерн обязателен |
| Некорректный Regex | Исключение с описанием ошибки паттерна |
| `null`-элементы в списке | Обрабатываются как `""` |
