# ListInspect — Список: Анализ

Активность для полной диагностики `List<string>` за один проход в процессах Primo RPA.  
Не изменяет входной список. Все метрики вычисляются одновременно.

---

## Режимы работы

Активность не имеет переключаемых режимов — всегда вычисляются все метрики.  
Поисковые выходы заполняются только если задано свойство **Искомое значение**.

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список** | `List<string>` | Всегда | Анализируемый список |
| **Учитывать регистр** | `Boolean` | Нет | Влияет на подсчёт уникальных и на поиск. По умолчанию `false` |

### Поиск _(заполняются если задано Искомое значение)_

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Искомое значение** | `String` | Нет | Значение для поиска в списке. Если не задано — все поисковые выходы равны `false`, `-1`, `[]`, `0` |

---

## Выходные параметры

### Статистика

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Всего элементов** | `Int32` | Общее количество элементов включая пустые |
| **Уникальных** | `Int32` | Количество уникальных непустых значений с учётом флага **Учитывать регистр** |
| **Пустых** | `Int32` | Количество `null`, `""` и строк состоящих только из пробелов |
| **Есть дубликаты** | `Boolean` | `true` если хотя бы одно значение встречается более одного раза |
| **Дублирующиеся значения** | `List<string>` | Список значений встречающихся более одного раза, отсортированный по алфавиту |

### Длины строк

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Мин. длина** | `Int32` | Длина кратчайшей строки. Пустая строка = 0 |
| **Макс. длина** | `Int32` | Длина длиннейшей строки |
| **Средняя длина** | `Double` | Среднее арифметическое длин всех строк |

### Поиск _(заполняются только если задано Искомое значение)_

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Найдено** | `Boolean` | Присутствует ли искомое значение в списке |
| **Первый индекс** | `Int32` | Индекс первого вхождения. `-1` если не найдено. Нумерация с `0` |
| **Все индексы** | `List<int>` | Индексы всех вхождений искомого значения |
| **Кол-во вхождений** | `Int32` | Сколько раз искомое значение встречается в списке |

---

## Примеры использования

### Анализ статистики и дубликатов

Настройки активности:
```
Список:            ["apple", "Banana", "apple", "Cherry", "banana", ""]
Учитывать регистр: false
Искомое значение:  (не задано)
```

Результат — Статистика:
```
Всего элементов:   6
Уникальных:        3     (apple, banana, cherry — без учёта регистра)
Пустых:            1
Есть дубликаты:    true
Дублирующиеся:     ["apple", "banana"]
```

Результат — Длины строк:
```
Мин. длина:        0     (пустая строка)
Макс. длина:       6     ("Banana", "Cherry")
Средняя длина:     4.17
```

---

### Поиск элемента

Настройки активности:
```
Список:            ["apple", "Banana", "apple", "Cherry", "banana", ""]
Учитывать регистр: false
Искомое значение:  "apple"
```

Результат — Поиск:
```
Найдено:           true
Первый индекс:     0
Все индексы:       [0, 2]
Кол-во вхождений:  2
```

---

### Влияние флага «Учитывать регистр»

Настройки активности:
```
Список: ["Apple", "apple", "APPLE", "Banana"]
Искомое значение: "apple"
```

| Учитывать регистр | Уникальных | Вхождений "apple" | Найдено |
|:-----------------:|:----------:|:-----------------:|:-------:|
| `false` | `2` (apple, banana) | `3` | `true` |
| `true` | `4` (Apple, apple, APPLE, Banana) | `1` | `true` |

---

### Анализ числового списка

Настройки активности:
```
Список:            ["10", "20", "10", "30", "20", "40"]
Учитывать регистр: false
Искомое значение:  "10"
```

Результат:
```
Всего:             6
Уникальных:        4    (10, 20, 30, 40)
Пустых:            0
Есть дубликаты:    true
Дублирующиеся:     ["10", "20"]

Мин. длина:        2    ("10", "20", "30", "40")
Макс. длина:       2
Средняя длина:     2.0

Найдено:           true
Первый индекс:     0
Все индексы:       [0, 2]
Кол-во вхождений:  2
```

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список пуст (`[]`) | Все числовые выходы = `0`, булевы = `false`, списки = `[]` |
| Искомое значение не задано | Поисковые выходы: `Найдено`=`false`, `Первый индекс`=`-1`, `Все индексы`=`[]`, `Кол-во`=`0` |
| `null`-элементы в списке | Считаются как пустые строки `""` |
