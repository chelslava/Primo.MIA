# ListAggregate — Список: Агрегация

Активность для вычисления одного агрегатного значения из всего `List<string>`.  
Числовые функции игнорируют нечисловые строки. Поддерживаются точка и запятая как разделитель дробной части.

---

## Режимы работы

Режим выбирается через свойство **Агрегатная функция** (`ListAggregateMode`):

| Режим | Выходное свойство | Описание |
|-------|------------------|----------|
| `Count` | Числовой результат | Общее количество элементов включая пустые |
| `CountDistinct` | Числовой результат | Количество уникальных непустых элементов |
| `CountNonEmpty` | Числовой результат | Количество непустых элементов |
| `Sum` | Числовой результат | Сумма числовых значений. Нечисловые игнорируются |
| `Min` | Числовой результат | Минимальное числовое значение |
| `Max` | Числовой результат | Максимальное числовое значение |
| `Average` | Числовой результат | Среднее арифметическое числовых значений |
| `ShortestString` | Строковый результат | Кратчайшая строка по длине. При равной длине — первая по алфавиту |
| `LongestString` | Строковый результат | Длиннейшая строка по длине |
| `Join` | Строковый результат | Конкатенация всех элементов через разделитель |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список** | `List<string>` | Всегда | Входной список |
| **Агрегатная функция** | `ListAggregateMode` | Всегда | Тип вычисления |

### Join _(только для режима `Join`)_

| Свойство | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| **Разделитель** | `String` | `", "` | Строка вставляемая между элементами |

---

## Выходные параметры

| Свойство | Тип | Режимы | Описание |
|----------|-----|--------|----------|
| **Строковый результат** | `String` | `Join`, `ShortestString`, `LongestString` | Строковый итог |
| **Числовой результат** | `Double` | `Count`, `CountDistinct`, `CountNonEmpty`, `Sum`, `Min`, `Max`, `Average` | Числовой итог |
| **Кол-во числовых** | `Int32` | Все | Количество элементов успешно распознанных как числа |

---

## Примеры использования

### Числовые функции

Настройки активности:
```
Список: ["10", "abc", "20.5", "", "30", "1,5"]
```

Результаты по функциям:
```
Count           → 6     (все элементы)
CountNonEmpty   → 5     (без пустой строки)
CountDistinct   → 5     (все уникальные непустые)
Sum             → 62    (10 + 20.5 + 30 + 1.5)
Average         → 15.5  (62 / 4, числовых: 4)
Min             → 1.5
Max             → 30
Кол-во числовых → 4     ("abc" и "" — не числа)
```

---

### Режим `Join`

Настройки активности:
```
Список:      ["Иванов", "Петров", "Сидоров"]
Функция:     Join
Разделитель: " | "
```

Результат → `Строковый результат` = `"Иванов | Петров | Сидоров"`

---

### Режим `ShortestString` / `LongestString`

Настройки активности:
```
Список:   ["кот", "слон", "ёж", "тигр"]
Функция:  ShortestString
```

Результат → `Строковый результат` = `"ёж"`

```
Функция:  LongestString
```

Результат → `Строковый результат` = `"слон"` (или `"тигр"` — у обоих 4 символа, выбирается первый по алфавиту)

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список пуст | `Count` = 0, остальные числовые = 0, строковые = `""` |
| Нет числовых элементов для `Sum`/`Min`/`Max`/`Average` | Числовой результат = 0, `Кол-во числовых` = 0 |
| `null`-элементы | Обрабатываются как `""` |
