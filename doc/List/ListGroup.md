# ListGroup — Список: Группировка

Активность для группировки элементов `List<string>` по выбранному ключу.  
Возвращает `Dictionary<string, List<string>>` — ключ группы → список элементов.  
Дополнительно всегда возвращает карту частот всех элементов.

---

## Режимы работы

Режим выбирается через свойство **Способ группировки** (`ListGroupMode`):

| Режим | Ключ группы | Описание |
|-------|-------------|----------|
| `ByFirstChar` | Первый символ в верхнем регистре | `"apple"` → группа `"A"` |
| `ByLength` | Длина строки | `"cat"` → группа `"3"` |
| `ByPrefix` | Первые N символов | `"report_2025"` → группа `"rep"` при N=3 |
| `ByRegexGroup` | Значение первой capture-группы regex | Гибкая группировка по любому паттерну |
| `TopFrequent` | `"значение (N×)"` | Топ N самых часто встречающихся значений |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список** | `List<string>` | Всегда | Входной список для группировки |
| **Способ группировки** | `ListGroupMode` | Всегда | Правило формирования ключа группы |

### Параметры _(зависят от режима)_

| Свойство | Тип | По умолчанию | Режим | Описание |
|----------|-----|--------------|-------|----------|
| **Длина префикса** | `Int32` | `3` | `ByPrefix` | Количество начальных символов образующих ключ группы |
| **Regex паттерн** | `String` | — | `ByRegexGroup` | Regex с capture-группой `(...)`. Значение группы 1 становится ключом. Строки без совпадений попадают в группу `"(нет совпадения)"` |
| **Топ N** | `Int32` | `10` | `TopFrequent` | Количество самых частых значений |

---

## Выходные параметры

| Свойство | Тип | Режимы | Описание |
|----------|-----|--------|----------|
| **Группы** | `Dictionary<string, List<string>>` | Все | Ключ группы → список элементов этой группы |
| **Количество групп** | `Int32` | Все | Количество групп в результате |
| **Частота элементов** | `Dictionary<string, int>` | Все | Каждый уникальный элемент → количество его вхождений в исходном списке |

---

## Примеры использования

### Режим `ByFirstChar`

Настройки активности:
```
Список:           ["apple", "Avocado", "banana", "cherry", "Blueberry"]
Способ:           ByFirstChar
```

Результат → `Группы`:
```
"A" → ["apple", "Avocado"]
"B" → ["banana", "Blueberry"]
"C" → ["cherry"]
```
`Количество групп` = `3`

---

### Режим `ByLength`

Настройки активности:
```
Список:  ["кот", "слон", "ёж", "тигр", "лев"]
Способ:  ByLength
```

Результат → `Группы`:
```
"2" → ["ёж"]
"3" → ["кот", "лев"]
"4" → ["слон", "тигр"]
```

---

### Режим `ByPrefix`

Настройки активности:
```
Список:          ["report_2024_01", "report_2024_02", "invoice_001", "invoice_002", "act_01"]
Способ:          ByPrefix
Длина префикса:  3
```

Результат → `Группы`:
```
"rep" → ["report_2024_01", "report_2024_02"]
"inv" → ["invoice_001", "invoice_002"]
"act" → ["act_01"]
```

---

### Режим `ByRegexGroup`

Настройки активности:
```
Список:   ["order_001_2025", "order_002_2024", "invoice_001_2025", "act_003_2025"]
Способ:   ByRegexGroup
Паттерн:  "^(\w+)_\d+"
```

Результат → `Группы`:
```
"order"   → ["order_001_2025", "order_002_2024"]
"invoice" → ["invoice_001_2025"]
"act"     → ["act_003_2025"]
```

---

### Режим `TopFrequent`

Настройки активности:
```
Список:  ["яблоко", "груша", "яблоко", "слива", "яблоко", "груша", "абрикос"]
Способ:  TopFrequent
Топ N:   3
```

Результат → `Группы`:
```
"яблоко (3×)" → ["яблоко", "яблоко", "яблоко"]
"груша (2×)"  → ["груша", "груша"]
"слива (1×)"  → ["слива"]
```
`Частота элементов` = `{ яблоко:3, груша:2, слива:1, абрикос:1 }` ← для всех режимов

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список пуст | Возвращает пустой словарь, `Количество групп` = 0 |
| Паттерн не задан для `ByRegexGroup` | Ошибка валидации |
| Некорректный Regex | Исключение с описанием ошибки паттерна |
| Строка без совпадения regex | Попадает в группу `"(нет совпадения)"` |
| Пустая строка в списке | Попадает в группу `"(пусто)"` |
