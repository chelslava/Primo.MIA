# ListSet — Список: Теория множеств

Активность для выполнения операций над двумя `List<string>` как над математическими множествами.  
Дубликаты внутри одного списка не влияют на результат — каждый уникальный элемент учитывается один раз.

---

## Режимы работы

Режим выбирается через свойство **Операция** (`ListSetOperation`):

| Режим | Формула | Нужен Список B | Описание |
|-------|---------|:--------------:|----------|
| `Union` | A ∪ B | Да | Все уникальные элементы обоих списков |
| `Intersect` | A ∩ B | Да | Только элементы присутствующие в обоих списках |
| `Except` | A ∖ B | Да | Элементы из A которых нет в B |
| `ExceptReverse` | B ∖ A | Да | Элементы из B которых нет в A |
| `SymmetricDiff` | (A ∪ B) ∖ (A ∩ B) | Да | Элементы присутствующие только в одном из списков |
| `Distinct` | уникальные(A) | Нет | Уникальные элементы первого списка — дубликаты удаляются |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список A** | `List<string>` | Всегда | Первое множество |
| **Список B** | `List<string>` | Все операции кроме `Distinct` | Второе множество |
| **Операция** | `ListSetOperation` | Всегда | Тип операции над множествами |
| **Учитывать регистр** | `Boolean` | Нет | По умолчанию `false` — `"Apple"` и `"apple"` считаются одним элементом |

---

## Выходные параметры

| Свойство | Тип | Описание |
|----------|-----|----------|
| **Результат** | `List<string>` | Результирующее множество |
| **Количество** | `Int32` | Количество элементов в результате |

---

## Примеры использования

### Все операции на одних данных

Настройки:
```
Список A: ["apple", "banana", "cherry"]
Список B: ["banana", "cherry", "date"]
```

Результаты по операциям:
```
Union:         ["apple", "banana", "cherry", "date"]   (4 элемента)
Intersect:     ["banana", "cherry"]                    (2 элемента)
Except:        ["apple"]                               (1 элемент)
ExceptReverse: ["date"]                                (1 элемент)
SymmetricDiff: ["apple", "date"]                       (2 элемента)
```

---

### Режим `Distinct` — удаление дубликатов

Настройки активности:
```
Список A:  ["яблоко", "груша", "яблоко", "ГРУША", "слива", "яблоко"]
Операция:  Distinct
Регистр:   false
```

Результат → `Список`:
```
["яблоко", "груша", "слива"]   (3 элемента)
```

---

### Режим `SymmetricDiff` — элементы только в одном списке

Применяется для поиска **расхождений** между двумя наборами данных.

Настройки активности:
```
Список A (план):   ["Иванов", "Петров", "Сидоров", "Козлов"]
Список B (факт):   ["Иванов", "Сидоров", "Новиков"]
Операция:          SymmetricDiff
```

Результат → `Список` (кто есть только в одном):
```
["Петров", "Козлов", "Новиков"]
```

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Список A пуст | Возвращает элементы только из B (для `Union`) или пустой список |
| Список B пуст | Возвращает копию A (для `Union`, `Except`) или пустой список |
| Список B не задан для `Distinct` | Операция выполняется корректно — B не нужен |
| Список B не задан для других операций | Ошибка валидации |
