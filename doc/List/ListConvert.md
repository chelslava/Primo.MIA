# ListConvert — Список: Конвертация

Активность для конвертации `List<string>` в различные структуры данных и обратно.  
В зависимости от режима заполняются разные выходные свойства.

---

## Режимы работы

Режим выбирается через свойство **Тип конвертации** (`ListConvertMode`):

| Режим | Вход | Выход | Описание |
|-------|------|-------|----------|
| `ToDict` | `List<string>` | `Dictionary<string,string>` | Список строк `"ключ=значение"` в словарь |
| `ToDictIndexed` | `List<string>` | `Dictionary<string,string>` | Список в словарь с числовыми ключами `"0"`, `"1"`... |
| `ToCSVRow` | `List<string>` | `String` | Список в одну CSV-строку с кавычками |
| `FromCSVRow` | `String` | `List<string>` | CSV-строка в список. Поддержка RFC 4180 |
| `ZipToDict` | `List<string>` + `List<string>` | `Dictionary<string,string>` | Zip двух списков в словарь |
| `Flatten` | `List<string>` | `List<string>` | Разбить каждый элемент по разделителю → плоский список |
| `Chunk` | `List<string>` | `List<string>` (первый батч) | Разбить список на подсписки по N элементов |

---

## Входные параметры

### Основные

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список** | `List<string>` | Все режимы кроме `FromCSVRow` | Входной список |
| **Тип конвертации** | `ListConvertMode` | Всегда | Целевой формат преобразования |

### ZipToDict _(только для режима `ZipToDict`)_

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Список значений (Zip)** | `List<string>` | Всегда | Второй список — становится значениями словаря. Должен быть той же длины что и первый |

### Параметры

| Свойство | Тип | По умолчанию | Режимы | Описание |
|----------|-----|--------------|--------|----------|
| **Разделитель** | `String` | `"="` | `ToDict`, `Flatten` | Для `ToDict` — разделитель ключа и значения. Для `Flatten` — разделитель разбиения элемента |
| **Размер батча** | `Int32` | `10` | `Chunk` | Количество элементов в одном подсписке |

### CSV _(только для режима `FromCSVRow`)_

| Свойство | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **CSV строка (вход)** | `String` | Всегда | Входная CSV-строка для разбора. Поддерживает RFC 4180: кавычки и экранирование `""` |

---

## Выходные параметры

| Свойство | Тип | Режимы | Описание |
|----------|-----|--------|----------|
| **Список** | `List<string>` | `FromCSVRow`, `Flatten`, `Chunk` | Для `Chunk` — только первый батч |
| **Словарь** | `Dictionary<string,string>` | `ToDict`, `ToDictIndexed`, `ZipToDict` | Результирующий словарь |
| **Строка** | `String` | `ToCSVRow` | CSV-строка с кавычками |
| **Количество** | `Int32` | Все | Для `Chunk` — количество батчей, для остальных — количество элементов |

---

## Примеры использования

### Режим `ToDict`

Настройки активности:
```
Список:      ["host=localhost", "port=5432", "name=mydb", "timeout=30"]
Режим:       ToDict
Разделитель: "="
```

Результат → `Словарь`:
```
host    → "localhost"
port    → "5432"
name    → "mydb"
timeout → "30"
```

---

### Режим `ToDictIndexed`

Настройки активности:
```
Список: ["Иванов", "Петров", "Сидоров"]
Режим:  ToDictIndexed
```

Результат → `Словарь`:
```
"0" → "Иванов"
"1" → "Петров"
"2" → "Сидоров"
```

---

### Режим `ToCSVRow`

Настройки активности:
```
Список: ["Иванов", "Иван", "Менеджер", "Москва, Тверская 1"]
Режим:  ToCSVRow
```

Результат → `Строка`:
```
"Иванов","Иван","Менеджер","Москва, Тверская 1"
```

> Значения содержащие запятую автоматически оборачиваются в кавычки. Внутренние кавычки экранируются удвоением.

---

### Режим `FromCSVRow`

Настройки активности:
```
CSV строка: "Иванов","Иван","Менеджер","Москва, Тверская 1"
Режим:      FromCSVRow
```

Результат → `Список`:
```
["Иванов", "Иван", "Менеджер", "Москва, Тверская 1"]
```

Пример с экранированными кавычками (RFC 4180):
```
CSV строка: "значение","со ""кавычками"" внутри",plain
Результат:  ["значение", 'со "кавычками" внутри', "plain"]
```

---

### Режим `ZipToDict`

Настройки активности:
```
Список (ключи):    ["host", "port", "name"]
Список значений:   ["localhost", "5432", "mydb"]
Режим:             ZipToDict
```

Результат → `Словарь`:
```
host → "localhost"
port → "5432"
name → "mydb"
```

---

### Режим `Flatten`

Настройки активности:
```
Список:      ["яблоко;груша;слива", "банан;апельсин", "виноград"]
Режим:       Flatten
Разделитель: ";"
```

Результат → `Список`:
```
["яблоко", "груша", "слива", "банан", "апельсин", "виноград"]
```
`Количество` = `6`

---

### Режим `Chunk`

Настройки активности:
```
Список:        ["A","B","C","D","E","F","G"]
Режим:         Chunk
Размер батча:  3
```

Результат:
```
Количество (батчей): 3
Список (1-й батч):   ["A", "B", "C"]
```

Батчи:
```
Батч 1: ["A", "B", "C"]   ← записывается в Список
Батч 2: ["D", "E", "F"]
Батч 3: ["G"]
```

> Для обхода всех батчей используйте `Chunk` совместно с активностью **Список: Срез** (режим `Page`).

---

## Обработка ошибок

| Ситуация | Поведение |
|----------|-----------|
| Списки разной длины для `ZipToDict` | Исключение с указанием длин обоих списков |
| Список не задан для `FromCSVRow` | Не требуется — используется `CSV строка (вход)` |
| `CSV строка (вход)` не задана для `FromCSVRow` | Ошибка валидации |
| Элемент без разделителя в `ToDict` | Элемент пропускается |
| Дублирующиеся ключи в `ToDict` / `ZipToDict` | Сохраняется последнее значение |
