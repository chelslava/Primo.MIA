# Словарь: Удалить ключ

> **Группа:** MIA → Словари  
> **Класс:** `DictionaryRemoveKeyBack`  
> **Тип результата:** `Dictionary<string, string>`

## Назначение

Возвращает **новую копию** `Dictionary<string, string>` без указанного ключа. Оригинальный словарь **не изменяется**. Поведение при отсутствии ключа настраивается.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| **Словарь** | `Dictionary<string, string>` | Да | — | Входной словарь |
| **Ключ** | `string` | Да | — | Ключ для удаления |
| **Ошибка если не найдено** | `bool` | Нет | `false` | Поведение если ключ отсутствует |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Результирующий словарь** | `Dictionary<string, string>` | Копия словаря без удалённого ключа |
| **Ключ удалён** | `bool` | `true` — ключ существовал и был удалён, `false` — ключа не было |

---

## Режимы поведения при отсутствии ключа

### `Ошибка если не найдено = false` *(по умолчанию)*
Возвращает полную копию словаря без изменений. `Ключ удалён = false`. Выполнение продолжается.

```
Словарь:                   { "a": "1", "b": "2" }
Ключ:                      "c"   ← отсутствует
Ошибка если не найдено:    false
→ Результат:    { "a": "1", "b": "2" }   ← без изменений
→ Ключ удалён:  false
```

### `Ошибка если не найдено = true`
Выбрасывает `KeyNotFoundException` с сообщением содержащим список доступных ключей словаря.

```
Словарь:                   { "a": "1", "b": "2" }
Ключ:                      "c"
Ошибка если не найдено:    true
→ Ошибка: "Ключ 'c' не найден. Доступные ключи: a, b"
```

---

## Примеры использования

**Удалить временный ключ после использования:**
```
Словарь:                   processData     ← { "id": "42", "_temp_flag": "1", "name": "Alice" }
Ключ:                      "_temp_flag"
Ошибка если не найдено:    false
Результирующий словарь:    cleanData       ← { "id": "42", "name": "Alice" }
```

**Удалить обязательный ключ с проверкой:**
```
Словарь:                   sessionDict
Ключ:                      "auth_token"
Ошибка если не найдено:    true
Результат:                 cleanedSession
→ Если токена нет — ошибка: «Ключ 'auth_token' не найден»
```

**Удаление с ветвлением по результату:**
```
[Словарь: Удалить ключ]
  Словарь:                configDict
  Ключ:                   "deprecated_setting"
  Ошибка если не найдено: false
  Результат:              updatedConfig
  Ключ удалён:            wasRemoved

[Условие] wasRemoved = true
  → Записать лог: "Устаревшая настройка удалена"
```

**Последовательное удаление нескольких ключей:**
```
[Удалить ключ] ключ="tmp1" → dict1
[Удалить ключ] ключ="tmp2" из dict1 → dict2
[Удалить ключ] ключ="tmp3" из dict2 → cleanDict
```

---

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentNullException` | Словарь = null |
| `ArgumentException` | Ключ пустой или null |
| `KeyNotFoundException` | Ключ не найден при `Ошибка если не найдено = true` — сообщение содержит список доступных ключей |

---

## Заметки

- Поиск ключа **регистрозависим**: `"Key"` и `"key"` — разные ключи
- Для удаления **нескольких ключей** используйте активность **«Словарь: Фильтровать»** — она позволяет оставить только нужные ключи через режим `Target = Keys`, `Method = Exact`
- Результирующий словарь — это новый экземпляр: исходный словарь гарантированно не изменён
