# Словарь: Создать

> **Группа:** MIA → Словари  
> **Класс:** `DictionaryCreateBack`  
> **Тип результата:** `Dictionary<string, string>`

## Назначение

Создаёт новый `Dictionary<string, string>` одним из четырёх способов. Входной словарь (при его наличии) **не изменяется** — всегда возвращается новый экземпляр.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Режим создания** | `DictionaryCreateMode` | Всегда | Способ создания словаря (см. режимы ниже) |
| **Словарь** | `Dictionary<string, string>` | Clone, Invert | Входной словарь для копирования или инверсии |
| **Список ключей** | `List<string>` | FromLists | Ключи для построения словаря |
| **Список значений** | `List<string>` | FromLists | Значения для построения словаря |
| **Ошибка при дублях** | `bool` | Нет | Поведение при дублях значений в режиме Invert (по умолч. `false`) |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Результирующий словарь** | `Dictionary<string, string>` | Созданный словарь |
| **Количество элементов** | `int` | Размер результата |
| **Пропущено дублей (Invert)** | `int` | Количество пропущенных дублей (только для режима Invert) |

---

## Режимы создания

### `CreateEmpty`
Создаёт пустой словарь без элементов.

```
Режим: CreateEmpty
→ Результат: {}
```

### `FromLists`
Строит словарь из двух списков одинаковой длины. Списки объединяются попарно по индексу.

- Длины `Список ключей` и `Список значений` **должны совпадать**
- При дублирующихся ключах побеждает **последнее** значение

```
Список ключей:   ["host", "port", "host"]
Список значений: ["localhost", "5432", "prod-server"]
→ Результат: { "host": "prod-server", "port": "5432" }
```

### `Clone`
Создаёт полную независимую копию словаря. Изменения в копии **не затрагивают** оригинал.

```
Входной словарь: { "a": "1", "b": "2" }
→ Результат:     { "a": "1", "b": "2" }  ← независимый экземпляр
```

### `Invert`
Меняет ключи и значения местами: значения становятся ключами, ключи — значениями.

| `Ошибка при дублях` | Поведение при одинаковых значениях |
|---|---|
| `false` (по умолч.) | Сохраняется первое вхождение, остальные пропускаются. `Пропущено дублей` = кол-во пропусков |
| `true` | Выбрасывается исключение со списком дублирующихся значений |

```
Входной словарь: { "city": "Moscow", "capital": "Moscow", "country": "Russia" }
Ошибка при дублях: false
→ Результат:     { "Moscow": "city", "Russia": "country" }
→ Пропущено дублей: 1
```

## Примеры использования

**Создать пустой словарь для заполнения в цикле:**
```
Режим:                 CreateEmpty
Результирующий словарь: myDict
```

**Собрать словарь из заголовков и значений таблицы:**
```
Режим:          FromLists
Список ключей:  headers        ← List<string> из строки заголовков
Список значений: rowValues     ← List<string> из строки данных
Результат:      rowDict
```

**Сделать резервную копию перед модификацией:**
```
Режим:          Clone
Словарь:        originalDict
Результат:      backupDict
```

**Получить обратный маппинг (значение → ключ):**
```
Режим:              Invert
Словарь:            codeToName   ← { "RU": "Россия", "US": "США" }
Ошибка при дублях:  false
Результат:          nameToCode   ← { "Россия": "RU", "США": "US" }
```

---

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentNullException` | Словарь = null в режиме Clone или Invert |
| `ArgumentNullException` | Список ключей или значений = null в режиме FromLists |
| `ArgumentException` | Длины списков не совпадают в режиме FromLists |
| `InvalidOperationException` | Дублирующиеся значения в режиме Invert при `Ошибка при дублях = true` |

---

## Заметки

- В режиме `FromLists` при дублирующихся ключах побеждает последнее значение — это стандартное поведение словаря
- В режиме `Invert` параметр `Пропущено дублей` заполняется только если `Ошибка при дублях = false`
- `Clone` создаёт поверхностную копию — для `Dictionary<string, string>` этого достаточно, так как строки в C# иммутабельны
