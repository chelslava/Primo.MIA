# Словарь: Проверить значение

> **Группа:** MIA → Словари  
> **Класс:** `DictionaryContainsValueBack`  
> **Тип результата:** `bool` + `List<string>`

## Назначение

Проверяет наличие **точного совпадения** значения в `Dictionary<string, string>`. Поддерживает регистрозависимый и регистронезависимый поиск. Возвращает флаг наличия и список **всех ключей**, у которых значение совпало. Словарь **не изменяется**.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| **Словарь** | `Dictionary<string, string>` | Да | — | Словарь для поиска |
| **Искомое значение** | `string` | Да | — | Значение для поиска (точное совпадение) |
| **Учитывать регистр** | `bool` | Нет | `false` | `false` — регистронезависимый поиск |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Значение найдено** | `bool` | `true` если хотя бы один ключ имеет искомое значение |
| **Ключи с таким значением** | `List<string>` | Все ключи с совпавшим значением (сортировка алфавитная) |

---

## Принцип работы

Активность просматривает **все значения** словаря через LINQ и собирает список ключей, чьё значение точно совпадает с искомым. Поэтому она корректно обрабатывает ситуацию, когда одно и то же значение встречается у нескольких ключей.

```
Словарь: { "user1": "admin", "user2": "operator", "user3": "admin", "user4": "viewer" }
Искомое: "admin"
→ Значение найдено:           true
→ Ключи с таким значением:    ["user1", "user3"]
```

---

## Влияние флага «Учитывать регистр»

```
Словарь: { "key1": "Active", "key2": "ACTIVE", "key3": "active" }
Искомое: "active"

Учитывать регистр: false  →  Найдено: true,  Ключи: ["key1", "key2", "key3"]
Учитывать регистр: true   →  Найдено: true,  Ключи: ["key3"]
```

---

## Примеры использования

**Проверить существование роли перед назначением:**
```
Словарь:              userRoles        ← { "alice": "admin", "bob": "user", "carol": "admin" }
Искомое значение:     "admin"
Учитывать регистр:    false
Значение найдено:     hasAdmin
Ключи с таким значением: adminUsers   ← ["alice", "carol"]
```

**Найти все записи с определённым статусом:**
```
Словарь:              orderStatuses
Искомое значение:     "pending"
→ Ключи с таким значением: pendingOrders  ← список номеров заказов
```

**Убедиться что значение уникально перед инверсией словаря:**
```
Словарь:              codeToName
Искомое значение:     "Moscow"
Ключи с таким значением: duplicates

→ Если duplicates.Count > 1 — значение не уникально, инверсия даст потери
```

## Сравнение с другими активностями

| Задача | Активность |
|---|---|
| Проверить наличие **ключа** | «Словарь: Проверить ключ» |
| Проверить наличие **точного значения** | «Словарь: Проверить значение» ← эта |

---

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentNullException` | Словарь = null |
| `ArgumentNullException` | Искомое значение = null |

---

## Заметки

- Если значение не найдено — `Ключи с таким значением` возвращается как **пустой список** `[]`, не `null`
- Ключи в результирующем списке всегда отсортированы **алфавитно**
- Поиск выполняется за **O(n)** — просматриваются все значения словаря
