# Словарь: Из строки

> **Группа:** MIA → Словари  
> **Класс:** `DictionaryFromStringBack`  
> **Тип результата:** `Dictionary<string, string>`

## Назначение

Десериализует строку вида `"key1=val1;key2=val2"` в `Dictionary<string, string>`. Разделители пар и разделитель ключ-значение настраиваются. Является парной операцией к активности **«Словарь: В строку»**.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| **Входная строка** | `string` | Да | — | Строка для разбора |
| **Разделитель пар** | `string` | Нет | `";"` | Разделитель между парами ключ-значение |
| **Разделитель ключ-значение** | `string` | Нет | `"="` | Разделитель внутри одной пары |
| **Обрезать пробелы** | `bool` | Нет | `true` | Удалять пробелы в начале/конце ключей и значений |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Результирующий словарь** | `Dictionary<string, string>` | Разобранный словарь |
| **Разобрано пар** | `int` | Количество успешно разобранных пар |
| **Пропущено пар** | `int` | Количество пар с ошибками или пустых |

---

## Логика разбора

1. Строка разбивается на части по **разделителю пар**
2. Каждая часть разбивается на ключ и значение по **разделителю ключ-значение** (с лимитом 2 части)
3. Части с пустым ключом или без разделителя — **пропускаются**
4. Если `Обрезать пробелы = true` — ключ и значение очищаются от пробелов
5. При дублирующихся ключах побеждает **последнее** значение

> **Важно:** разбиение по разделителю ключ-значение выполняется с лимитом `2 части` — это означает что **значение может содержать сам разделитель**. Например, `url=https://example.com?a=1&b=2` корректно разберётся как ключ `url` и значение `https://example.com?a=1&b=2`.

---

## Примеры

### Стандартный формат
```
Входная строка:             "host=localhost;port=5432;db=mydb"
Разделитель пар:            ";"
Разделитель ключ-значение:  "="
→ Результат: { "host": "localhost", "port": "5432", "db": "mydb" }
→ Разобрано пар: 3
→ Пропущено пар: 0
```

### Пользовательские разделители
```
Входная строка:             "name:Alice|age:30|city:Moscow"
Разделитель пар:            "|"
Разделитель ключ-значение:  ":"
→ Результат: { "name": "Alice", "age": "30", "city": "Moscow" }
```

### Значение содержит разделитель
```
Входная строка:  "url=https://example.com?a=1;timeout=30"
→ Результат: { "url": "https://example.com?a=1", "timeout": "30" }
```

### Многострочный формат
```
Входная строка:  "name=John\nrole=admin\ncity=Moscow"
Разделитель пар: "\n"
→ Результат: { "name": "John", "role": "admin", "city": "Moscow" }
```

### Строка с пробелами вокруг разделителей
```
Входная строка:    "  host  =  localhost  ;  port  =  5432  "
Обрезать пробелы:  true
→ Результат: { "host": "localhost", "port": "5432" }
```

### Пары с ошибками пропускаются
```
Входная строка:  "valid=ok;;=emptykey;noequalssign;another=good"
→ Результат:     { "valid": "ok", "another": "good" }
→ Разобрано пар: 2
→ Пропущено пар: 3   ← пустая строка, пустой ключ, строка без разделителя
```

---

## Поведение при дублирующихся ключах
```
Входная строка: "host=server1;port=3306;host=server2"
→ Результат: { "host": "server2", "port": "3306" }
             ↑ побеждает последнее значение
```

---

## Совместимость с «Словарь: В строку»

Активности полностью симметричны при одинаковых настройках разделителей:

```
Словарь → [В строку, пары=";", кз="="] → "a=1;b=2;c=3"
"a=1;b=2;c=3" → [Из строки, пары=";", кз="="] → { "a": "1", "b": "2", "c": "3" }
```

---

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentException` | Входная строка пустая или null |

---

## Заметки

- `Пропущено пар` удобно использовать для диагностики качества входных данных — если значение > 0, входная строка содержит некорректные фрагменты
- При пустом значении в разделителях автоматически используются значения по умолчанию (`;` и `=`)
- Порядок элементов в результирующем словаре не гарантирован (стандартное поведение `Dictionary<string, string>`)
