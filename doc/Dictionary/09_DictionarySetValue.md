# Словарь: Установить значение

> **Группа:** MIA → Словари  
> **Класс:** `DictionarySetValueBack`  
> **Тип результата:** `Dictionary<string, string>`

## Назначение

Добавляет новый ключ или обновляет значение существующего в `Dictionary<string, string>`. Возвращает **новую копию** словаря с изменениями. Оригинальный словарь **не изменяется**.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Словарь** | `Dictionary<string, string>` | Да | Входной словарь |
| **Ключ** | `string` | Да | Ключ для добавления или обновления |
| **Значение** | `string` | Да | Значение для установки |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Результирующий словарь** | `Dictionary<string, string>` | Копия словаря с изменённым ключом |
| **Обновление (не добавление)** | `bool` | `true` — ключ уже существовал (обновление), `false` — ключ новый (добавление) |

---

## Принцип работы

1. Проверяется наличие ключа в исходном словаре → запоминается результат для `Обновление`
2. Создаётся **полная копия** исходного словаря
3. В копии устанавливается новое значение для ключа
4. Копия возвращается как результат — исходный словарь не тронут

```
Исходный словарь: { "host": "localhost", "port": "5432" }
Ключ:             "port"
Значение:         "3306"

→ Результат:              { "host": "localhost", "port": "3306" }
→ Обновление (не добавление): true   ← ключ "port" уже существовал
→ Исходный словарь:       { "host": "localhost", "port": "5432" }  ← не изменился
```

---

## Сценарии использования

### Добавление нового ключа
```
Словарь:                   baseConfig      ← { "host": "localhost" }
Ключ:                      "timeout"
Значение:                  "30"
Результирующий словарь:    extendedConfig  ← { "host": "localhost", "timeout": "30" }
Обновление (не добавление): false           ← новый ключ
```

### Обновление существующего значения
```
Словарь:                   orderData       ← { "status": "pending", "id": "12345" }
Ключ:                      "status"
Значение:                  "completed"
Результирующий словарь:    updatedOrder    ← { "status": "completed", "id": "12345" }
Обновление (не добавление): true            ← ключ "status" был
```

### Сохранение истории изменений
```
← активность не изменяет оригинал, поэтому можно хранить обе версии:

originalDict  ← { "version": "1", "status": "draft" }

[Словарь: Установить значение]
  Словарь:   originalDict
  Ключ:      "status"
  Значение:  "published"
  Результат: publishedDict   ← { "version": "1", "status": "published" }

← originalDict по-прежнему содержит { "version": "1", "status": "draft" }
```

### Накопление данных в цикле
```
currentDict = {}  ← начинаем с пустого словаря

[Для каждой строки таблицы]
  [Словарь: Установить значение]
    Словарь:   currentDict
    Ключ:      row["id"]
    Значение:  row["name"]
    Результат: currentDict   ← переназначаем ту же переменную
```

---

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentNullException` | Словарь = null |
| `ArgumentException` | Ключ пустой или null |
| `ArgumentNullException` | Значение = null |

---

## Заметки

- Пустая строка `""` как значение — допустима. Ошибку вызывает только `null`
- Для **удаления** ключа используйте активность **«Словарь: Удалить ключ»**
- Для **массового обновления** (добавить много ключей) — используйте **«Словарь: Объединить»**
- Ключи **регистрозависимы**: `"Name"` и `"name"` — разные ключи
