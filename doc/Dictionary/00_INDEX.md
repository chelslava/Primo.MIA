# Документация: Библиотека активностей «Словари» (MIA)

> **Группа в студии:** MIA → Словари  
> **Тип данных:** `Dictionary<string, string>`

Все активности работают с `Dictionary<string, string>` и **не изменяют входные словари** — операции всегда возвращают новый экземпляр.

## Общие принципы библиотеки

1. **Иммутабельность** — все активности возвращают новый словарь, оригинал не изменяется
2. **Null-безопасность** — передача null в обязательные параметры всегда вызывает явную `ArgumentNullException` с понятным сообщением
3. **Информативные ошибки** — при отсутствии ключа сообщение об ошибке содержит список доступных ключей
4. **Предсказуемые списки** — там где возвращаются списки ключей, они всегда отсортированы алфавитно
5. **LINQ** — вся логика реализована через LINQ-выражения и лямбды
