# Словарь: Информация

> **Группа:** MIA → Словари  
> **Класс:** `DictionaryGetInfoBack`  
> **Тип результата:** `int` + `List<string>` × 2 + `bool`

## Назначение

За один шаг возвращает полную структурную информацию о `Dictionary<string, string>`: количество элементов, список всех ключей, список всех значений и флаг пустоты. Словарь **не изменяется**.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Словарь** | `Dictionary<string, string>` | Да | Словарь для анализа |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Количество элементов** | `int` | Размер словаря (`dict.Count`) |
| **Список ключей** | `List<string>` | Все ключи в **алфавитном** порядке |
| **Список значений** | `List<string>` | Все значения в том же порядке что и ключи |
| **Словарь пуст** | `bool` | `true` если словарь не содержит ни одного элемента |

---

## Важно: синхронность порядка ключей и значений

Списки `Список ключей` и `Список значений` **синхронизированы** — элемент с индексом `i` в списке значений соответствует элементу с индексом `i` в списке ключей.

```
Словарь: { "city": "Moscow", "country": "Russia", "code": "RU" }

Список ключей:   ["city",    "code", "country"]   ← алфавитный порядок
Список значений: ["Moscow",  "RU",   "Russia"  ]  ← тот же порядок
                   ↑ i=0      ↑ i=1   ↑ i=2
```

## Примеры использования

**Проверить словарь перед обработкой:**
```
Словарь:             inputData
Количество элементов: count
Словарь пуст:        isEmpty

→ Если isEmpty = true — пропустить обработку или сообщить об ошибке
→ Если count > 100   — предупредить о большом объёме данных
```

**Перебрать все ключи в цикле:**
```
[Словарь: Информация]
  Словарь:       myDict
  Список ключей: keysList       ← List<string>

[Для каждого] key в keysList
  → [Словарь: Получить значение] ключ = key
```

**Вывести содержимое словаря в лог:**
```
[Словарь: Информация]
  Словарь:         debugDict
  Список ключей:   keys
  Список значений: values
  Количество:      cnt

[Для каждого с индексом] i от 0 до cnt-1
  → Записать лог: keys[i] + " = " + values[i]
```

**Передать ключи в фильтр:**
```
[Словарь: Информация]
  Словарь:       sourceDict
  Список ключей: allKeys        ← для последующей передачи в «Словарь: Фильтровать»
```

## Сравнение с другими способами получения размера

| Задача | Способ |
|---|---|
| Только количество элементов | «Словарь: Информация» → `Количество элементов` |
| Только список ключей | «Словарь: Информация» → `Список ключей` |
| Полный анализ | «Словарь: Информация» — все 4 параметра за один шаг |

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentNullException` | Словарь = null |

---

## Заметки

- Ключи и значения возвращаются отсортированными **алфавитно по ключу** — это обеспечивает предсказуемый и воспроизводимый порядок независимо от порядка добавления элементов
- Для пустого словаря: `Количество = 0`, `Список ключей = []`, `Список значений = []`, `Словарь пуст = true`
- Активность не изменяет словарь и не создаёт его копию — работает с исходным экземпляром
