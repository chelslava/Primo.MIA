# Словарь: Проверить ключ

> **Группа:** MIA → Словари  
> **Класс:** `DictionaryContainsKeyBack`  
> **Тип результата:** `bool`

## Назначение

Проверяет наличие ключа в `Dictionary<string, string>`. Возвращает `true` если ключ присутствует, `false` если нет. Словарь **не изменяется**.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Словарь** | `Dictionary<string, string>` | Да | Словарь для проверки |
| **Ключ** | `string` | Да | Ключ существование которого нужно проверить |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Ключ существует** | `bool` | `true` — ключ найден, `false` — не найден |

---

## Пример использования

**Проверить наличие настройки перед чтением:**
```
Словарь:         configDict
Ключ:            "database_host"
Ключ существует: hasDbHost     ← bool

→ Если hasDbHost = true — читаем значение через «Получить значение»
→ Если hasDbHost = false — используем значение по умолчанию
```

**Условная обработка в роботе:**
```
[Словарь: Проверить ключ]
  Словарь:         orderData
  Ключ:            "discount_code"
  Ключ существует: hasDiscount

[Условие] hasDiscount = true
  → [Словарь: Получить значение] — читаем код скидки
```

---

## Особенности

- Проверка **регистрозависима** — ключи `"Name"` и `"name"` считаются разными (стандартное поведение `Dictionary`)
- Поиск выполняется за **O(1)** — операция не зависит от размера словаря
- Пустой ключ (`""`) вызовет ошибку валидации

---

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentNullException` | Словарь = null |
| `ArgumentException` | Ключ пустой или null |

---

## Заметки

> Если нужно не только проверить наличие ключа, но и получить его значение — используйте активность **«Словарь: Получить значение»** с параметром `Ошибка если не найдено = false` и параметром выхода `Ключ найден`. Она за один шаг выполняет обе операции.
