# Словарь: Получить значение

> **Группа:** MIA → Словари  
> **Класс:** `DictionaryGetValueBack`  
> **Тип результата:** `string` + `bool`

## Назначение

Читает значение из `Dictionary<string, string>` по заданному ключу. При отсутствии ключа — возвращает значение по умолчанию **или** выбрасывает исключение (настраивается). Словарь **не изменяется**.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| **Словарь** | `Dictionary<string, string>` | Да | — | Словарь для чтения |
| **Ключ** | `string` | Да | — | Ключ для поиска значения |
| **Значение по умолчанию** | `string` | Нет | `""` | Возвращается если ключ не найден (при `Ошибка если не найдено = false`) |
| **Ошибка если не найдено** | `bool` | Нет | `false` | Поведение при отсутствии ключа |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Значение** | `string` | Найденное значение или `Значение по умолчанию` |
| **Ключ найден** | `bool` | `true` если ключ присутствовал в словаре |

---

## Режимы поведения при отсутствии ключа

### `Ошибка если не найдено = false` *(по умолчанию)*
Возвращает `Значение по умолчанию`, `Ключ найден = false`. Выполнение продолжается.

```
Словарь:                   { "host": "localhost" }
Ключ:                      "port"
Значение по умолчанию:     "5432"
Ошибка если не найдено:    false
→ Значение:    "5432"
→ Ключ найден: false
```

### `Ошибка если не найдено = true`
Выбрасывает `KeyNotFoundException` с сообщением содержащим список всех доступных ключей словаря.

```
Словарь:                { "host": "localhost" }
Ключ:                   "port"
Ошибка если не найдено: true
→ Ошибка: "Ключ 'port' не найден. Доступные ключи: host"
```

## Примеры использования

**Чтение с гарантированным значением по умолчанию:**
```
Словарь:                configDict
Ключ:                   "retry_count"
Значение по умолчанию:  "3"
Ошибка если не найдено: false
Значение:               retryCount     ← "3" если ключ не задан
Ключ найден:            retryDefined   ← false если использован default
```

**Чтение обязательного параметра:**
```
Словарь:                requiredConfig
Ключ:                   "api_key"
Ошибка если не найдено: true
Значение:               apiKey
→ Если ключ отсутствует — робот остановится с понятным сообщением об ошибке
```

**Чтение с проверкой и ветвлением:**
```
Ошибка если не найдено: false
Значение по умолчанию:  ""
Значение:               featureFlag
Ключ найден:            flagExists

[Условие] flagExists = true AND featureFlag = "enabled"
  → применить новую логику
[Иначе]
  → применить стандартную логику
```

## Сравнение с «Словарь: Проверить ключ»

| Задача | Рекомендуемая активность |
|---|---|
| Только проверить наличие ключа | «Словарь: Проверить ключ» |
| Проверить наличие И получить значение | «Словарь: Получить значение» — делает оба действия |
| Получить значение или default | «Словарь: Получить значение» с `Ошибка если не найдено = false` |
| Получить значение или упасть | «Словарь: Получить значение» с `Ошибка если не найдено = true` |

---

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentNullException` | Словарь = null |
| `ArgumentException` | Ключ пустой или null |
| `KeyNotFoundException` | Ключ не найден при `Ошибка если не найдено = true` — сообщение содержит список доступных ключей |

---

## Заметки

- Значение по умолчанию устанавливается в конструкторе как `""` (пустая строка)
- Поиск выполняется через `TryGetValue` — за **O(1)**
- Поиск **регистрозависим** — `"Name"` и `"name"` считаются разными ключами
- Параметр `Ключ найден` позволяет отличить ситуацию «ключ есть и значение пустое» от «ключа нет» — обе вернут пустую строку, но `Ключ найден` будет разным
