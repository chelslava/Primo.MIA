# Словарь: В строку

> **Группа:** MIA → Словари  
> **Класс:** `DictionaryToStringBack`  
> **Тип результата:** `string`

## Назначение

Сериализует `Dictionary<string, string>` в строку. Разделители пар и разделитель ключ-значение настраиваются. Ключи сортируются алфавитно для **стабильного и воспроизводимого** вывода. Является парной операцией к активности **«Словарь: Из строки»**.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| **Словарь** | `Dictionary<string, string>` | Да | — | Словарь для сериализации |
| **Разделитель пар** | `string` | Нет | `";"` | Символ между парами ключ-значение |
| **Разделитель ключ-значение** | `string` | Нет | `"="` | Символ между ключом и значением внутри пары |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Результирующая строка** | `string` | Сериализованный словарь |
| **Количество пар** | `int` | Размер словаря (равно числу пар в строке) |

---

## Форматы вывода

### Стандартный формат (по умолчанию)
```
Словарь:              { "host": "localhost", "port": "5432", "db": "prod" }
Разделитель пар:      ";"
Разделитель кз:       "="
→ Результат: "db=prod;host=localhost;port=5432"
              ↑ ключи отсортированы алфавитно
```

### Формат с pipe-разделителем
```
Разделитель пар:  "|"
Разделитель кз:   ":"
→ "db:prod|host:localhost|port:5432"
```

### Многострочный формат
```
Разделитель пар:  "\n"
Разделитель кз:   " = "
→ "db = prod
   host = localhost
   port = 5432"
```

### JSON-подобный формат
```
Разделитель пар:  ", "
Разделитель кз:   ": "
→ "db: prod, host: localhost, port: 5432"
```

---

## Алфавитная сортировка ключей

Ключи всегда сортируются алфавитно перед сериализацией. Это обеспечивает:
- **Воспроизводимость** — одинаковый словарь всегда даёт одинаковую строку
- **Читаемость** — результат предсказуем и не зависит от порядка добавления элементов
- **Сравнимость** — строки двух одинаковых словарей можно сравнивать напрямую

```
Добавление в разном порядке → одинаковый результат:
{ "b": "2", "a": "1", "c": "3" }  →  "a=1;b=2;c=3"
{ "c": "3", "a": "1", "b": "2" }  →  "a=1;b=2;c=3"
```

---

## Совместимость с «Словарь: Из строки»

Активности полностью симметричны при одинаковых разделителях:

```
{ "host": "localhost", "port": "5432" }
    ↓ [В строку, пары=";", кз="="]
"host=localhost;port=5432"
    ↓ [Из строки, пары=";", кз="="]
{ "host": "localhost", "port": "5432" }
```

> ⚠️ Если **значение** содержит разделитель ключ-значение (`=`), строка будет некорректно разобрана при `Из строки` с лимитом 2 части — но только если это первый встреченный разделитель. Подробнее — в документации «Словарь: Из строки».

## Примеры использования

**Передать конфигурацию как строку в следующий шаг:**
```
Словарь:               configDict
Разделитель пар:       ";"
Разделитель кз:        "="
Результирующая строка: configString   ← "db=prod;host=server1;port=5432"
→ Передать configString в другой процесс / записать в файл
```

**Сохранить словарь в ячейку Excel:**
```
Словарь:               rowData
Результирующая строка: cellValue   ← сохранить в одну ячейку
```

**Сравнить два словаря:**
```
[В строку] dict1 → str1
[В строку] dict2 → str2
[Условие]  str1 = str2  ← словари идентичны
```

**Логирование содержимого словаря:**
```
[В строку]
  Словарь:               requestData
  Разделитель пар:       " | "
  Разделитель кз:        "="
  Результирующая строка: logLine

→ Записать в лог: "Request: " + logLine
```

## Возможные ошибки

| Ошибка | Причина |
|---|---|
| `ArgumentNullException` | Словарь = null |

---

## Заметки

- Пустой словарь (0 элементов) → пустая строка `""`, `Количество пар = 0`
- При пустом значении разделителей автоматически применяются значения по умолчанию (`;` и `=`)
- Многосимвольные разделители допустимы: `" | "`, `" => "`, `"\r\n"` и т.д.
- Разделитель пар и разделитель ключ-значение **не должны совпадать** — иначе обратный разбор «Из строки» будет некорректным
