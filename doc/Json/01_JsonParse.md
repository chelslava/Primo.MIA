# JSON: Парсинг

> **Группа:** MIA → HTTP / Web  
> **Класс:** `JsonParseBack`

## Назначение

Разбирает JSON-строку, валидирует её или форматирует. Может вернуть структуру `Dictionary/List`, признак валидности и сообщение об ошибке.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `JSON-строка` | `string` | Исходный JSON для обработки. |
| `Режим` | `JsonParseMode` | `ToDictionary`, `ToList`, `Validate`, `Format`. |
| `Строгий режим` | `bool` | Если JSON невалиден, в строгом режиме активность завершится ошибкой. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Результат` | `object` | Структура данных или отформатированная строка, в зависимости от режима. |
| `Валиден` | `bool` | Признак корректного JSON. |
| `Ошибки` | `string` | Текст ошибки валидации. |

## Режимы

| Режим | Поведение |
|---|---|
| `ToDictionary` | Преобразует JSON-объект в словарь. |
| `ToList` | Преобразует JSON-массив в список. |
| `Validate` | Только проверяет валидность. |
| `Format` | Возвращает JSON в отформатированном виде. |

## Примечания

- В нестрогом режиме невалидный JSON не вызывает ошибку выполнения, а отражается через выходные параметры.
- Для выборки отдельных значений по JSONPath используйте [02_JsonQuery.md](02_JsonQuery.md).
