# JSON: Запрос

> **Группа:** MIA → HTTP / Web  
> **Класс:** `JsonQueryBack`

## Назначение

Извлекает данные из JSON по выражению JSONPath. Подходит для получения отдельных полей, массивов или подсчёта найденных элементов.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `JSON-строка` | `string` | Исходный JSON. |
| `JSONPath` | `string` | Выражение поиска, например `$.store.book[*].title`. |
| `Только первое` | `bool` | Если `true`, возвращается только первое совпадение. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Результат` | `object` | Одно значение или список найденных значений. |
| `Количество` | `int` | Число найденных элементов. |
| `Найдено` | `bool` | Есть ли хотя бы одно совпадение. |

## Примеры JSONPath

- `$.store.book[0].title`
- `$.store.book[*].author`
- `$..price`
- `$.items[?(@.status=='done')]`

## Примечания

- Перед выполнением запроса JSON валидируется; невалидная строка вызывает ошибку.
- Если нужен только признак корректности JSON, удобнее использовать [01_JsonParse.md](01_JsonParse.md) в режиме `Validate`.
