# БД: Постраничный запрос

> **Группа:** MIA → База данных
> **Класс:** `DatabaseQueryPagedBack`

## Назначение

Выполняет SQL-запрос постранично.

Активность:
- считает общее количество строк через `COUNT(*)`
- возвращает только одну страницу результата
- сообщает metadata по пагинации: `TotalRows`, `TotalPages`, `HasNextPage`, `HasPreviousPage`

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | ADO.NET provider |
| `Строка подключения` | `string` | Connection string |
| `ID транзакции` | `string` | Необязательный transactionId |
| `SQL / имя процедуры` | `string` | Исходный SQL-запрос |
| `Order by` | `string` | Обязательное выражение `ORDER BY` для стабильной пагинации |
| `Номер страницы` | `int` | Начиная с `1` |
| `Размер страницы` | `int` | Количество строк на странице |
| `Параметры` | `Dictionary<string,string>` | Параметры исходного запроса |
| `Таймаут команды (сек)` | `int` | Таймаут выполнения |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Таблица-результат` | `DataTable` | Строки текущей страницы |
| `Количество строк` | `int` | Сколько строк вернулось на текущей странице |
| `Всего строк` | `int` | Полный размер выборки |
| `Всего страниц` | `int` | Общее количество страниц |
| `Есть следующая страница` | `bool` | Можно ли запросить следующую страницу |
| `Есть предыдущая страница` | `bool` | Есть ли страница до текущей |

## Замечания

- Для SQL Server используется `OFFSET ... FETCH`
- Для PostgreSQL / MySQL / SQLite используется `LIMIT ... OFFSET`
- Для Oracle используется `OFFSET ... FETCH` с oracle-compatible alias
