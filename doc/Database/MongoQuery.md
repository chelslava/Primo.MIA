# MongoDB: Запрос

> **Группа:** MIA → MongoDB
> **Класс:** `MongoQueryBack`

## Назначение

Выполняет поиск документов в коллекции MongoDB по заданному фильтру. Поддерживает проекцию, сортировку и ограничение количества результатов.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | MongoDB connection string. Пример: `mongodb://localhost:27017` |
| **База данных** | `string` | ✅ | Имя базы данных |
| **Коллекция** | `string` | ✅ | Имя коллекции |
| **Фильтр** | `string` | Нет | JSON-фильтр. По умолчанию `{}` (все документы) |

### Дополнительные

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Проекция** | `string` | — | JSON-проекция для включения/исключения полей |
| **Сортировка** | `string` | — | JSON-выражение сортировки. Пример: `{"name": 1}` |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Макс. документов** | `int` | `0` | Ограничение выборки. `0` = без ограничения |
| **Таймаут** | `int` | `30` | Таймаут выполнения в секундах |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Результат (JSON)** | `string` | Массив документов в формате JSON |
| **Количество документов** | `int` | Количество найденных документов |
| **Есть документы** | `bool` | `true`, если найден хотя бы один документ |

## Примеры

### Пример 1: Все документы

```
Строка подключения: "mongodb://localhost:27017"
База данных: "shop"
Коллекция: "products"
Фильтр: "{}"

Результат:
[
  {"_id":"...","name":"Телефон","price":29999},
  {"_id":"...","name":"Ноутбук","price":79999}
]
```

### Пример 2: Фильтрация и проекция

```
Строка подключения: "mongodb://localhost:27017"
База данных: "shop"
Коллекция: "products"
Фильтр: {"category": "electronics"}
Проекция: {"name": 1, "price": 1}
Сортировка: {"price": 1}

Результат (только name и price, отсортировано по цене):
[
  {"name":"Телефон","price":29999},
  {"name":"Ноутбук","price":79999}
]
```

### Пример 3: С условием

```
Фильтр: {"price": {"$gte": 10000}, "inStock": true}
Макс. документов: 10

Результат: первые 10 документов, где price >= 10000 и inStock = true
```

## Фильтры

```json
// Пустой фильтр — все документы
{}

// Точное совпадение
{"status": "active"}

// Вложенное поле
{"user.name": "Иван"}

// Условия
{"age": {"$gte": 18}}
{"tags": {"$in": ["a", "b"]}}

// Комбинированный
{"status": "active", "price": {"$lt": 50000}}
```
