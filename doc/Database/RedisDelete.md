# Redis: Удалить ключ

> **Группа:** MIA → Redis
> **Класс:** `RedisDeleteBack`

## Назначение

Удаляет один или несколько ключей из Redis.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string |
| **Ключи** | `List<string>` | ✅ | Список ключей для удаления |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Удалено ключей** | `int` | Количество фактически удалённых ключей |

## Примеры

### Пример 1: Удаление одного ключа

```
Строка подключения: "localhost:6379"
Ключи: ["temp:data:123"]

Результат:
  Удалено ключей: 1
```

### Пример 2: Удаление нескольких ключей

```
Ключи: ["cache:user:1", "cache:user:2", "cache:user:3"]

Результат:
  Удалено ключей: 3
```

### Пример 3: Очистка кэша

```
// Создать список всех ключей кэша
// Затем удалить
Ключи: ["cache:products", "cache:categories", "cache:orders"]
```

## ⚠️ Важно

- Удаление несуществующего ключа **не считается ошибкой** — он просто не учитывается в результате
- Операция необратима — удалённые данные восстановить нельзя
