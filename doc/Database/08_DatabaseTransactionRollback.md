# БД: Откатить транзакцию

> **Группа:** MIA → База данных
> **Класс:** `DatabaseTransactionRollbackBack`

## Назначение

Откатывает транзакцию по явному `transactionId` или по текущему ambient-контексту.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `ID транзакции` | `string` | Необязательный идентификатор транзакции для отката. Если он указан, активность откатит именно эту транзакцию. Если поле пусто, используется текущая активная DB-транзакция из контекста. |

## Выходные параметры

У активности нет пользовательских выходных переменных. Успех или ошибка определяются результатом выполнения.

## Замечания

- Если `transactionId` не указан, будет использована текущая активная DB-транзакция.
- После `Rollback` транзакция удаляется из менеджера и контекста.
- Активность полезна в `Catch`/обработке ошибок, когда нужно гарантированно отменить все изменения, сделанные после `Begin`.
- После отката использовать тот же `transactionId` повторно уже нельзя: для новых операций нужно открыть новую транзакцию.
