# Redis: Хэш — Получить поле

> **Группа:** MIA → Redis
> **Класс:** `RedisHashGetBack`

## Назначение

Получает значение одного поля хэша (`HGET`) или все поля сразу (`HGETALL`). Если указано конкретное поле — возвращается его значение. Если поле не указано — возвращается словарь всех полей.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string |
| **Ключ** | `string` | ✅ | Ключ хэша |
| **Поле** | `string` | Нет | Имя поля. Если пусто — возвращаются все поля |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Выходные параметры

| Параметр | Тип | Когда | Описание |
|----------|-----|-------|----------|
| **Значение поля** | `string` | Поле указано | Значение конкретного поля |
| **Все поля (Dictionary)** | `Dictionary<string,string>` | Поле пусто | Все поля хэша |

## Примеры

### Пример 1: Получение одного поля

```
Строка подключения: "localhost:6379"
Ключ: "user:42"
Поле: "email"

Результат:
  Значение поля: "ivan@example.com"
```

### Пример 2: Получение всех полей

```
Ключ: "user:42"
Поле: (пусто)

Результат:
  Все поля (Dictionary):
    name → "Иван"
    email → "ivan@example.com"
    age → "30"
    city → "Москва"
```

### Пример 3: Поле не существует

```
Ключ: "user:42"
Поле: "phone"

Результат:
  Значение поля: ""
```

## Структура хэша

```
Ключ: "user:42"
├── name: "Иван"
├── email: "ivan@example.com"
├── age: "30"
└── city: "Москва"
```
