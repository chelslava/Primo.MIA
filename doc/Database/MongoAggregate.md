# MongoDB: Агрегация

> **Группа:** MIA → MongoDB
> **Класс:** `MongoAggregateBack`

## Назначение

Выполняет агрегационный pipeline в коллекции MongoDB и возвращает результат в виде JSON-массива. Поддерживает все стадии агрегации: `$match`, `$group`, `$sort`, `$limit`, `$project` и другие.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | MongoDB connection string |
| **База данных** | `string` | ✅ | Имя базы данных |
| **Коллекция** | `string` | ✅ | Имя коллекции |
| **Pipeline (JSON)** | `string` | ✅ | JSON-массив стадий агрегации |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Результат (JSON)** | `string` | Массив результирующих документов в формате JSON |
| **Количество документов** | `int` | Количество документов в результате |

## Примеры

### Пример 1: Группировка и подсчёт

```
Коллекция: "orders"
Pipeline: '[
  {"$match": {"status": "completed"}},
  {"$group": {"_id": "$category", "total": {"$sum": "$amount"}}},
  {"$sort": {"total": -1}}
]'

Результат:
[
  {"_id": "electronics", "total": 150000},
  {"_id": "clothing", "total": 85000}
]
```

### Пример 2: Среднее значение

```
Pipeline: '[
  {"$match": {"year": 2025}},
  {"$group": {"_id": null, "avgPrice": {"$avg": "$price"}, "count": {"$sum": 1}}}
]'

Результат:
[{"_id": null, "avgPrice": 249.99, "count": 1500}]
```

### Пример 3: Ограничение результата

```
Pipeline: '[
  {"$sort": {"createdAt": -1}},
  {"$limit": 10}
]'

Результат: последние 10 документов
```

## Стадии агрегации

| Стадия | Описание |
|--------|----------|
| `$match` | Фильтрация документов |
| `$group` | Группировка и агрегация |
| `$sort` | Сортировка результата |
| `$limit` | Ограничение количества |
| `$skip` | Пропуск документов |
| `$project` | Выбор полей |
| `$unwind` | Разворачивание массивов |
| `$lookup` | Объединение с другой коллекцией |
