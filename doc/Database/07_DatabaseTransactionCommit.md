# БД: Подтвердить транзакцию

> **Группа:** MIA → База данных
> **Класс:** `DatabaseTransactionCommitBack`

## Назначение

Подтверждает транзакцию по явному `transactionId` или по текущему ambient-контексту.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `ID транзакции` | `string` | Необязательный идентификатор транзакции. Если заполнен, активность подтвердит именно эту транзакцию. Если поле пустое, активность попытается взять текущую DB-транзакцию из ambient-контекста, открытого предыдущим `Begin`. |

## Выходные параметры

У активности нет пользовательских выходных переменных. Успех или ошибка определяются результатом выполнения.

## Замечания

- Если `transactionId` не указан, будет использована текущая активная DB-транзакция.
- После `Commit` транзакция удаляется из менеджера и контекста.
- После успешного подтверждения дальнейшие обращения по этому `transactionId` уже недоступны, поэтому при необходимости нужно открыть новую транзакцию.
- Активность имеет смысл вызывать только после всех связанных `Query` / `NonQuery` / `BulkInsert` / `Upsert` шагов, которые должны войти в одну атомарную операцию.
