# БД: Подтвердить транзакцию

> **Группа:** MIA → База данных
> **Класс:** `DatabaseTransactionCommitBack`

## Назначение

Подтверждает транзакцию по явному `transactionId` или по текущему ambient-контексту.

## Замечания

- Если `transactionId` не указан, будет использована текущая активная DB-транзакция.
- После `Commit` транзакция удаляется из менеджера и контекста.
