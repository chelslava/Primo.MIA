# Redis: Хэш — Установить поле

> **Группа:** MIA → Redis
> **Класс:** `RedisHashSetBack`

## Назначение

Устанавливает значение одного поля в хэше Redis (операция `HSET`). Если поле уже существует — значение перезаписывается.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string |
| **Ключ** | `string` | ✅ | Ключ хэша |
| **Поле** | `string` | ✅ | Имя поля |
| **Значение** | `string` | ✅ | Значение поля |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Примеры

### Пример 1: Установка одного поля

```
Строка подключения: "localhost:6379"
Ключ: "user:42"
Поле: "name"
Значение: "Иван"

Результат: поле установлено
```

### Пример 2: Построение хэша профиля

```
1. Redis: Хэш: Установить поле
   - Ключ: "user:42"
   - Поле: "name"
   - Значение: "Иван"

2. Redis: Хэш: Установить поле
   - Ключ: "user:42"
   - Поле: "email"
   - Значение: "ivan@example.com"

3. Redis: Хэш: Установить поле
   - Ключ: "user:42"
   - Поле: "city"
   - Значение: "Москва"

Итоговый хэш:
  user:42
  ├── name: "Иван"
  ├── email: "ivan@example.com"
  └── city: "Москва"
```
