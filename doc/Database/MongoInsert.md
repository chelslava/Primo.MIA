# MongoDB: Вставить документы

> **Группа:** MIA → MongoDB
> **Класс:** `MongoInsertBack`

## Назначение

Вставляет один или несколько документов в коллекцию MongoDB. Если передан JSON-объект — выполняется `InsertOne`; если JSON-массив — `InsertMany`.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | MongoDB connection string |
| **База данных** | `string` | ✅ | Имя базы данных |
| **Коллекция** | `string` | ✅ | Имя коллекции |
| **Документ (JSON)** | `string` | ✅ | JSON-объект или JSON-массив объектов |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Вставлено документов** | `int` | Количество вставленных документов |
| **ID вставленных документов** | `List<string>` | Список `_id` вставленных документов |

## Примеры

### Пример 1: Вставка одного документа

```
Строка подключения: "mongodb://localhost:27017"
База данных: "shop"
Коллекция: "products"
Документ (JSON): '{"name":"Телефон","price":29999,"inStock":true}'

Результат:
  Вставлено документов: 1
  ID вставленных документов: ["65f8a3b2c1d2e3f4a5b6c7d8"]
```

### Пример 2: Вставка нескольких документов

```
Документ (JSON): '[
  {"name":"Телефон","price":29999},
  {"name":"Ноутбук","price":79999},
  {"name":"Наушники","price":5999}
]'

Результат:
  Вставлено документов: 3
  ID вставленных документов: ["id1", "id2", "id3"]
```
