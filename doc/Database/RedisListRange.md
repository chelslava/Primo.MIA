# Redis: Список — Получить диапазон

> **Группа:** MIA → Redis
> **Класс:** `RedisListRangeBack`

## Назначение

Возвращает элементы списка Redis в заданном диапазоне (операция `LRANGE`). Индексация начинается с 0.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string |
| **Ключ** | `string` | ✅ | Ключ списка |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Начало диапазона** | `int` | `0` | Индекс начального элемента (`0` = первый) |
| **Конец диапазона** | `int` | `-1` | Индекс конечного элемента (`-1` = до конца списка) |
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Значения** | `List<string>` | Список элементов в заданном диапазоне |

## Примеры

### Пример 1: Получить все элементы

```
Ключ: "queue:tasks"
Начало диапазона: 0
Конец диапазона: -1

Результат:
  Значения: ["task:1", "task:2", "task:3", "task:4", "task:5"]
```

### Пример 2: Первые N элементов

```
Ключ: "leaderboard"
Начало диапазона: 0
Конец диапазона: 9

Результат: первые 10 элементов списка
```

### Пример 3: Последний элемент

```
Начало диапазона: -1
Конец диапазона: -1

Результат: ["last-element"]
```

### Пример 4: Диапазон в середине

```
Список: ["a", "b", "c", "d", "e"]
Начало диапазона: 1
Конец диапазона: 3

Результат: ["b", "c", "d"]
```

## Индексация

```
Список:  ["first", "second", "third", "fourth"]
Индексы:     0        1         2         3
             -4       -3        -2        -1
```

| Запрос | Результат |
|--------|-----------|
| `0, -1` | Все элементы |
| `0, 0` | Только первый |
| `-1, -1` | Только последний |
| `-3, -1` | Последние 3 |
