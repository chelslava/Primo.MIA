# MongoDB: Удалить документы

> **Группа:** MIA → MongoDB
> **Класс:** `MongoDeleteBack`

## Назначение

Удаляет один или все совпадающие документы из коллекции MongoDB по заданному фильтру.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | MongoDB connection string |
| **База данных** | `string` | ✅ | Имя базы данных |
| **Коллекция** | `string` | ✅ | Имя коллекции |
| **Фильтр** | `string` | ✅ | JSON-фильтр для поиска удаляемых документов |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Удалить все совпадения** | `bool` | `false` | `true` = DeleteMany, `false` = DeleteOne |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Удалено документов** | `int` | Количество удалённых документов |

## Примеры

### Пример 1: DeleteOne — удалить первое совпадение

```
Строка подключения: "mongodb://localhost:27017"
База данных: "shop"
Коллекция: "products"
Фильтр: {"name": "Телефон"}
Удалить все совпадения: false

Результат:
  Удалено документов: 1
```

### Пример 2: DeleteMany — удалить все совпадения

```
Фильтр: {"inStock": false, "category": "outdated"}
Удалить все совпадения: true

Результат:
  Удалено документов: 42
```

### Пример 3: Удаление по дате

```
Фильтр: {"createdAt": {"$lt": {"$date": "2024-01-01T00:00:00Z"}}}
Удалить все совпадения: true

Результат: удалены все документы старше 2024 года
```

## ⚠️ Предупреждение

Операция удаления **необратима**. Будьте осторожны с фильтрами — пустой фильтр `{}` удалит **все документы** в коллекции.
