# Redis: Увеличить счётчик

> **Группа:** MIA → Redis
> **Класс:** `RedisIncrBack`

## Назначение

Увеличивает числовое значение ключа на заданный шаг (атомарная операция `INCRBY`). Если ключ не существует — создаётся со значением 0, затем применяется шаг.

Идеально для: генерации уникальных ID, счётчиков просмотров, rate limiting.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string |
| **Ключ** | `string` | ✅ | Ключ для инкремента |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Шаг инкремента** | `int` | `1` | Величина приращения |
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Новое значение** | `string` | Результирующее значение ключа после инкремента |

## Примеры

### Пример 1: Простой инкремент

```
Строка подключения: "localhost:6379"
Ключ: "counter"
Шаг инкремента: 1

Вызов 1 → Новое значение: "1"
Вызов 2 → Новое значение: "2"
Вызов 3 → Новое значение: "3"
```

### Пример 2: Инкремент с шагом

```
Ключ: "order:counter"
Шаг инкремента: 1000

Вызов 1 → Новое значение: "1000"
Вызов 2 → Новое значение: "2000"
Вызов 3 → Новое значение: "3000"
```

### Пример 3: Счётчик просмотров

```
Ключ: "page:views:homepage"
Шаг инкремента: 1

Каждый вызов увеличивает счётчик на 1
```

## Сценарии использования

### Генерация уникального номера заказа

```
1. Redis: Увеличить счётчик
   - Ключ: "order:counter"
   - Шаг: 1
   → Новое значение: "1001"
2. Присвоить: orderNumber = "ORD-" + Новое значение
   → "ORD-1001"
```

### Rate limiting

```
1. Redis: Увеличить счётчик
   - Ключ: "ratelimit:user:" + userId + ":" + currentHour
   - Шаг: 1
   → Новое значение: "15"
2. Если Новое значение > 100:
   → [Отклонить запрос — превышен лимит]
```

## Особенности

- **Атомарность**: операция выполняется атомарно, без race conditions
- **Инициализация**: если ключ не существует, он создаётся со значением 0
- **Тип возврата**: возвращается `long` (преобразуется в строку)
