# БД: Скалярное значение

> **Группа:** MIA → База данных
> **Класс:** `DatabaseScalarBack`

## Назначение

Выполняет запрос, который возвращает одно значение. Результат сохраняется как строка в invariant-культуре.

Подходит для:
- `select count(*) ...`
- `select max(...) ...`
- `select cast(getdate() as datetime)`
- вызовов stored procedure с одним возвращаемым значением

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Значение` | `string` | Результат в строковом виде |
| `Есть значение` | `bool` | `false`, если результат `null/DBNull` |
| `Тип значения` | `string` | Полное имя .NET-типа результата |
