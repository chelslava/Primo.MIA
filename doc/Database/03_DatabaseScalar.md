# БД: Скалярное значение

> **Группа:** MIA → База данных
> **Класс:** `DatabaseScalarBack`

## Назначение

Выполняет запрос, который возвращает одно значение. Результат сохраняется как строка в invariant-культуре.

Если запрос вернул `null/DBNull`, активность может подставить `Значение по умолчанию`.
Дополнительно она пытается преобразовать результат в типизированные выходы: `Int32`, `Decimal`, `Boolean`, `DateTime`.

Подходит для:
- `select count(*) ...`
- `select max(...) ...`
- `select cast(getdate() as datetime)`
- вызовов stored procedure с одним возвращаемым значением

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Значение` | `string` | Результат в строковом виде |
| `Есть значение` | `bool` | `false`, если результат `null/DBNull` |
| `Тип значения` | `string` | Полное имя .NET-типа результата |
| `Использовано значение по умолчанию` | `bool` | `true`, если был подставлен `DefaultValue` |
| `Значение как Int32` | `int` | Заполняется, если результат можно привести к `Int32` |
| `Значение как Decimal` | `decimal` | Заполняется, если результат можно привести к `Decimal` |
| `Значение как Boolean` | `bool` | Заполняется, если результат можно привести к `Boolean` |
| `Значение как DateTime` | `DateTime` | Заполняется, если результат можно привести к `DateTime` |
