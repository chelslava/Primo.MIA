# БД: Скалярное значение

> **Группа:** MIA → База данных
> **Класс:** `DatabaseScalarBack`

## Назначение

Выполняет запрос, который возвращает одно значение. Результат сохраняется как строка в invariant-культуре.

Если запрос вернул `null/DBNull`, активность может подставить `Значение по умолчанию`.
Дополнительно она пытается преобразовать результат в типизированные выходы: `Int32`, `Decimal`, `Boolean`, `DateTime`.

Подходит для:
- `select count(*) ...`
- `select max(...) ...`
- `select cast(getdate() as datetime)`
- вызовов stored procedure с одним возвращаемым значением

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Значение` | `string` | Универсальное строковое представление результата в invariant-культуре. Это основное поле, если типизация результата заранее неизвестна. |
| `Есть значение` | `bool` | `false`, если провайдер вернул `null` или `DBNull`. Полезно, когда нужно отличать пустой результат от строки `"0"` или пустой строки. |
| `Тип значения` | `string` | Полное имя .NET-типа исходного результата или подставленного значения. Удобно для диагностики и динамических сценариев. |
| `Использовано значение по умолчанию` | `bool` | `true`, если реального значения не было и активность подставила `DefaultValue`. |
| `Значение как Int32` | `int` | Заполняется только если результат можно безопасно привести к `Int32`. Удобно для `COUNT(*)`, ID и числовых счётчиков. |
| `Значение как Decimal` | `decimal` | Заполняется, если результат удалось преобразовать в `Decimal`. Подходит для сумм, цен и финансовых значений. |
| `Значение как Boolean` | `bool` | Заполняется при успешном преобразовании к `Boolean`, включая строки `0/1`. |
| `Значение как DateTime` | `DateTime` | Заполняется, если результат удалось интерпретировать как дату/время, включая ISO-строки. |

## Входные параметры

Состав входных параметров такой же, как у активности [БД: Запрос](02_DatabaseQuery.md), плюс `Значение по умолчанию`, которое используется при `null/DBNull`.
