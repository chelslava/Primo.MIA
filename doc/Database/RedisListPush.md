# Redis: Список — Добавить

> **Группа:** MIA → Redis
> **Класс:** `RedisListPushBack`

## Назначение

Добавляет значение в начало (`LPUSH`) или конец (`RPUSH`) списка Redis. Список автоматически создаётся, если не существует.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string |
| **Ключ** | `string` | ✅ | Ключ списка |
| **Значение** | `string` | ✅ | Добавляемое значение |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Направление** | `bool` | `true` | `true` = LPUSH (в начало), `false` = RPUSH (в конец) |
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Длина списка** | `long` | Новая длина списка после добавления |

## Примеры

### Пример 1: Добавление в начало (LPUSH)

```
Ключ: "queue:tasks"
Значение: "task:A"
Направление: true (LPUSH)

После добавления список: ["task:A"]
Длина списка: 1

Повторное добавление "task:B":
После: ["task:B", "task:A"]
Длина списка: 2
```

### Пример 2: Добавление в конец (RPUSH)

```
Ключ: "queue:tasks"
Значение: "task:C"
Направление: false (RPUSH)

После добавления список: ["task:B", "task:A", "task:C"]
Длина списка: 3
```

### Пример 3: Очередь задач (FIFO)

```
1. RPUSH для добавления задачи в очередь
2. LPOP для извлечения первой задачи (FIFO)
```

## Структура данных

```
Ключ: "queue:tasks"
Индекс:  [0]      [1]      [2]
Значение: "task:1" "task:2" "task:3"

LPUSH → вставляет в начало (индекс 0)
RPUSH → вставляет в конец
```
