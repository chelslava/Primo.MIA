# БД: Проверить подключение

> **Группа:** MIA → База данных
> **Класс:** `DatabaseCheckConnectionBack`

## Назначение

Открывает подключение к БД через указанный ADO.NET-провайдер, фиксирует успешность, версию сервера и время проверки.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | Например `System.Data.SqlClient` |
| `Строка подключения` | `string` | Полная connection string |
| `Таймаут команды (сек)` | `int` | Технический таймаут активности |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Подключение доступно` | `bool` | Успешно ли открылось соединение |
| `Версия сервера` | `string` | `DbConnection.ServerVersion` |
| `Время выполнения (мс)` | `int` | Сколько заняла проверка |
| `Текст ошибки` | `string` | Сообщение ошибки при неуспехе |
