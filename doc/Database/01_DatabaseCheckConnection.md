# БД: Проверить подключение

> **Группа:** MIA → База данных
> **Класс:** `DatabaseCheckConnectionBack`

## Назначение

Открывает подключение к БД через указанный ADO.NET-провайдер, фиксирует успешность, версию сервера и время проверки.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | Идентификатор ADO.NET-провайдера, по которому выбирается `DbProviderFactory`. Например: `System.Data.SqlClient`, `Npgsql`, `MySql.Data.MySqlClient`. |
| `Строка подключения` | `string` | Полная connection string для выбранной БД. Примеры для SQL Server, PostgreSQL, MySQL, Oracle, SQLite и ODBC приведены в [00_INDEX.md](00_INDEX.md). |
| `Таймаут команды (сек)` | `int` | Верхняя граница времени выполнения проверки. Полезно ограничивать при нестабильной сети или медленном DNS/маршруте до сервера. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Подключение доступно` | `bool` | `true`, если соединение удалось открыть без исключений. Используйте это поле в маршрутизации процесса или health-check шагах. |
| `Версия сервера` | `string` | Значение `DbConnection.ServerVersion`. Полезно для логирования и диагностики различий между средами. |
| `Время выполнения (мс)` | `int` | Фактическая длительность проверки подключения. Помогает отслеживать деградацию производительности канала до БД. |
| `Текст ошибки` | `string` | Сообщение последнего исключения, если подключение не удалось. Удобно писать в лог или включать в уведомления. |

## Пример

```text
Provider invariant name: "Npgsql"
Строка подключения: "Host=pg01;Port=5432;Database=demo_db;Username=robot;Password=secret;"
Таймаут команды (сек): 15
```
