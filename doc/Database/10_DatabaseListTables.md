# БД: Список таблиц

> **Группа:** MIA → База данных
> **Класс:** `DatabaseListTablesBack`

## Назначение

Возвращает список таблиц БД через schema metadata.

Активность удобна, когда нужно:
- проверить доступность целевых таблиц перед загрузкой данных
- получить список объектов для динамического выбора
- построить служебную диагностику или лог по структуре БД

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | Идентификатор ADO.NET-провайдера, через который будет вызван `GetSchema("Tables")`. От этого значения зависит, какие типы объектов и какие служебные поля вернёт провайдер. |
| `Строка подключения` | `string` | Connection string выбранной БД. Лучше использовать ту же строку, что и в основных DB-активностях процесса, чтобы список таблиц отражал тот же каталог и те же права доступа. См. примеры в [00_INDEX.md](00_INDEX.md). |
| `Имя схемы` | `string` | Необязательный фильтр по схеме. Позволяет ограничить результат, например только `dbo`, `public` или другой бизнес-схемой, если в БД много объектов. |
| `Учитывать представления` | `bool` | Если `true`, в результат могут попадать не только таблицы, но и `view`. Это полезно в сценариях, где процесс работает с логическими источниками данных, а не только с физическими таблицами. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Список таблиц` | `List<string>` | Список найденных имён таблиц или представлений. Обычно его используют для последующего перебора, проверки существования обязательных объектов или построения служебной аналитики. |
| `Количество элементов` | `int` | Сколько объектов попало в результат после применения фильтров по схеме и типу объекта. |

## Замечания

- Возвращаются именно имена объектов из schema metadata; порядок элементов зависит от конкретного провайдера.
- Если нужен полный набор атрибутов по объектам, а не только имена, лучше использовать активность [12_DatabaseGetTableSchema.md](12_DatabaseGetTableSchema.md) для конкретной таблицы.
