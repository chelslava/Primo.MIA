# MongoDB: Количество документов

> **Группа:** MIA → MongoDB
> **Класс:** `MongoCountBack`

## Назначение

Возвращает количество документов в коллекции, соответствующих заданному фильтру. Использует `CountDocuments()` для эффективного подсчёта без загрузки данных.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | MongoDB connection string |
| **База данных** | `string` | ✅ | Имя базы данных |
| **Коллекция** | `string` | ✅ | Имя коллекции |
| **Фильтр** | `string` | Нет | JSON-фильтр. По умолчанию `{}` (все документы) |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Количество документов** | `int` | Количество документов, соответствующих фильтру |

## Примеры

### Пример 1: Подсчёт всех документов

```
Строка подключения: "mongodb://localhost:27017"
База данных: "shop"
Коллекция: "products"
Фильтр: "{}"

Результат:
  Количество документов: 150
```

### Пример 2: Подсчёт с фильтром

```
Фильтр: {"category": "electronics", "inStock": true}

Результат:
  Количество документов: 23
```

### Пример 3: Проверка существования

```
Фильтр: {"email": "user@example.com"}

Результат:
  Количество документов: 1  (пользователь существует)
  или
  Количество документов: 0  (пользователь не найден)
```
