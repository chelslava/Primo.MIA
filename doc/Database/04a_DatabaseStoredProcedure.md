# БД: Stored procedure

> **Группа:** MIA → База данных
> **Класс:** `DatabaseStoredProcedureBack`

## Назначение

Вызывает stored procedure через ADO.NET с поддержкой:

- input-параметров
- inputoutput-параметров
- output-параметров
- `return value`
- выполнения внутри DB-транзакции

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | Идентификатор ADO.NET-провайдера, через который будет создано соединение и объект `DbCommand`. |
| `Строка подключения` | `string` | Полная connection string для БД. Если вызов идёт внутри уже открытой DB-транзакции, поле может не использоваться. |
| `ID транзакции` | `string` | Необязательный `transactionId` существующей DB-транзакции. Позволяет вызвать процедуру в рамках общего unit-of-work. |
| `SQL / имя процедуры` | `string` | Имя stored procedure. Дополнительный `EXEC` писать не нужно. |
| `Параметры` | `Dictionary<string,string>` | Входные `Input` параметры процедуры. Пустые значения будут переданы как `DBNull.Value`. |
| `InputOutput параметры` | `Dictionary<string,string>` | Параметры `InputOutput` с начальными значениями. После выполнения они попадают в словарь `Выходные значения`. |
| `Выходные параметры` | `List<string>` | Имена `Output` параметров, которые должны быть созданы и считаны после выполнения процедуры. |
| `Получать return value` | `bool` | Добавляет параметр `ReturnValue` и возвращает значение `RETURN` из процедуры, если провайдер это поддерживает. |
| `Размер output-параметров` | `int` | Размер буфера для `Output` и `InputOutput` параметров. Особенно важен для строковых параметров, которые возвращают текст. |
| `Таймаут команды (сек)` | `int` | Максимальная длительность выполнения stored procedure. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Выходные значения` | `Dictionary<string,string>` | Словарь значений `Output` и `InputOutput` параметров после выполнения процедуры. |
| `Return value` | `string` | Значение `RETURN`, если включён флаг получения return value и провайдер поддерживает этот механизм. |
| `Затронуто строк` | `int` | Значение `ExecuteNonQuery()`, которое возвращает провайдер после вызова процедуры. |

## Примечания

- `InputOutput параметры` после выполнения попадают в общий словарь `Выходные значения`
- если имя параметра указано без префикса, он добавляется автоматически: `@` или `:`

## Пример

```text
Provider invariant name: "System.Data.SqlClient"
SQL / имя процедуры: "dbo.ProcessDocument"
Параметры:
{
  "DocumentId": "1001",
  "UserName": "robot"
}
Выходные параметры:
new List<string> { "StatusCode", "StatusMessage" }
```
