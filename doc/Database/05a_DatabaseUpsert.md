# БД: Upsert из DataTable

> **Группа:** MIA → База данных
> **Класс:** `DatabaseUpsertBack`

## Назначение

Выполняет key-based upsert из `DataTable`.

Логика:
- по `KeyColumns` выполняется `UPDATE`
- если строка не найдена, выполняется `INSERT`

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Таблица данных` | `DataTable` | Исходные строки |
| `Provider invariant name` | `string` | ADO.NET provider |
| `Строка подключения` | `string` | Connection string |
| `ID транзакции` | `string` | Необязательный transactionId |
| `Таблица-приёмник` | `string` | Таблица назначения |
| `Ключевые колонки` | `List<string>` | Колонки для поиска существующей строки |
| `Колонки обновления` | `List<string>` | Что обновлять; если пусто, обновляются все неключевые колонки |
| `Маппинг колонок` | `Dictionary<string,string>` | `SourceColumn -> DestinationColumn`, опционально |
| `Таймаут команды (сек)` | `int` | Таймаут выполнения |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Вставлено строк` | `int` | Сколько строк было вставлено |
| `Обновлено строк` | `int` | Сколько строк было обновлено |

## Замечания

- `KeyColumns` можно задавать как по имени колонки в `DataTable`, так и по имени destination-колонки из маппинга
- `Upsert` выполняется в одной транзакции
- Для `Odbc` и `OleDb` используются позиционные параметры `?`
- Это универсальный row-by-row upsert, ориентированный на совместимость, а не на vendor-specific bulk merge
