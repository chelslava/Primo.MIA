# Redis: Установить значение

> **Группа:** MIA → Redis
> **Класс:** `RedisSetBack`

## Назначение

Записывает строковое значение по ключу в Redis с опциональным сроком хранения (TTL).

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string |
| **Ключ** | `string` | ✅ | Ключ для записи |
| **Значение** | `string` | ✅ | Значение для сохранения |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Срок хранения (сек)** | `int` | `0` | TTL в секундах. `0` = без ограничения |
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Примеры

### Пример 1: Запись без срока хранения

```
Строка подключения: "localhost:6379"
Ключ: "user:42:name"
Значение: "Иван"
Срок хранения (сек): 0

Результат: ключ записан бессрочно
```

### Пример 2: Запись с TTL (кэширование)

```
Ключ: "api:products"
Значение: "{...JSON data...}"
Срок хранения (сек): 300  (5 минут)

Результат: ключ автоматически удалится через 5 минут
```

## Сценарии использования

### Кэширование API-ответа

```
1. HTTP: Запрос
   → responseData
2. Redis: Установить
   - Ключ: "api:products:cache"
   - Значение: responseData
   - Срок хранения: 3600
3. [Продолжение процесса]
```

### Rate limiting (ограничение запросов)

```
1. Redis: Увеличить счётчик
   - Ключ: "ratelimit:user:42"
   → value
2. Если value > 100:
   → [Отклонить запрос]
```
