# БД: Начать транзакцию

> **Группа:** MIA → База данных
> **Класс:** `DatabaseTransactionBeginBack`

## Назначение

Открывает соединение, начинает транзакцию и сохраняет её как текущий DB-контекст.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | ADO.NET provider |
| `Строка подключения` | `string` | Connection string |
| `Уровень изоляции` | `DatabaseIsolationLevel` | Isolation level транзакции |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `ID транзакции` | `string` | Идентификатор открытой транзакции |
| `Начата (UTC)` | `string` | Момент старта в ISO 8601 |
