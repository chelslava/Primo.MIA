# БД: Начать транзакцию

> **Группа:** MIA → База данных
> **Класс:** `DatabaseTransactionBeginBack`

## Назначение

Открывает соединение, начинает транзакцию и сохраняет её как текущий DB-контекст.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | Идентификатор ADO.NET-провайдера, через который будет открыто соединение и создана транзакция. Здесь важно использовать тот же провайдер, который потом будет передаваться в `Query`, `Scalar`, `NonQuery`, `BulkInsert`, `Stored procedure`, `PagedQuery` и `Upsert` внутри этой транзакции. |
| `Строка подключения` | `string` | Connection string БД, в которой нужно открыть транзакцию. Все дальнейшие операции по этому `transactionId` выполняются именно на этом соединении, поэтому строка подключения должна указывать на ту же БД и тот же сервер, где ожидается атомарность операций. Примеры строк приведены в [00_INDEX.md](00_INDEX.md). |
| `Уровень изоляции` | `DatabaseIsolationLevel` | Уровень изоляции транзакции. Он влияет на поведение блокировок, видимость неподтверждённых изменений и вероятность конфликтов при параллельной работе с одними и теми же данными. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `ID транзакции` | `string` | Идентификатор открытой транзакции, который затем передаётся в `Query`, `Scalar`, `NonQuery`, `BulkInsert`, `Stored procedure`, `PagedQuery` и `Upsert`. Это основной ключ, по которому DB-модуль находит уже открытое соединение и активную транзакцию. |
| `Начата (UTC)` | `string` | Момент старта транзакции в формате ISO 8601 UTC. Полезно для логирования, диагностики "зависших" операций и контроля долгоживущих транзакций. |

## Замечания

- После `Begin` транзакция становится доступной и по явному `ID транзакции`, и как текущий DB-контекст.
- Если процесс завершается с ошибкой, стоит явно вызывать `Rollback`, чтобы не оставлять долгоживущее соединение открытым.

## Пример

```text
Provider invariant name: "System.Data.SqlClient"
Строка подключения: "Server=sql01;Database=DemoDb;Integrated Security=True;TrustServerCertificate=True;"
Уровень изоляции: ReadCommitted
```
