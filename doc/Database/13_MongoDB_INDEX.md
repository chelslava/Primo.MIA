# Документация: MongoDB активности

> **Группа в студии:** MIA → MongoDB
> **Драйвер:** MongoDB.Driver (официальный C# драйвер)
> **Версия драйвера:** настраивается через NuGet

Все активности работают с документами MongoDB в формате JSON (`BsonDocument`) и поддерживают стандартные операции CRUD.

## Общие параметры

### Основные (обязательные)

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Строка подключения** | `string` | MongoDB connection string. Пример: `mongodb://localhost:27017` |
| **База данных** | `string` | Имя базы данных |
| **Коллекция** | `string` | Имя коллекции |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Таймаут (сек)** | `int` | `30` | Максимальное время выполнения операции |

## Формат фильтров

MongoDB использует JSON-фильтры аналогично команде `find()` в оболочке Mongo.

### Примеры фильтров

```json
// Все документы
{}

 // По равенству поля
{"status": "active"}

// Вложенное поле
{"user.name": "Иван"}

// Условие
{"age": {"$gte": 18}}

// Массив
{"tags": {"$in": ["important", "urgent"]}}

// Комбинированное
{"status": "active", "age": {"$gte": 18}}
```

### Операторы сравнения

| Оператор | Описание | Пример |
|----------|----------|--------|
| `$eq` | Равно | `{"field": {"$eq": value}}` |
| `$ne` | Не равно | `{"field": {"$ne": value}}` |
| `$gt` | Больше | `{"age": {"$gt": 21}}` |
| `$gte` | Больше или равно | `{"age": {"$gte": 21}}` |
| `$lt` | Меньше | `{"age": {"$lt": 65}}` |
| `$lte` | Меньше или равно | `{"age": {"$lte": 65}}` |
| `$in` | В списке | `{"status": {"$in": ["a", "b"]}}` |
| `$nin` | Не в списке | `{"status": {"$nin": ["x"]}}` |

## Формат обновлений

```json
// Установить значение поля
{"$set": {"status": "completed"}}

// Увеличить числовое поле
{"$inc": {"views": 1}}

// Удалить поле
{"$unset": {"temporary": ""}}

// Добавить в массив
{"$push": {"tags": "new-tag"}}
```

---

## Формат сортировки

```json
// По возрастанию поля name
{"name": 1}

// По убыванию поля createdAt
{"createdAt": -1}

// Множественная сортировка
{"priority": -1, "name": 1}
```

---

## Формат проекции

```json
// Включить только поля name и email
{"name": 1, "email": 1}

// Исключить поле _id
{"_id": 0, "password": 0}
```

## Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Строка подключения обязательна` | Пустое поле connection string | Укажите валидный MongoDB connection string |
| `База данных обязательна` | Пустое поле database | Укажите имя базы данных |
| `Коллекция обязательна` | Пустое поле collection | Укажите имя коллекции |
| `Ошибка MongoDB: ...` | Ошибка драйвера | Проверьте доступность сервера, корректность фильтра |

## Подключение к MongoDB Atlas

Пример строки подключения для MongoDB Atlas:

```
mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/<database>?retryWrites=true&w=majority
```

## Сравнение с SQL

| MongoDB | SQL |
|---------|-----|
| Коллекция (Collection) | Таблица (Table) |
| Документ (Document) | Строка (Row) |
| Поле (Field) | Колонка (Column) |
| `_id` | Первичный ключ |
| `$set` | UPDATE SET |
| `$inc` | UPDATE SET col = col + n |
