# Redis: Получить значение

> **Группа:** MIA → Redis
> **Класс:** `RedisGetBack`

## Назначение

Получает строковое значение по ключу из Redis. Если ключ отсутствует — возвращает пустую строку и `Ключ существует = false`.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string. Пример: `localhost:6379` |
| **Ключ** | `string` | ✅ | Ключ для получения значения |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Значение** | `string` | Полученное значение или пустая строка |
| **Ключ существует** | `bool` | `true`, если ключ найден в Redis |

## Примеры

### Пример 1: Получение существующего ключа

```
Строка подключения: "localhost:6379"
Ключ: "user:42:name"

Результат:
  Значение: "Иван"
  Ключ существует: true
```

### Пример 2: Получение несуществующего ключа

```
Ключ: "nonexistent:key"

Результат:
  Значение: ""
  Ключ существует: false
```

## Сценарии использования

### Кэширование API-ответа

```
1. Redis: Получить
   - Ключ: "api:users:42"
   → Ключ существует: true
   → Значение: "{...JSON...}"
   
2. [Использовать данные из кэша]

[ELSE]

3. HTTP: Запрос → получить свежие данные
4. Redis: Установить → записать в кэш
```
