# БД: Список колонок

> **Группа:** MIA → База данных
> **Класс:** `DatabaseListColumnsBack`

## Назначение

Возвращает список колонок указанной таблицы через `GetSchema("Columns")`.

Активность полезна, когда нужно:
- проверить соответствие входного `DataTable` структуре таблицы назначения
- динамически строить mappings или SQL
- валидировать наличие обязательных колонок перед `BulkInsert` или `Upsert`

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | Идентификатор ADO.NET-провайдера, через который будет выполнено чтение metadata по колонкам. Разные провайдеры могут по-разному обрабатывать регистр имён и схему поиска. |
| `Строка подключения` | `string` | Connection string выбранной БД. Рекомендуется использовать ту же строку, что и в активностях записи/чтения, чтобы получать metadata именно того окружения, с которым работает процесс. См. примеры в [00_INDEX.md](00_INDEX.md). |
| `Имя таблицы` | `string` | Имя таблицы, для которой нужно получить список колонок. Обычно передаётся имя без схемы, а схема указывается отдельным параметром. |
| `Имя схемы` | `string` | Необязательное имя схемы, например `dbo` или `public`. Помогает исключить неоднозначность, если одинаковые имена таблиц существуют в нескольких схемах. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Список колонок` | `List<string>` | Список имён колонок целевой таблицы. Его можно использовать для проверки `ColumnMappings`, генерации SQL или сравнения со структурой входного `DataTable`. |
| `Количество элементов` | `int` | Сколько колонок найдено в metadata выбранной таблицы. Это значение удобно для быстрой валидации ожидаемой структуры. |

## Замечания

- Активность возвращает только имена колонок. Если нужны типы данных, nullable и другие атрибуты, используйте [12_DatabaseGetTableSchema.md](12_DatabaseGetTableSchema.md).
- В некоторых провайдерах системные и вычисляемые колонки могут отображаться в metadata иначе, чем ожидается по бизнес-логике, поэтому лучше проверять результат на целевой БД.
