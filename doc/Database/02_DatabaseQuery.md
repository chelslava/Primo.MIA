# БД: Запрос

> **Группа:** MIA → База данных
> **Класс:** `DatabaseQueryBack`
> **Тип результата:** `DataTable`

## Назначение

Выполняет SQL-запрос или stored procedure и возвращает табличный результат в `DataTable`.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Provider invariant name` | `string` | Идентификатор ADO.NET-провайдера. Определяет, какой драйвер будет создавать соединение, команду и `DataAdapter`. |
| `Строка подключения` | `string` | Полная connection string для выбранной БД. Если активность запускается внутри DB-транзакции, поле можно не использовать. |
| `Тип команды` | `DatabaseCommandType` | `Text` для обычного SQL или `StoredProcedure` для вызова процедуры, которая возвращает табличный результат. |
| `SQL / имя процедуры` | `string` | Исходный SQL-текст или имя stored procedure. Для `Text` это обычно `SELECT ...`, для `StoredProcedure` — имя процедуры без дополнительного `EXEC`. |
| `Параметры` | `Dictionary<string,string>` | Необязательные параметры команды. Ключ — имя параметра, значение — строковое значение; пустая строка будет преобразована в `DBNull.Value`. |
| `Таймаут команды (сек)` | `int` | Максимальное время выполнения запроса до генерации исключения по timeout. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Таблица-результат` | `DataTable` | Полный табличный результат запроса. Его можно сразу передавать в активности обработки `DataTable`, HTML-рендеринг или дальнейшую загрузку в БД. |
| `RowCount` | `int` | Количество строк в `DataTable`. Удобно для быстрых проверок пустой/непустой выборки без отдельного `COUNT(*)`. |
| `ColumnCount` | `int` | Количество колонок в результирующей таблице. Полезно для валидации ожидаемой формы результата. |
| `Список колонок` | `List<string>` | Имена колонок в том порядке, в котором их вернул провайдер. Помогает в динамических сценариях маппинга. |
| `Есть строки` | `bool` | `true`, если выборка содержит хотя бы одну строку. Удобный shortcut для branching в процессе. |

## Пример

```text
Provider invariant name: "System.Data.SqlClient"
Строка подключения: dbConn
Тип команды: Text
SQL / имя процедуры: "select top 100 * from dbo.Users where Status = @Status"
Параметры: dbParams
Таблица-результат: usersTable
```
