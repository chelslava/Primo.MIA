# MongoDB: Обновить документы

> **Группа:** MIA → MongoDB
> **Класс:** `MongoUpdateBack`

## Назначение

Обновляет один или все совпадающие документы в коллекции MongoDB по заданному фильтру.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | MongoDB connection string |
| **База данных** | `string` | ✅ | Имя базы данных |
| **Коллекция** | `string` | ✅ | Имя коллекции |
| **Фильтр** | `string` | ✅ | JSON-фильтр для поиска документов |
| **Обновление (JSON)** | `string` | ✅ | JSON-выражение обновления |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Обновить все совпадения** | `bool` | `false` | `true` = UpdateMany, `false` = UpdateOne |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Совпало документов** | `int` | Количество документов, совпавших с фильтром |
| **Обновлено документов** | `int` | Количество фактически изменённых документов |

## Примеры

### Пример 1: UpdateOne — обновить первое совпадение

```
Строка подключения: "mongodb://localhost:27017"
База данных: "shop"
Коллекция: "products"
Фильтр: {"name": "Телефон"}
Обновление (JSON): '{"$set": {"price": 24999}}'
Обновить все совпадения: false

Результат:
  Совпало документов: 1
  Обновлено документов: 1
```

### Пример 2: UpdateMany — обновить все совпадения

```
Фильтр: {"category": "electronics", "inStock": true}
Обновление (JSON): '{"$set": {"discount": 10}}'
Обновить все совпадения: true

Результат:
  Совпало документов: 15
  Обновлено документов: 15
```

### Пример 3: Инкремент числового поля

```
Фильтр: {"name": "Телефон"}
Обновление (JSON): '{"$inc": {"views": 1}}'

Результат: поле views увеличено на 1
```

## Операторы обновления

```json
// $set — установить значение
{"$set": {"field": "value"}}

// $inc — увеличить/уменьшить число
{"$inc": {"field": 1}}
{"$inc": {"field": -1}}

// $unset — удалить поле
{"$unset": {"temporary": ""}}

// $push — добавить в массив
{"$push": {"tags": "new-tag"}}

// $pull — удалить из массива
{"$pull": {"tags": "old-tag"}}

// $rename — переименовать поле
{"$rename": {"oldName": "newName"}}
```
