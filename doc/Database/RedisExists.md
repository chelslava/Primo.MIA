# Redis: Проверить существование

> **Группа:** MIA → Redis
> **Класс:** `RedisExistsBack`

## Назначение

Проверяет наличие ключа в Redis без получения его значения. Быстрая операция — не загружает данные.

## Входные параметры

### Основные

| Параметр | Тип | Обязательность | Описание |
|----------|-----|----------------|----------|
| **Строка подключения** | `string` | ✅ | Redis connection string |
| **Ключ** | `string` | ✅ | Имя ключа для проверки |

### Настройки

| Параметр | Тип | По умолч. | Описание |
|----------|-----|-----------|----------|
| **Индекс БД** | `int` | `0` | Индекс базы данных Redis (0–15) |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Ключ существует** | `bool` | `true`, если ключ присутствует в Redis |

## Примеры

### Пример 1: Ключ существует

```
Строка подключения: "localhost:6379"
Ключ: "session:abc123"

Результат:
  Ключ существует: true
```

### Пример 2: Ключ не существует

```
Ключ: "expired:session:xyz"

Результат:
  Ключ существует: false
```

## Сценарии использования

### Проверка сессии

```
1. Redis: Проверить существование
   - Ключ: "session:" + sessionId
   → Ключ существует: true/false
   
2. Если false:
   → [Создать новую сессию]
3. Иначе:
   → [Продолжить с существующей]
```

### Очередь задач

```
1. Redis: Проверить существование
   - Ключ: "queue:tasks"
   → Ключ существует: true
   
2. Если true:
   → [Обработать задачи]
3. Иначе:
   → [Завершить без действий]
```
