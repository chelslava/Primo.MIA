# Активность "Ожидание нового файла" (WaitForFileBack)

## Описание

Активность предназначена для ожидания появления **нового файла** в указанной директории. Активность отслеживает только те файлы, которые появились **после** начала её работы, игнорируя файлы, существовавшие до запуска.

## Основные возможности

- ✅ Ожидание появления нового файла в директории
- ✅ Поддержка **wildcard** масок (`*.txt`, `report_*.xlsx`)
- ✅ Поддержка **regex** паттернов для сложной фильтрации
- ✅ Ожидание завершения записи файла (стабильность размера)
- ✅ Гибкая настройка таймаутов и интервалов проверки
- ✅ Детальная информация о найденном файле
- ✅ Возможность выброса исключения при таймауте

## Входные параметры

### Обязательные параметры

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| **Путь к директории** | `string` | Путь к директории для мониторинга | `"C:\Downloads"` |
| **Маска файла** | `string` | Маска или паттерн для фильтрации файлов | `"*.xlsx"`, `"report_*.pdf"` |
| **Таймаут (сек)** | `int` | Время ожидания в секундах | `30` |
| **Интервал проверки (мс)** | `int` | Интервал между проверками в миллисекундах | `500` |
| **Время стабильности (мс)** | `int` | Время стабильности размера файла | `2000` |

### Опциональные параметры (галочки)

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| **Ожидать завершения записи** | `bool` | `false` | Ждать, пока размер файла стабилизируется |
| **Использовать wildcard** | `bool` | `true` | Использовать wildcard символы `*` и `?` |
| **Использовать regex** | `bool` | `false` | Использовать regex паттерны (приоритет над wildcard) |
| **Ошибка при таймауте** | `bool` | `false` | Выбрасывать исключение при истечении таймаута |

## Выходные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| **Файл найден** | `bool` | Флаг успешного обнаружения нового файла |
| **Путь к файлу** | `string` | Полный путь к найденному файлу |
| **Имя файла** | `string` | Только имя файла без пути |
| **Размер файла (байт)** | `long` | Размер файла в байтах |
| **Время ожидания (мс)** | `long` | Фактическое время ожидания в миллисекундах |

## Режимы фильтрации файлов

### 1. Точное совпадение
Используется когда **wildcard** и **regex** отключены.

```
Маска файла: "report.xlsx"
Найдет только: report.xlsx
```

### 2. Wildcard фильтрация (по умолчанию)
Используется когда **wildcard** включен.

| Маска | Описание | Примеры совпадений |
|-------|----------|-------------------|
| `*.txt` | Все текстовые файлы | `file.txt`, `document.txt` |
| `report_*.xlsx` | Excel файлы начинающиеся с "report_" | `report_2025.xlsx`, `report_final.xlsx` |
| `data_?.csv` | CSV файлы с одним символом после "data_" | `data_1.csv`, `data_A.csv` |
| `*` | Все файлы | Любые файлы |

### 3. Regex фильтрация (приоритет над wildcard)
Используется когда **regex** включен. Имеет приоритет над wildcard.

| Паттерн | Описание | Примеры совпадений |
|---------|----------|-------------------|
| `^report_\d{8}\.xlsx$` | Excel файлы с 8 цифрами в имени | `report_20250215.xlsx` |
| `^invoice_[A-Z]{3}\d{4}\.pdf$` | PDF счета с кодом | `invoice_ABC1234.pdf` |
| `.*\.log$` | Все лог файлы | `app.log`, `error.log` |
| `^data_\d{4}-\d{2}-\d{2}\.csv$` | CSV с датой в имени | `data_2025-02-15.csv` |

## Алгоритм работы

```
1. Запуск активности
   ↓
2. Сохранение списка всех существующих файлов в директории
   ↓
3. Цикл проверки (каждые "Интервал проверки" мс):
   ├─ Получение списка файлов, соответствующих маске
   ├─ Фильтрация: оставляем только НОВЫЕ файлы
   ├─ Если новый файл найден:
   │  ├─ Если "Ожидать завершения записи" = true:
   │  │  ├─ Ожидание стабильности размера
   │  │  └─ Возврат файла
   │  └─ Иначе: возврат файла сразу
   └─ Если таймаут истек:
      ├─ Если "Ошибка при таймауте" = true: выброс исключения
      └─ Иначе: возврат с флагом "Файл найден" = false
```

## Особенности работы

### ✅ Что считается "новым" файлом?

Файл считается новым, если:
1. Он **отсутствовал** в директории на момент запуска активности
2. Он **соответствует** заданной маске или паттерну

### ⚙️ Ожидание завершения записи

Когда включена опция "Ожидать завершения записи":
- Активность проверяет размер файла каждые "Интервал проверки" мс
- Если размер не меняется в течение "Время стабильности" мс, файл считается полностью записанным
- Полезно при загрузке больших файлов или копировании по сети

### 🎯 Возврат первого файла

Если несколько новых файлов соответствуют маске:
- Возвращается **первый** по времени создания (самый старый из новых)
- Это гарантирует обработку файлов в порядке их появления

### ⏱️ Таймауты

```
Общий таймаут = Таймаут (сек) × 1000 мс

Если включено "Ожидать завершения записи":
  Общий таймаут = Время ожидания появления + Время ожидания стабильности
  
Рекомендуется:
  Таймаут ≥ Время стабильности / 1000 + запас на появление файла
```

## Обработка ошибок

### Типичные ошибки и решения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Директория не найдена` | Указан несуществующий путь | Проверить правильность пути к директории |
| `Путь к директории не может быть пустым` | Не заполнено обязательное поле | Указать путь к директории |
| `Маска файла не может быть пустой` | Не заполнено обязательное поле | Указать маску файла |
| `Некорректный regex паттерн` | Синтаксическая ошибка в regex | Проверить корректность regex выражения |
| `Таймаут должен быть больше нуля` | Некорректное значение | Указать положительное значение |
| `Таймаут ожидания нового файла истек` | Файл не появился за отведенное время | Увеличить таймаут или проверить условия |

## Диагностика и отладка

### 🔍 Как проверить работу активности?

1. **Проверьте выходной параметр "Время ожидания"**
   - Если время ≈ таймаут → файл не появился
   - Если время < таймаут → файл был найден

2. **Используйте логирование**
   ```
   Запишите в лог:
   - Файл найден: {fileFound}
   - Путь к файлу: {filePath}
   - Время ожидания: {waitTime} мс
   ```

3. **Тестируйте на заранее подготовленных файлах**
   - Создайте тестовую директорию
   - Скопируйте туда файл во время работы активности
   - Проверьте, что он обнаружен

### ⚠️ Частые проблемы

**Проблема**: Активность не находит файл, хотя он есть
- **Причина 1**: Файл существовал до запуска активности
- **Решение**: Активность ищет только НОВЫЕ файлы

- **Причина 2**: Маска не совпадает с именем файла
- **Решение**: Проверьте правильность wildcard/regex паттерна

**Проблема**: Активность завершается по таймауту слишком рано
- **Причина**: Файл копируется дольше, чем установлен таймаут
- **Решение**: Увеличьте таймаут и/или время стабильности

**Проблема**: Regex паттерн не работает
- **Причина**: Некорректный синтаксис regex
- **Решение**: Проверьте паттерн на https://regex101.com/
