# Браузер: Навигация

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserNavigateBack`  
> **Тип результата:** `void`

## Назначение

Выполняет навигацию в браузере: переход по URL, навигация по истории (назад/вперед), обновление страницы.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Режим** | `NavigateMode` | Да | Тип навигации (ToUrl, Back, Forward, Refresh) |
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **URL** | `string` | Для ToUrl | Адрес для перехода (только для режима ToUrl) |

### Режимы навигации

| Режим | Описание |
|---|---|
| `ToUrl` | Переход по указанному URL |
| `Back` | Назад в истории браузера |
| `Forward` | Вперед в истории браузера |
| `Refresh` | Обновление текущей страницы |

### Выходные

Нет выходных параметров.

---

## Примеры использования

**Переход на веб-сайт:**
```
Режим: ToUrl
ID сессии: browserSession
URL: "https://example.com"
```

**Навигация назад после ошибки:**
```
Try:
  - ElementClick (кнопка "Далее")
  - ... проверка результата ...
Catch:
  - BrowserNavigate (Режим: Back, ID сессии: browserSession)
```

**Обновление страницы для получения актуальных данных:**
```
Loop:
  - BrowserNavigate (Режим: Refresh, ID сессии: browserSession)
  - ElementGetInfo (проверка статуса)
  - Delay (5 секунд)
```

**Навигация по истории:**
```
BrowserNavigate (Режим: Back, ID сессии: browserSession)
Delay (1 секунда)
BrowserNavigate (Режим: Forward, ID сессии: browserSession)
```

---

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `ArgumentException` | URL пустой для режима ToUrl | Указать корректный URL |
| `WebDriverException` | Невозможно загрузить страницу | Проверить доступность URL |
| `TimeoutException` | Превышен таймаут загрузки (60 сек) | Увеличить таймаут или проверить соединение |
| `InvalidOperationException` | Нет истории для Back/Forward | Проверить наличие истории навигации |

---

## Форматы URL

**Поддерживаемые протоколы:**
- `https://example.com` — безопасное соединение
- `http://example.com` — обычное соединение
- `file:///C:/path/file.html` — локальный файл
- `about:blank` — пустая страница

**Примеры URL:**
```
"https://www.google.com"
"http://localhost:8080/app"
"file:///C:/Users/User/Desktop/page.html"
"about:blank"
```

## Лучшие практики

✅ **Рекомендуется:**
- Использовать HTTPS для безопасности
- Добавлять задержку после навигации (500мс)
- Проверять успешность загрузки страницы
- Использовать BrowserWaitFor после навигации
- Обрабатывать ошибки навигации

❌ **Не рекомендуется:**
- Переходить на небезопасные сайты без проверки
- Использовать Back/Forward без проверки истории
- Игнорировать таймауты загрузки
- Выполнять навигацию без ожидания загрузки
- Использовать Refresh в бесконечном цикле без задержки

## Технические детали

- Таймаут загрузки страницы: 60 секунд
- Автоматическая пауза после навигации: 500мс
- Поддержка редиректов
- Обработка JavaScript редиректов
- Ожидание события DOMContentLoaded

## Troubleshooting

**Страница не загружается:**
- Проверить доступность URL
- Проверить интернет-соединение
- Увеличить таймаут
- Проверить наличие блокировщиков

**Ошибка "Нет истории":**
- Убедиться, что выполнялась навигация
- Проверить, что не используется режим Incognito
- Проверить, что браузер не был перезапущен

**Refresh не обновляет данные:**
- Проверить кэширование браузера
- Использовать Ctrl+F5 через SendKeys
- Очистить cookies перед обновлением
- Проверить, что данные не статичны

**Медленная загрузка:**
- Оптимизировать размер страницы
- Использовать headless режим
- Отключить загрузку изображений
- Проверить скорость соединения
