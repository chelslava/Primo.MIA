# Элемент: Проверить существование

> **Группа:** MIA → Браузер  
> **Класс:** `ElementExistsBack`  
> **Тип результата:** `bool`

## Назначение

Проверяет наличие элемента на странице без выброса исключения. Используется для условной логики.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Тип локатора** | `ElementLocatorType` | Да | Способ поиска элемента |
| **Значение локатора** | `string` | Да | Конкретное значение для поиска |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Существует** | `bool` | true если элемент найден |

---

## Примеры использования

**Проверка наличия кнопки:**
```
Тип локатора: Id
Значение: "submitButton"
Существует: buttonExists

If (buttonExists):
  - ElementClick (...)
```

**Проверка сообщения об ошибке:**
```
Тип локатора: ClassName
Значение: "error-message"
Существует: hasError

If (hasError):
  - LogMessage ("Обнаружена ошибка")
```

**Условное выполнение:**
```
ElementExists (Локатор: ".modal", Существует: modalVisible)
If (modalVisible):
  - ElementClick (".modal-close")
```
