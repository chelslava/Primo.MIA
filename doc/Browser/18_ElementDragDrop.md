# Элемент: Drag & Drop

> **Группа:** MIA → Браузер  
> **Класс:** `ElementDragDropBack`  
> **Тип результата:** `void`

## Назначение

Выполняет перетаскивание элемента из одной позиции в другую. Поддерживает перетаскивание на элемент или на координаты.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID исходного элемента** | `string` | Если нет локатора | ID элемента для перетаскивания |
| **Тип локатора (исходный)** | `ElementLocatorType` | Если нет ID | Способ поиска источника |
| **Значение локатора (исходный)** | `string` | Если нет ID | Значение для поиска источника |
| **ID целевого элемента** | `string` | Если нет смещения | ID целевого элемента |
| **Тип локатора (целевой)** | `ElementLocatorType` | Если нет ID цели | Способ поиска цели |
| **Значение локатора (целевой)** | `string` | Если нет ID цели | Значение для поиска цели |
| **Смещение X** | `int` | Если нет цели | Смещение по X (пиксели) |
| **Смещение Y** | `int` | Если нет цели | Смещение по Y (пиксели) |
| **Использовать JavaScript** | `bool` | Нет | JS для сложных случаев |
| **Таймаут ожидания** | `int` | Нет | Время ожидания (сек), по умолчанию 10 |

---

## Примеры использования

**Перетаскивание на элемент:**
```
Тип локатора (исходный): Id
Значение (исходный): "draggable"
Тип локатора (целевой): Id
Значение (целевой): "dropzone"
```

**Перетаскивание на координаты:**
```
Тип локатора (исходный): ClassName
Значение: "item"
Смещение X: 100
Смещение Y: 50
```

**Drag & Drop через JavaScript:**
```
Локатор (исходный): "#source"
Локатор (целевой): "#target"
Использовать JavaScript: true
```
