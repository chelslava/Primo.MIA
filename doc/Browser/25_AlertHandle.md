# Браузер: Обработка Alert

> **Группа:** MIA → Браузер  
> **Класс:** `AlertHandleBack`  
> **Тип результата:** `void` (текст в выходной переменной)

## Назначение

Работает с JavaScript алертами, подтверждениями (confirm) и промптами (prompt). Поддерживает принятие, отклонение, чтение текста и ввод данных.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Действие** | `AlertAction` | Да | Accept, Dismiss, GetText или SendKeys |
| **Текст для ввода** | `string` | Для SendKeys | Текст для ввода в prompt |

### Действия с алертом

| Действие | Описание |
|---|---|
| `Accept` | Принять алерт (нажать OK) |
| `Dismiss` | Отклонить алерт (нажать Cancel) |
| `GetText` | Получить текст алерта |
| `SendKeys` | Ввести текст в prompt и принять |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Текст алерта** | `string` | Содержимое сообщения алерта |

---

## Примеры использования

**Принятие простого alert:**
```
AlertHandle (
  ID сессии: browserSession,
  Действие: Accept
)
```

**Чтение текста confirm:**
```
AlertHandle (
  ID сессии: browserSession,
  Действие: GetText,
  Текст алерта: alertMessage
)
LogMessage (alertMessage)
```

**Ввод в prompt:**
```
AlertHandle (
  ID сессии: browserSession,
  Действие: SendKeys,
  Текст для ввода: "Мой ответ"
)
```

**Отклонение confirm:**
```
AlertHandle (
  ID сессии: browserSession,
  Действие: Dismiss
)
```

**Обработка с проверкой текста:**
```
AlertHandle (Действие: GetText, Текст: alertText)
If (alertText.Contains("Удалить")):
  - AlertHandle (Действие: Accept)
Else:
  - AlertHandle (Действие: Dismiss)
```

---

## Типы JavaScript диалогов

**Alert:**
```javascript
alert("Сообщение");
```
- Только кнопка OK
- Используйте Accept для закрытия

**Confirm:**
```javascript
confirm("Подтвердите действие");
```
- Кнопки OK и Cancel
- Accept для OK, Dismiss для Cancel

**Prompt:**
```javascript
prompt("Введите значение", "default");
```
- Поле ввода и кнопки OK/Cancel
- SendKeys для ввода и принятия

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `NoAlertPresentException` | Алерт не найден | Проверить наличие алерта |
| `ArgumentException` | Пустой текст для SendKeys | Указать текст для ввода |
| `UnhandledAlertException` | Алерт не обработан | Обработать алерт перед продолжением |

## Лучшие практики

✅ **Рекомендуется:**
- Проверять наличие алерта перед обработкой
- Читать текст перед принятием
- Использовать try-catch для обработки
- Обрабатывать алерты сразу после появления
- Логировать текст алертов

❌ **Не рекомендуется:**
- Игнорировать алерты
- Принимать без чтения текста
- Использовать SendKeys для alert/confirm
- Оставлять алерты необработанными
- Предполагать наличие алерта

## Troubleshooting

**Алерт не обнаружен:**
- Добавить ожидание перед обработкой
- Проверить, что алерт действительно появляется
- Убедиться, что это JavaScript алерт, а не HTML модальное окно
- Проверить таймауты

**Текст не читается:**
- Убедиться, что алерт существует
- Проверить кодировку текста
- Попробовать Accept перед GetText

**SendKeys не работает:**
- Убедиться, что это prompt, а не alert
- Проверить, что текст не пустой
- Попробовать Accept после SendKeys
