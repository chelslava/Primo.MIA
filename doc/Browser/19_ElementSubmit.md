# Элемент: Отправить форму

> **Группа:** MIA → Браузер  
> **Класс:** `ElementSubmitBack`  
> **Тип результата:** `void`

## Назначение

Отправляет HTML форму через элемент формы или кнопку submit. Эквивалентно нажатию Enter в поле формы.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента формы |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска |
| **Значение локатора** | `string` | Если нет ID | Значение для поиска |
| **Таймаут ожидания** | `int` | Нет | Время ожидания (сек), по умолчанию 10 |

---

## Примеры использования

**Отправка формы:**
```
Тип локатора: Id
Значение: "loginForm"
```

**Отправка через поле ввода:**
```
Тип локатора: Name
Значение: "search"
```

**Отправка после заполнения:**
```
ElementInput (Локатор: "#username", Текст: "user")
ElementInput (Локатор: "#password", Текст: "pass")
ElementSubmit (Локатор: "#loginForm")
```

---

## Примечания

- Работает с элементами внутри формы или самой формой
- Эквивалентно нажатию Enter
- Не требует поиска кнопки submit
- Автоматически триггерит submit событие
