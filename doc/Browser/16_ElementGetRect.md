# Элемент: Получить размер и позицию

> **Группа:** MIA → Браузер  
> **Класс:** `ElementGetRectBack`  
> **Тип результата:** `void` (данные в выходных переменных)

## Назначение

Получает координаты и размеры элемента на странице: X, Y, ширину и высоту.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска |
| **Значение локатора** | `string` | Если нет ID | Значение для поиска |
| **Таймаут ожидания** | `int` | Нет | Время ожидания (сек), по умолчанию 10 |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **X** | `int` | Координата левого верхнего угла |
| **Y** | `int` | Координата левого верхнего угла |
| **Ширина** | `int` | Ширина элемента в пикселях |
| **Высота** | `int` | Высота элемента в пикселях |

---

## Примеры использования

**Получение позиции элемента:**
```
Тип локатора: Id
Значение: "element"
X: posX
Y: posY
Ширина: width
Высота: height
```

**Проверка размера:**
```
ElementGetRect (Локатор: "image", Ширина: w, Высота: h)
If (w > 500 OR h > 500):
  - LogMessage ("Изображение слишком большое")
```

**Вычисление центра:**
```
ElementGetRect (X: x, Y: y, Ширина: w, Высота: h)
centerX = x + (w / 2)
centerY = y + (h / 2)
```
