# Браузер: Ожидание условия

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserWaitForBack`  
> **Тип результата:** `bool`

## Назначение

Ожидает выполнения условия в браузере: появление элемента, изменение URL, появление текста или alert.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Условие** | `WaitConditionType` | Да | Тип проверяемого условия |
| **Тип локатора** | `ElementLocatorType` | Для условий с элементами | Способ поиска |
| **Значение локатора** | `string` | Для условий с элементами | Значение для поиска |
| **Текст** | `string` | Для текстовых условий | Строка для проверки |
| **Таймаут** | `int` | Нет | Максимальное время ожидания (сек), по умолчанию 30 |

### Типы условий

| Условие | Описание |
|---|---|
| `ElementExists` | Элемент существует в DOM |
| `ElementVisible` | Элемент видим |
| `ElementClickable` | Элемент кликабелен |
| `ElementInvisible` | Элемент невидим |
| `TextPresent` | Текст присутствует в элементе |
| `TitleContains` | Заголовок содержит текст |
| `UrlContains` | URL содержит текст |
| `AlertPresent` | Alert присутствует |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Условие выполнено** | `bool` | true если условие выполнилось |
| **Время ожидания** | `int` | Фактическое время ожидания (мс) |

---

## Примеры использования

**Ожидание элемента:**
```
Условие: ElementVisible
Тип локатора: Id
Значение: "submitButton"
Таймаут: 10
```

**Ожидание изменения URL:**
```
Условие: UrlContains
Текст: "/dashboard"
Таймаут: 15
```

**Ожидание alert:**
```
Условие: AlertPresent
Таймаут: 5
```
