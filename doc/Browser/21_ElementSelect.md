# Элемент: Выбрать из списка

> **Группа:** MIA → Браузер  
> **Класс:** `ElementSelectBack`  
> **Тип результата:** `void`

## Назначение

Выбирает опцию из выпадающего списка (select). Поддерживает выбор по тексту, значению или индексу.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента select |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска |
| **Значение локатора** | `string` | Если нет ID | Значение для поиска |
| **Режим выбора** | `SelectMode` | Да | ByText, ByValue или ByIndex |
| **Значение для выбора** | `string` | Да | Текст, value или индекс |
| **Таймаут ожидания** | `int` | Нет | Время ожидания (сек), по умолчанию 10 |

### Режимы выбора

| Режим | Описание |
|---|---|
| `ByText` | По видимому тексту опции |
| `ByValue` | По значению атрибута value |
| `ByIndex` | По порядковому номеру (с 0) |

---

## Примеры использования

**Выбор по тексту:**
```
Режим выбора: ByText
Тип локатора: Id
Значение локатора: "country"
Значение для выбора: "Россия"
```

**Выбор по value:**
```
Режим выбора: ByValue
Тип локатора: Name
Значение локатора: "status"
Значение для выбора: "active"
```

**Выбор по индексу:**
```
Режим выбора: ByIndex
Тип локатора: Id
Значение локатора: "month"
Значение для выбора: "0"  // Первая опция
```
