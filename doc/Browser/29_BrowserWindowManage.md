# Браузер: Управление окном

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserWindowManageBack`  
> **Тип результата:** `void` (данные в выходных переменных)

## Назначение

Управляет окном браузера: изменение размера, позиции, развертывание, свертывание.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Операция** | `WindowOperation` | Да | Тип операции с окном |
| **Ширина** | `int` | Для SetSize | Ширина окна (пиксели) |
| **Высота** | `int` | Для SetSize | Высота окна (пиксели) |
| **X** | `int` | Для SetPosition | Позиция X (пиксели) |
| **Y** | `int` | Для SetPosition | Позиция Y (пиксели) |

### Операции

| Операция | Описание |
|---|---|
| `Maximize` | Развернуть на весь экран |
| `Minimize` | Свернуть окно |
| `FullScreen` | Полноэкранный режим |
| `SetSize` | Установить размер |
| `SetPosition` | Установить позицию |
| `GetSize` | Получить текущий размер |
| `GetPosition` | Получить текущую позицию |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Ширина** | `int` | Текущая ширина окна |
| **Высота** | `int` | Текущая высота окна |
| **X** | `int` | Текущая позиция X |
| **Y** | `int` | Текущая позиция Y |

---

## Примеры использования

**Развернуть окно:**
```
Операция: Maximize
```

**Установить размер:**
```
Операция: SetSize
Ширина: 1920
Высота: 1080
```

**Установить позицию:**
```
Операция: SetPosition
X: 0
Y: 0
```

**Получить размер:**
```
Операция: GetSize
Ширина: width
Высота: height
```

**Полноэкранный режим:**
```
Операция: FullScreen
```
