# Браузер: Получить информацию

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserGetInfoBack`  
> **Тип результата:** `void` (данные в выходных переменных)

## Назначение

Извлекает информацию о текущем состоянии браузера: URL страницы, заголовок и полный HTML код. Используется для проверки состояния, отладки и извлечения данных.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Текущий URL** | `string` | Адрес текущей страницы |
| **Заголовок** | `string` | Содержимое тега `<title>` |
| **HTML код** | `string` | Полный исходный код страницы |

---

## Примеры использования

**Проверка успешной навигации:**
```
BrowserNavigate (URL: "https://example.com")
BrowserGetInfo (ID сессии: browserSession, Текущий URL: currentUrl)
If (currentUrl.Contains("example.com")):
  - Log ("Навигация успешна")
```

**Извлечение заголовка для логирования:**
```
BrowserGetInfo (
  ID сессии: browserSession,
  Заголовок: pageTitle
)
LogMessage ($"Открыта страница: {pageTitle}")
```

**Сохранение HTML для анализа:**
```
BrowserGetInfo (
  ID сессии: browserSession,
  HTML код: htmlSource
)
WriteTextFile (
  Путь: "page_snapshot.html",
  Содержимое: htmlSource
)
```

**Проверка редиректа:**
```
BrowserNavigate (URL: originalUrl)
BrowserGetInfo (Текущий URL: finalUrl)
If (originalUrl != finalUrl):
  - Log ($"Редирект: {originalUrl} → {finalUrl}")
```

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `WebDriverException` | Браузер не отвечает | Проверить состояние браузера |
| `NoSuchWindowException` | Окно браузера закрыто | Проверить, что браузер открыт |
| `TimeoutException` | Превышен таймаут получения данных | Увеличить таймаут или проверить страницу |

---

## Особенности HTML кода

**Что включает PageSource:**
- Полный HTML документ с DOCTYPE
- Все теги, включая `<head>` и `<body>`
- Встроенные стили и скрипты
- Динамически добавленный контент (после выполнения JavaScript)

**Что НЕ включает:**
- Внешние CSS и JS файлы (только ссылки на них)
- Содержимое iframe (нужно переключаться отдельно)
- Shadow DOM содержимое (требует специальных методов)

## Лучшие практики

✅ **Рекомендуется:**
- Использовать для проверки успешной навигации
- Извлекать заголовок для логирования
- Сохранять HTML для отладки ошибок
- Проверять URL перед выполнением действий
- Использовать для валидации редиректов

❌ **Не рекомендуется:**
- Парсить HTML вручную (используйте ElementGetInfo)
- Сохранять HTML на каждом шаге (большой объем данных)
- Использовать для извлечения данных (используйте локаторы)
- Игнорировать изменения URL при редиректах
- Полагаться только на заголовок для идентификации страницы

## Технические детали

- Таймаут операции: 30 секунд
- URL возвращается в полном формате (включая протокол)
- Заголовок возвращается без HTML тегов
- HTML код может быть очень большим (несколько МБ)
- Кодировка сохраняется из оригинального документа

---

## Примеры использования данных

**Проверка авторизации по URL:**
```csharp
BrowserGetInfo (Текущий URL: url)
If (url.Contains("/login")):
  - Log ("Требуется авторизация")
Else If (url.Contains("/dashboard")):
  - Log ("Авторизация успешна")
```

**Извлечение домена:**
```csharp
BrowserGetInfo (Текущий URL: fullUrl)
// fullUrl = "https://example.com/page?param=value"
domain = new Uri(fullUrl).Host  // "example.com"
```

**Поиск в HTML коде:**
```csharp
BrowserGetInfo (HTML код: html)
If (html.Contains("error-message")):
  - Log ("На странице обнаружена ошибка")
```

## Troubleshooting

**Пустой заголовок:**
- Проверить, что страница полностью загружена
- Убедиться, что у страницы есть тег `<title>`
- Проверить, что не используется about:blank

**HTML код не содержит ожидаемых элементов:**
- Элементы могут загружаться асинхронно (добавить ожидание)
- Проверить, что не используется Shadow DOM
- Убедиться, что JavaScript выполнился

**URL отличается от ожидаемого:**
- Проверить наличие редиректов
- Убедиться, что страница загрузилась полностью
- Проверить, что не произошла ошибка 404/500
