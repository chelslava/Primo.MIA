# Элемент: Клик

> **Группа:** MIA → Браузер  
> **Класс:** `ElementClickBack`  
> **Базовый класс:** `BrowserActivityBase`

## Назначение

Выполняет клик по элементу на веб-странице. Поддерживает различные типы кликов (обычный, двойной, правой кнопкой) и автоматическое ожидание кликабельности элемента.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| **Session ID** | `string` | Да | `""` | Идентификатор сессии браузера |
| **Тип локатора** | `ElementLocatorType` | Да | `CssSelector` | Способ поиска элемента |
| **Значение локатора** | `string` | Да | - | Селектор элемента |
| **Тип клика** | `ClickType` | Нет | `Single` | Тип клика |
| **Таймаут (мс)** | `int` | Нет | `10000` | Время ожидания элемента |
| **Прокрутить к элементу** | `bool` | Нет | `true` | Автопрокрутка перед кликом |

### Выходные

Активность не возвращает выходных параметров, только статус выполнения.

---

## Типы кликов

| Значение | Описание | Использование |
|---|---|---|
| `Single` | Обычный клик левой кнопкой | Кнопки, ссылки, чекбоксы |
| `Double` | Двойной клик | Выделение текста, открытие файлов |
| `Right` | Клик правой кнопкой | Контекстное меню |

---

## Типы локаторов

| Тип | Пример | Описание |
|---|---|---|
| `Id` | `"submit-button"` | По атрибуту id |
| `Name` | `"username"` | По атрибуту name |
| `ClassName` | `"btn-primary"` | По CSS классу |
| `TagName` | `"button"` | По тегу |
| `LinkText` | `"Войти"` | По точному тексту ссылки |
| `PartialLinkText` | `"Вой"` | По частичному тексту ссылки |
| `CssSelector` | `"#app > button.submit"` | По CSS селектору |
| `XPath` | `"//button[@type='submit']"` | По XPath |

## Алгоритм работы

```
1. Получение WebDriver по sessionId
   ↓
2. Поиск элемента с ожиданием (до таймаута)
   ├─ Ожидание присутствия в DOM
   ├─ Ожидание видимости
   └─ Ожидание кликабельности
   ↓
3. Прокрутка к элементу (если включено)
   ↓
4. Выполнение клика
   ├─ Single → element.Click()
   ├─ Double → Actions.DoubleClick()
   └─ Right → Actions.ContextClick()
   ↓
5. Возврат результата
```

## Расширенные возможности

### Retry механизм

Активность автоматически повторяет попытки при временных ошибках:

```
Попытка 1: StaleElementReferenceException
  ↓ Ожидание 500ms
Попытка 2: ElementNotInteractableException
  ↓ Ожидание 500ms
Попытка 3: Успех
```

**Настройка retry:**
```csharp
// В коде активности можно использовать
FindElementWithRetry(driver, locatorType, locatorValue, timeout, retryConfig);
```

### Автоматическая обработка iframe

Если элемент находится внутри iframe, активность автоматически:
1. Обнаруживает iframe
2. Переключается в контекст iframe
3. Выполняет клик
4. Возвращается в основной контекст

### Shadow DOM поддержка

Для элементов в Shadow DOM используйте специальные методы:
```csharp
FindElementInShadowRoot(shadowHost, locatorType, locatorValue);
```

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `NoSuchElementException` | Элемент не найден | Проверить локатор, увеличить таймаут |
| `ElementNotInteractableException` | Элемент не кликабелен | Включить прокрутку, дождаться видимости |
| `StaleElementReferenceException` | Элемент устарел | Retry механизм обработает автоматически |
| `ElementClickInterceptedException` | Элемент перекрыт | Прокрутить к элементу, закрыть модальные окна |
| `TimeoutException` | Превышен таймаут | Увеличить таймаут, проверить загрузку страницы |

## Troubleshooting

### Элемент не кликается

**Проблема:** `ElementNotInteractableException`

**Решения:**
1. Включить "Прокрутить к элементу"
2. Увеличить таймаут
3. Дождаться загрузки страницы
4. Проверить видимость элемента

```
Добавить перед кликом:
- Браузер: Ожидание (элемент видим)
- Элемент: Прокрутка к элементу
```

### Клик происходит не по тому элементу

**Проблема:** Неточный локатор

**Решения:**
1. Использовать более специфичный селектор
2. Добавить уникальные атрибуты
3. Использовать XPath с условиями

```
Плохо:  button
Хорошо: button[type='submit']
Лучше:  #submit-form button[type='submit']
```

### Элемент перекрыт модальным окном

**Проблема:** `ElementClickInterceptedException`

**Решения:**
1. Закрыть модальное окно перед кликом
2. Дождаться исчезновения overlay
3. Использовать JavaScript клик

```
Добавить перед кликом:
- Браузер: Ожидание (элемент .modal отсутствует)
- Или: Элемент: Клик (.modal-close)
```

## Лучшие практики

### ✅ Рекомендуется

- Использовать CSS селекторы (быстрее XPath)
- Включать прокрутку к элементу
- Устанавливать адекватные таймауты (5-15 сек)
- Дожидаться загрузки страницы перед кликом
- Использовать уникальные id где возможно

### ❌ Не рекомендуется

- Использовать слишком короткие таймауты (<3 сек)
- Кликать по невидимым элементам
- Использовать сложные XPath выражения
- Игнорировать ошибки кликабельности
- Кликать сразу после навигации без ожидания

## Производительность

| Операция | Среднее время |
|---|---|
| Поиск элемента | 100-500 мс |
| Прокрутка | 200-500 мс |
| Клик | 50-100 мс |
| Retry попытка | +500 мс |

**Оптимизация:**
- Уменьшить таймаут для быстрых страниц
- Отключить прокрутку если элемент точно видим
- Использовать CSS вместо XPath

## Технические детали

### Selenium Actions

Для специальных кликов используется Selenium Actions API:

```csharp
// Двойной клик
new Actions(driver).DoubleClick(element).Perform();

// Правый клик
new Actions(driver).ContextClick(element).Perform();
```

### JavaScript альтернатива

В некоторых случаях можно использовать JavaScript клик:

```csharp
IJavaScriptExecutor js = (IJavaScriptExecutor)driver;
js.ExecuteScript("arguments[0].click();", element);
```
