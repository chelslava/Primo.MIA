# Браузер: Выполнить JavaScript

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserExecuteJavaScriptBack`  
> **Тип результата:** `object` (в выходной переменной)

## Назначение

Выполняет JavaScript код в контексте текущей страницы браузера. Поддерживает передачу аргументов и получение результата выполнения.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **JavaScript код** | `string` | Да | Код для выполнения |
| **Аргументы** | `List<object>` | Нет | Список аргументов для скрипта |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Результат** | `object` | Возвращаемое значение скрипта |

---

## Примеры использования

**Получение заголовка страницы:**
```
JavaScript код: "return document.title;"
Результат: pageTitle
```

**Клик по элементу через JavaScript:**
```
JavaScript код: "document.getElementById('button').click();"
```

**Прокрутка к низу страницы:**
```
JavaScript код: "window.scrollTo(0, document.body.scrollHeight);"
```

**Получение значения с аргументами:**
```
JavaScript код: "return arguments[0] + arguments[1];"
Аргументы: [10, 20]
Результат: sum  // 30
```

**Изменение стиля элемента:**
```
JavaScript код: "document.getElementById('element').style.display = 'none';"
```

---

## Доступ к аргументам

В JavaScript коде аргументы доступны через массив `arguments`:
```javascript
arguments[0]  // первый аргумент
arguments[1]  // второй аргумент
// и т.д.
```

## Лучшие практики

✅ **Рекомендуется:**
- Использовать для сложных манипуляций DOM
- Возвращать результат через return
- Проверять наличие элементов перед доступом
- Использовать для обхода ограничений Selenium
- Логировать выполняемый код

❌ **Не рекомендуется:**
- Выполнять длительные операции
- Изменять критичные части страницы
- Использовать вместо стандартных методов
- Игнорировать ошибки выполнения
- Выполнять небезопасный код

## Troubleshooting

**Скрипт не выполняется:**
- Проверить синтаксис JavaScript
- Убедиться, что элементы существуют
- Проверить консоль браузера
- Добавить обработку ошибок в скрипт

**Результат null:**
- Убедиться, что используется return
- Проверить, что скрипт возвращает значение
- Проверить тип возвращаемого значения
