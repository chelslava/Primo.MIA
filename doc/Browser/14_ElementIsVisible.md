# Элемент: Проверить видимость

> **Группа:** MIA → Браузер  
> **Класс:** `ElementIsVisibleBack`  
> **Тип результата:** `void` (данные в выходных переменных)

## Назначение

Проверяет состояние элемента: видимость (Displayed), включённость (Enabled), выбранность (Selected).

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска |
| **Значение локатора** | `string` | Если нет ID | Значение для поиска |
| **Таймаут ожидания** | `int` | Нет | Время ожидания (сек), по умолчанию 10 |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Видим** | `bool` | Элемент отображается (Displayed) |
| **Включён** | `bool` | Элемент активен (Enabled) |
| **Выбран** | `bool` | Элемент выбран (Selected) |

---

## Примеры использования

**Проверка видимости кнопки:**
```
Тип локатора: Id
Значение: "submitBtn"
Видим: isVisible

If (isVisible):
  - ElementClick (...)
```

**Проверка состояния checkbox:**
```
Тип локатора: Id
Значение: "agreeCheckbox"
Выбран: isChecked

If (!isChecked):
  - ElementClick (...)
```

**Проверка доступности поля:**
```
Тип локатора: Name
Значение: "email"
Включён: isEnabled

If (isEnabled):
  - ElementInput (...)
```
