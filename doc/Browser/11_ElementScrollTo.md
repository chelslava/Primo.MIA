# Элемент: Прокрутить

> **Группа:** MIA → Браузер  
> **Класс:** `ElementScrollToBack`  
> **Тип результата:** `void`

## Назначение

Прокручивает страницу к указанному элементу с выбором выравнивания элемента в окне браузера.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента (если уже найден) |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска элемента |
| **Значение локатора** | `string` | Если нет ID | Конкретное значение для поиска |
| **Выравнивание** | `ScrollAlignment` | Да | Top, Center или Bottom |
| **Таймаут ожидания** | `int` | Нет | Время ожидания элемента (сек), по умолчанию 10 |

### Типы выравнивания

| Выравнивание | Описание |
|---|---|
| `Top` | Элемент в верхней части окна |
| `Center` | Элемент в центре окна |
| `Bottom` | Элемент в нижней части окна |

---

## Примеры использования

**Прокрутка к элементу перед кликом:**
```
ElementScrollTo (
  Тип локатора: Id,
  Значение: "submitButton",
  Выравнивание: Center
)
ElementClick (Локатор: "submitButton")
```

**Прокрутка к началу формы:**
```
ElementScrollTo (
  Тип локатора: Id,
  Значение: "formHeader",
  Выравнивание: Top
)
```

**Прокрутка к футеру:**
```
ElementScrollTo (
  Тип локатора: TagName,
  Значение: "footer",
  Выравнивание: Bottom
)
```

---

## Лучшие практики

✅ **Рекомендуется:**
- Прокручивать перед взаимодействием с элементом
- Использовать Center для лучшей видимости
- Добавлять задержку после прокрутки (200-500мс)
- Проверять видимость после прокрутки

❌ **Не рекомендуется:**
- Прокручивать к невидимым элементам
- Игнорировать ошибки прокрутки
- Прокручивать без необходимости
- Использовать для элементов в viewport

## Troubleshooting

**Элемент не прокручивается:**
- Проверить, что элемент существует
- Убедиться, что страница имеет прокрутку
- Проверить CSS overflow свойства
- Попробовать другое выравнивание

**Прокрутка не точная:**
- Использовать Center вместо Top/Bottom
- Добавить задержку после прокрутки
- Проверить фиксированные заголовки
- Учесть sticky элементы
