# Браузер: Открыть

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserOpenBack`  
> **Тип результата:** `string` (sessionId)

## Назначение

Открывает новый экземпляр браузера (Chrome, Firefox или Edge) с заданными настройками. Возвращает уникальный `sessionId` для последующей работы с этим браузером.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | По умолчанию | Описание |
|---|---|---|---|---|
| **Тип браузера** | `BrowserType` | Да | `Chrome` | Какой браузер открыть |
| **Session ID** | `string` | Нет | `""` | Идентификатор сессии (пустая строка = автогенерация) |
| **URL** | `string` | Нет | `""` | Начальный URL для открытия |
| **Headless режим** | `bool` | Нет | `false` | Запуск без GUI |
| **Развернуть окно** | `bool` | Нет | `true` | Развернуть окно на весь экран |
| **Путь к драйверу** | `string` | Нет | `""` | Путь к WebDriver (если не в PATH) |
| **Аргументы браузера** | `string` | Нет | `""` | Дополнительные аргументы командной строки |
| **Таймаут (сек)** | `int` | Нет | `30` | Таймаут запуска браузера |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Session ID** | `string` | Уникальный идентификатор открытого браузера |

---

## Типы браузеров

| Значение | Описание | Требуется драйвер |
|---|---|---|
| `Chrome` | Google Chrome | ChromeDriver |
| `Firefox` | Mozilla Firefox | GeckoDriver |
| `Edge` | Microsoft Edge | EdgeDriver |

## Примеры использования

### Пример 1: Простое открытие Chrome

```
Входные параметры:
- Тип браузера: Chrome
- Session ID: "" (автогенерация)
- URL: "https://google.com"

Результат:
Session ID: "browser-session-1"
Браузер открыт и перешел на google.com
```

---

### Пример 2: Headless режим для фоновой работы

```
Входные параметры:
- Тип браузера: Chrome
- Session ID: "background-bot"
- Headless режим: true
- Развернуть окно: false

Результат:
Session ID: "background-bot"
Браузер работает в фоне без GUI
```

---

### Пример 3: Множественные браузеры

```
Сценарий:
1. Открыть браузер с Session ID = "browser-1"
2. Открыть браузер с Session ID = "browser-2"
3. Работать с обоими браузерами параллельно

Результат:
Два независимых экземпляра браузера
```

---

### Пример 4: Пользовательские аргументы

```
Входные параметры:
- Тип браузера: Chrome
- Аргументы браузера: "--disable-extensions --incognito"

Результат:
Chrome открыт в режиме инкогнито без расширений
```

---

## Полезные аргументы браузера

### Chrome

| Аргумент | Описание |
|---|---|
| `--incognito` | Режим инкогнито |
| `--disable-extensions` | Отключить расширения |
| `--disable-gpu` | Отключить GPU (для headless) |
| `--no-sandbox` | Отключить sandbox (для Docker) |
| `--window-size=1920,1080` | Размер окна |
| `--user-agent="..."` | Пользовательский User-Agent |
| `--disable-blink-features=AutomationControlled` | Скрыть признаки автоматизации |

### Firefox

| Аргумент | Описание |
|---|---|
| `-private` | Приватный режим |
| `-width 1920 -height 1080` | Размер окна |

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `WebDriverException: ChromeDriver not found` | Драйвер не найден | Установить драйвер в PATH или указать путь |
| `SessionNotCreatedException: version mismatch` | Несовпадение версий | Обновить драйвер под версию браузера |
| `WebDriverException: chrome not reachable` | Браузер не запустился | Проверить установку браузера |
| `ArgumentException: Session ID already exists` | Дублирующийся sessionId | Использовать уникальный sessionId |

## Управление сессиями

### Автогенерация Session ID

Если `Session ID` не указан или пустая строка, система автоматически генерирует уникальный идентификатор:

```
"browser-session-1"
"browser-session-2"
...
```

### Пользовательский Session ID

Можно указать свой идентификатор для удобства:

```
Session ID: "main-browser"
Session ID: "data-extraction-bot"
Session ID: "test-session"
```

### Множественные сессии

Можно открыть несколько браузеров одновременно с разными `sessionId`:

```
Browser 1: sessionId = "user-1"
Browser 2: sessionId = "user-2"
Browser 3: sessionId = "admin"
```

## Headless режим

### Когда использовать

- Фоновая обработка данных
- Запуск на серверах без GUI
- CI/CD pipeline
- Массовая обработка

### Ограничения

- Некоторые сайты могут детектировать headless режим
- Отсутствие визуальной отладки
- Некоторые функции могут работать иначе

### Обход детекции

```
Аргументы браузера:
--disable-blink-features=AutomationControlled
--user-agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
```

## Производительность

### Время запуска

| Режим | Среднее время |
|---|---|
| Обычный | 2-5 секунд |
| Headless | 1-3 секунды |
| С расширениями | 5-10 секунд |

### Потребление ресурсов

| Браузер | RAM | CPU |
|---|---|---|
| Chrome | 200-500 МБ | Средняя |
| Firefox | 150-400 МБ | Средняя |
| Edge | 200-500 МБ | Средняя |

## Лучшие практики

### ✅ Рекомендуется

- Всегда закрывать браузер после использования
- Использовать уникальные sessionId для разных задач
- Указывать таймаут для медленных систем
- Использовать headless для фоновых задач

### ❌ Не рекомендуется

- Открывать слишком много браузеров одновременно (>5)
- Использовать одинаковые sessionId
- Оставлять браузеры открытыми после завершения
- Игнорировать ошибки запуска

## Технические детали

### Ambient Context Pattern

Активность использует `BrowserSessionContext` для управления текущей сессией через стек в `RepoDict`. Это позволяет:
- Автоматически определять текущий браузер
- Вкладывать операции с разными браузерами
- Изолировать сессии друг от друга

### WebDriver

Под капотом используется Selenium WebDriver:
- ChromeDriver для Chrome
- GeckoDriver для Firefox
- EdgeDriver для Edge
