# Элемент: Multiple Select

> **Группа:** MIA → Браузер  
> **Класс:** `ElementSelectMultipleBack`  
> **Тип результата:** `void` (данные в выходных переменных)

## Назначение

Управляет множественным выбором в select[multiple] элементах. Поддерживает выбор и снятие выбора нескольких опций.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента select |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска |
| **Значение локатора** | `string` | Если нет ID | Значение для поиска |
| **Операция** | `MultiSelectOperation` | Да | Тип операции |
| **Значение** | `string` | Для некоторых операций | Текст/value/индекс |
| **Таймаут ожидания** | `int` | Нет | Время ожидания (сек), по умолчанию 10 |

### Операции

| Операция | Описание |
|---|---|
| `SelectByText` | Выбрать по тексту |
| `SelectByValue` | Выбрать по value |
| `SelectByIndex` | Выбрать по индексу |
| `DeselectByText` | Снять выбор по тексту |
| `DeselectByValue` | Снять выбор по value |
| `DeselectByIndex` | Снять выбор по индексу |
| `DeselectAll` | Снять все выборы |
| `GetAllOptions` | Получить все опции |
| `GetSelectedOptions` | Получить выбранные |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Список опций** | `List<string>` | Все опции (для GetAllOptions) |
| **Выбранные опции** | `List<string>` | Выбранные опции (для GetSelectedOptions) |

---

## Примеры использования

**Выбор нескольких опций:**
```
Операция: SelectByText
Значение: "Опция 1"
// Повторить для других опций
```

**Снятие всех выборов:**
```
Операция: DeselectAll
```

**Получение выбранных:**
```
Операция: GetSelectedOptions
Выбранные опции: selected
```
