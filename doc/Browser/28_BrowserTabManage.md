# Браузер: Управление вкладками

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserTabManageBack`  
> **Тип результата:** `void` (данные в выходных переменных)

## Назначение

Управляет вкладками браузера: открытие новых вкладок, переключение между ними, закрытие.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Операция** | `TabOperation` | Да | Тип операции с вкладками |
| **URL** | `string` | Для OpenNew | URL для открытия в новой вкладке |
| **Заголовок** | `string` | Для SwitchByTitle | Заголовок вкладки для переключения |

### Операции

| Операция | Описание |
|---|---|
| `OpenNew` | Открыть новую вкладку |
| `Close` | Закрыть текущую вкладку |
| `SwitchByTitle` | Переключиться по заголовку |
| `SwitchByIndex` | Переключиться по индексу |
| `GetAllTabs` | Получить список всех вкладок |
| `CloseAllExceptMain` | Закрыть все кроме основной |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Список вкладок** | `List<string>` | Заголовки всех вкладок |
| **Количество вкладок** | `int` | Количество открытых вкладок |

---

## Примеры использования

**Открытие новой вкладки:**
```
Операция: OpenNew
URL: "https://example.com"
```

**Переключение по заголовку:**
```
Операция: SwitchByTitle
Заголовок: "Dashboard"
```

**Закрытие всех кроме основной:**
```
Операция: CloseAllExceptMain
```

**Получение списка вкладок:**
```
Операция: GetAllTabs
Список вкладок: tabs
Количество: tabCount
```
