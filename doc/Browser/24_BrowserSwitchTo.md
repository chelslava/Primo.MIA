# Браузер: Переключить контекст

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserSwitchToBack`  
> **Тип результата:** `void`

## Назначение

Переключает контекст браузера между фреймами, окнами и alert. Необходимо для работы с iframe, popup окнами и вкладками.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Тип переключения** | `SwitchToType` | Да | Frame, Window, Alert, DefaultContent, ParentFrame |
| **Цель** | `string` | Для Frame/Window | Индекс фрейма, handle окна или локатор |

### Типы переключения

| Тип | Описание |
|---|---|
| `Frame` | Переключиться в iframe |
| `Window` | Переключиться в другое окно/вкладку |
| `Alert` | Переключиться на alert |
| `DefaultContent` | Вернуться к основному контенту |
| `ParentFrame` | Вернуться к родительскому фрейму |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Window Handles** | `List<string>` | Список handles всех окон (для Window) |

---

## Примеры использования

**Переключение в iframe:**
```
Тип: Frame
Цель: "0"  // или "iframe-id"
```

**Переключение в окно:**
```
Тип: Window
Цель: windowHandle
```

**Возврат к основному контенту:**
```
Тип: DefaultContent
```

**Переключение на alert:**
```
Тип: Alert
```
