# Браузер: Управление Cookies

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserManageCookiesBack`  
> **Тип результата:** `void` (данные в выходной переменной)

## Назначение

Управляет cookies браузера: получение, установка, удаление. Используется для управления сессиями и состоянием браузера.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Операция** | `CookieOperation` | Да | Тип операции с cookies |
| **Имя cookie** | `string` | Для Get/Set/Delete | Имя cookie |
| **Значение cookie** | `string` | Для Set | Значение cookie |

### Операции

| Операция | Описание |
|---|---|
| `Get` | Получить cookie по имени |
| `GetAll` | Получить все cookies (JSON) |
| `Set` | Установить cookie |
| `Delete` | Удалить cookie |
| `DeleteAll` | Удалить все cookies |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Результат** | `string` | Значение cookie или JSON всех cookies |

---

## Примеры использования

**Получение cookie:**
```
Операция: Get
Имя cookie: "session_id"
Результат: sessionValue
```

**Установка cookie:**
```
Операция: Set
Имя cookie: "user_pref"
Значение: "dark_theme"
```

**Получение всех cookies:**
```
Операция: GetAll
Результат: allCookiesJson
```

**Удаление cookie:**
```
Операция: Delete
Имя cookie: "temp_data"
```

**Очистка всех cookies:**
```
Операция: DeleteAll
```

---

## Лучшие практики

✅ **Рекомендуется:**
- Сохранять cookies для повторного использования
- Очищать cookies между тестами
- Проверять наличие cookie перед использованием
- Использовать для управления сессиями

❌ **Не рекомендуется:**
- Хранить чувствительные данные в cookies
- Удалять системные cookies
- Игнорировать ошибки операций
- Устанавливать cookies на чужих доменах
