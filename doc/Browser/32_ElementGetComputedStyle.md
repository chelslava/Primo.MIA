# Элемент: Получить CSS стиль

> **Группа:** MIA → Браузер  
> **Класс:** `ElementGetComputedStyleBack`

## Назначение

Возвращает вычисленное значение CSS-свойства элемента через `window.getComputedStyle()`. Это фактическое значение после применения всех CSS-правил, а не только inline-атрибутов.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `ID сессии браузера` | `string` | Идентификатор открытого браузера. |
| `ID элемента` | `string` | Уже найденный элемент. |
| `Тип локатора` | `ElementLocatorType` | Альтернативный способ поиска элемента. |
| `Значение локатора` | `string` | Значение локатора. |
| `CSS свойство` | `string` | Имя свойства, например `color`, `font-size`, `display`, `background-color`. |
| `Таймаут ожидания (сек)` | `int` | Используется, если элемент ищется по локатору. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Значение свойства` | `string` | Вычисленное CSS-значение элемента. |

## Пример

```text
ID сессии браузера: "browser-1"
Тип локатора: CssSelector
Значение локатора: ".status-badge"
CSS свойство: "background-color"
Таймаут ожидания (сек): 10
```

## Примечания

- Достаточно указать либо `ID элемента`, либо локатор.
- Лучше использовать CSS-имена в kebab-case: `font-size`, `line-height`, `z-index`.
- Активность удобна для UI-проверок: цвет, размер, видимость через `display`, прозрачность, шрифты и отступы.
