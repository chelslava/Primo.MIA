# Элемент: Скриншот

> **Группа:** MIA → Браузер  
> **Класс:** `ElementGetScreenshotBack`  
> **Тип результата:** `void` (скриншот в файле и/или Base64)

## Назначение

Создаёт скриншот конкретного элемента (не всей страницы). Поддерживает сохранение в файл и получение Base64.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска |
| **Значение локатора** | `string` | Если нет ID | Значение для поиска |
| **Путь к файлу** | `string` | Нет | Путь для сохранения PNG |
| **Таймаут ожидания** | `int` | Нет | Время ожидания (сек), по умолчанию 10 |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Base64** | `string` | Скриншот в формате Base64 |

---

## Примеры использования

**Скриншот элемента в файл:**
```
Тип локатора: Id
Значение: "chart"
Путь к файлу: "C:\Screenshots\chart.png"
```

**Скриншот для отправки:**
```
Тип локатора: ClassName
Значение: "product-image"
Base64: imageBase64
```

**Скриншот при ошибке:**
```
Try:
  - ElementClick (...)
Catch:
  - ElementGetScreenshot (
      Локатор: ".error-container",
      Путь: "error.png"
    )
```
