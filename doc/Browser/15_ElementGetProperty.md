# Элемент: Получить свойство

> **Группа:** MIA → Браузер  
> **Класс:** `ElementGetPropertyBack`  
> **Тип результата:** `string`

## Назначение

Извлекает свойства элемента: текст, HTML атрибуты или CSS свойства.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID элемента** | `string` | Да | Идентификатор элемента |
| **Имя свойства** | `string` | Да | text, attribute:name или css:property |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Значение** | `string` | Полученное значение свойства |

---

## Форматы имени свойства

**Текст элемента:**
```
"text" → видимый текст элемента
```

**HTML атрибут:**
```
"attribute:href" → значение атрибута href
"attribute:value" → значение поля ввода
"attribute:class" → CSS классы
```

**CSS свойство:**
```
"css:color" → цвет текста
"css:background-color" → цвет фона
"css:display" → тип отображения
```

---

## Примеры использования

**Получение текста:**
```
ID элемента: elementId
Имя свойства: "text"
Значение: elementText
```

**Получение URL ссылки:**
```
ID элемента: linkId
Имя свойства: "attribute:href"
Значение: linkUrl
```

**Получение цвета:**
```
ID элемента: elementId
Имя свойства: "css:color"
Значение: textColor
```
