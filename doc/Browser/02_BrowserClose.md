# Браузер: Закрыть

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserCloseBack`  
> **Тип результата:** `void`

## Назначение

Закрывает сессию браузера и освобождает все связанные ресурсы. После выполнения ID сессии становится недействительным и не может быть использован повторно.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера из BrowserOpen |

### Выходные

Нет выходных параметров.

---

## Примеры использования

**Закрытие браузера после завершения работы:**
```
ID сессии: browserSession
```

**Закрытие в блоке Finally для гарантированного освобождения ресурсов:**
```
Try:
  - BrowserOpen → browserSession
  - ... работа с браузером ...
Finally:
  - BrowserClose (ID сессии: browserSession)
```

**Закрытие нескольких браузеров:**
```
BrowserClose (ID сессии: session1)
BrowserClose (ID сессии: session2)
BrowserClose (ID сессии: session3)
```

---

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `KeyNotFoundException` | Сессия не найдена в RepoDict | Проверить корректность ID сессии |
| `InvalidOperationException` | Браузер уже закрыт | Не вызывать BrowserClose дважды для одной сессии |
| `WebDriverException` | Ошибка при закрытии драйвера | Проверить состояние браузера |

---

## Что происходит при закрытии

1. Вызывается `driver.Quit()` — закрытие всех окон браузера
2. Вызывается `driver.Dispose()` — освобождение ресурсов драйвера
3. Сессия удаляется из `RepoDict`
4. Сессия снимается из ambient-контекста (`BrowserSessionContext.Pop()`)

---

## Лучшие практики

✅ **Рекомендуется:**
- Всегда закрывать браузер в блоке Finally
- Использовать один BrowserClose на одну сессию
- Закрывать браузер сразу после завершения работы
- Проверять существование сессии перед закрытием

❌ **Не рекомендуется:**
- Закрывать браузер дважды
- Использовать сессию после закрытия
- Оставлять браузер открытым после завершения процесса
- Игнорировать ошибки закрытия

## Технические детали

- Таймаут операции: 30 секунд
- Закрытие происходит синхронно
- Все открытые окна и вкладки закрываются автоматически
- Временные файлы браузера удаляются драйвером
- После закрытия память освобождается

---

## Troubleshooting

**Браузер не закрывается:**
- Проверить, что процесс браузера не завис
- Увеличить таймаут операции
- Проверить логи драйвера

**Ошибка "Сессия не найдена":**
- Убедиться, что ID сессии корректен
- Проверить, что браузер был успешно открыт
- Проверить, что сессия не была закрыта ранее

**Процесс браузера остается в памяти:**
- Убедиться, что вызывается Dispose()
- Проверить, что нет исключений при закрытии
- Использовать Task Manager для принудительного завершения
