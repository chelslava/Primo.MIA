# Элемент: Поиск и проверка

> **Группа:** MIA → Браузер  
> **Класс:** `ElementSearchBack`

## Назначение

Универсальная активность для проверки состояния элемента и поиска списков элементов. Объединяет сценарии существования, видимости, кликабельности, ожидания, поиска всех элементов и подсчёта количества.

## Входные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `ID сессии браузера` | `string` | Идентификатор браузерной сессии. |
| `ID элемента` | `string` | Уже найденный элемент. Если задан, локатор можно не указывать. |
| `Тип локатора` | `ElementLocatorType` | Локатор для поиска элемента, если `ID элемента` не передан. |
| `Значение локатора` | `string` | Значение локатора. |
| `Режим поиска` | `ElementSearchMode` | Определяет, что именно нужно проверить или вернуть. |
| `Режим ожидания` | `ElementWaitMode` | Как ожидать элемент: `Present`, `Visible`, `Clickable`, `None`. |
| `Таймаут ожидания (сек)` | `int` | Верхняя граница ожидания. |

## Выходные параметры

| Параметр | Тип | Описание |
|---|---|---|
| `Элемент найден` | `bool` | Базовый признак, что элемент найден или список не пустой. |
| `Видим` | `bool` | Заполняется в режимах, где проверяется отображение. |
| `Включён` | `bool` | Состояние `Enabled`. |
| `Выбран` | `bool` | Состояние `Selected`, полезно для checkbox/radio/options. |
| `Элемент кликабельный` | `bool` | `true`, если элемент отображается и доступен для клика. |
| `Количество элементов` | `int` | Используется в режимах `FindAll` и `Count`. |
| `Найденные элементы` | `List<string>` | Список ID найденных элементов в режиме `FindAll`. |

## Режимы

| Режим | Что делает |
|---|---|
| `Exists` | Проверяет наличие элемента в DOM. |
| `IsVisible` | Проверяет, найден ли элемент и отображается ли он. |
| `IsClickable` | Проверяет видимость и доступность для клика. |
| `WaitAndCheck` | Ждёт элемент и возвращает полный набор флагов состояния. |
| `FindAll` | Возвращает все найденные элементы и их количество. |
| `Count` | Только считает элементы по локатору. |

## Пример

```text
ID сессии браузера: "browser-1"
Тип локатора: XPath
Значение локатора: "//button[@type='submit']"
Режим поиска: IsClickable
Режим ожидания: Clickable
Таймаут ожидания (сек): 15
```

## Примечания

- Если передан `ID элемента`, активность работает с уже сохранённым элементом и не выполняет повторный поиск по локатору.
- Для простого получения одного элемента удобнее использовать [30_ElementFind.md](30_ElementFind.md).
- Режим `WaitAndCheck` особенно полезен для SPA-страниц, где элемент появляется раньше, чем становится доступным для действия.
