# Браузер: Скриншот

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserScreenshotBack`  
> **Тип результата:** `void` (скриншот в файле и/или Base64)

## Назначение

Создаёт скриншот текущей страницы браузера. Поддерживает сохранение в файл PNG и получение Base64 строки для встраивания или передачи.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Путь к файлу** | `string` | Нет | Путь для сохранения PNG (опционально) |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Base64** | `string` | Скриншот в формате Base64 строки |

---

## Примеры использования

**Сохранение скриншота в файл:**
```
BrowserScreenshot (
  ID сессии: browserSession,
  Путь к файлу: "C:\Screenshots\page.png"
)
```

**Получение Base64 для отправки по API:**
```
BrowserScreenshot (
  ID сессии: browserSession,
  Base64: screenshotBase64
)
HttpRequest (
  Body: { "screenshot": screenshotBase64 }
)
```

**Скриншот с timestamp в имени:**
```
timestamp = DateTime.Now.ToString("yyyyMMdd_HHmmss")
filePath = $"C:\Screenshots\page_{timestamp}.png"
BrowserScreenshot (
  ID сессии: browserSession,
  Путь к файлу: filePath
)
```

**Скриншот при ошибке:**
```
Try:
  - ElementClick (кнопка)
Catch (ex):
  - BrowserScreenshot (
      ID сессии: browserSession,
      Путь к файлу: "C:\Errors\error_screenshot.png"
    )
  - LogMessage ($"Ошибка: {ex.Message}")
```

---

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `WebDriverException` | Не удалось создать скриншот | Проверить состояние браузера |
| `IOException` | Нет доступа к пути сохранения | Проверить права доступа |
| `DirectoryNotFoundException` | Директория не существует | Создать директорию или использовать существующую |
| `ArgumentException` | Некорректный путь к файлу | Проверить формат пути |

## Форматы вывода

**Файл PNG:**
- Формат: PNG (Portable Network Graphics)
- Качество: без потерь
- Размер: зависит от размера страницы (обычно 100-500 КБ)
- Расширение: `.png`

**Base64 строка:**
- Формат: Base64 encoded PNG
- Использование: встраивание в JSON, HTML, отправка по API
- Размер: ~33% больше чем файл PNG
- Префикс для HTML: `data:image/png;base64,{base64}`

---

## Что включает скриншот

**Включается:**
- Видимая область страницы (viewport)
- Все отрисованные элементы
- CSS стили и фоны
- Изображения (если загружены)

**НЕ включается:**
- Область за пределами viewport (нужна прокрутка)
- Элементы с `display: none`
- Содержимое iframe (требует переключения)
- Курсор мыши

---

## Лучшие практики

✅ **Рекомендуется:**
- Создавать директорию перед сохранением
- Использовать timestamp в имени файла
- Делать скриншот при ошибках для отладки
- Сохранять Base64 для отправки по API
- Использовать для документирования процесса

❌ **Не рекомендуется:**
- Создавать скриншоты на каждом шаге (большой объем)
- Сохранять в системные директории без прав
- Использовать одно имя файла (перезапись)
- Игнорировать ошибки сохранения
- Хранить Base64 в логах (большой размер)

## Технические детали

- Таймаут операции: 30 секунд
- Формат: PNG с прозрачностью
- Разрешение: соответствует размеру окна браузера
- Цветовая модель: RGB/RGBA
- Автоматическое создание директории при сохранении

---

## Примеры работы с Base64

**Сохранение Base64 в файл вручную:**
```csharp
BrowserScreenshot (Base64: base64)
bytes = Convert.FromBase64String(base64)
File.WriteAllBytes("screenshot.png", bytes)
```

**Встраивание в HTML:**
```html
<img src="data:image/png;base64,{base64}" />
```

**Отправка в Telegram:**
```csharp
BrowserScreenshot (Base64: base64)
bytes = Convert.FromBase64String(base64)
TelegramSendPhoto (PhotoBytes: bytes)
```

## Troubleshooting

**Скриншот пустой или черный:**
- Проверить, что страница загружена
- Убедиться, что окно браузера не свернуто
- Проверить, что не используется headless режим с ошибками
- Добавить задержку перед скриншотом

**Файл не создается:**
- Проверить права доступа к директории
- Убедиться, что путь корректен
- Проверить наличие свободного места на диске
- Создать директорию вручную

**Скриншот не включает всю страницу:**
- Использовать прокрутку перед скриншотом
- Увеличить размер окна браузера
- Рассмотреть использование полного скриншота (требует расширений)

**Большой размер файла:**
- Уменьшить размер окна браузера
- Использовать сжатие PNG
- Рассмотреть использование JPEG для фотографий
- Оптимизировать содержимое страницы
