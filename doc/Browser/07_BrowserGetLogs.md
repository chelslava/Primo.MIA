# Браузер: Получить логи

> **Группа:** MIA → Браузер  
> **Класс:** `BrowserGetLogsBack`  
> **Тип результата:** `List<string>`

## Назначение

Получает логи браузера указанного типа: консоль, драйвер, производительность. Используется для отладки и мониторинга веб-приложений.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **Тип логов** | `BrowserLogType` | Да | Browser, Driver, Client, Server, Performance |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Логи** | `List<string>` | Список строк с записями логов |
| **Количество записей** | `int` | Количество полученных логов |

---

## Примеры использования

**Получение ошибок консоли:**
```
Тип логов: Browser
Логи: consoleLogs
Количество: logCount
```

**Проверка наличия ошибок JavaScript:**
```
BrowserGetLogs (Тип: Browser, Логи: logs)
For each log in logs:
  If log.Contains("ERROR"):
    LogMessage ($"JS Error: {log}")
```
