# Элемент: Ввод

> **Группа:** MIA → Браузер  
> **Класс:** `ElementInputBack`  
> **Тип результата:** `void`

## Назначение

Объединённая активность для работы с вводом в элементы. Поддерживает три режима: ввод текста, отправку специальных клавиш и очистку поля.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Режим ввода** | `InputMode` | Да | TypeText, SendKeys или Clear |
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента (если уже найден) |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска элемента |
| **Значение локатора** | `string` | Если нет ID | Конкретное значение для поиска |
| **Таймаут ожидания** | `int` | Нет | Время ожидания элемента (сек), по умолчанию 10 |

### Параметры для TypeText

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Текст** | `string` | Да | Текст для ввода |
| **Очистить перед вводом** | `bool` | Нет | Очистить поле перед вводом (по умолчанию true) |
| **Кликнуть перед вводом** | `bool` | Нет | Кликнуть по элементу перед вводом |
| **Симулировать печать** | `bool` | Нет | Вводить с задержкой между символами |
| **Задержка (мс)** | `int` | Нет | Задержка между символами (по умолчанию 50мс) |
| **Нажать Enter после** | `bool` | Нет | Нажать Enter после ввода |

### Параметры для SendKeys

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Специальная клавиша** | `SpecialKeyType` | Да | Клавиша для отправки |
| **Количество повторений** | `int` | Нет | Сколько раз нажать (по умолчанию 1) |

### Режимы ввода

| Режим | Описание |
|---|---|
| `TypeText` | Ввести текст (очистить поле и ввести) |
| `SendKeys` | Отправить специальные клавиши |
| `Clear` | Очистить поле ввода |

### Специальные клавиши

| Клавиша | Описание |
|---|---|
| `Enter` | Клавиша Enter |
| `Tab` | Клавиша Tab |
| `Escape` | Клавиша Escape |
| `Backspace` | Клавиша Backspace |
| `Delete` | Клавиша Delete |
| `Space` | Пробел |
| `ArrowUp/Down/Left/Right` | Стрелки |
| `Home/End` | Home/End |
| `PageUp/PageDown` | Page Up/Down |
| `F1-F12` | Функциональные клавиши |
| `CtrlA/C/V/X/Z` | Комбинации с Ctrl |
| `ShiftTab` | Shift+Tab |
| `AltF4` | Alt+F4 |

## Примеры использования

**Ввод текста в поле:**
```
Режим ввода: TypeText
ID сессии: browserSession
Тип локатора: Id
Значение локатора: "username"
Текст: "user@example.com"
Очистить перед вводом: true
```

**Ввод с симуляцией печати:**
```
Режим ввода: TypeText
Тип локатора: Name
Значение локатора: "search"
Текст: "поисковый запрос"
Симулировать печать: true
Задержка (мс): 100
```

**Ввод с нажатием Enter:**
```
Режим ввода: TypeText
Тип локатора: Id
Значение локатора: "searchBox"
Текст: "query"
Нажать Enter после: true
```

**Отправка специальной клавиши:**
```
Режим ввода: SendKeys
Тип локатора: Id
Значение локатора: "inputField"
Специальная клавиша: Tab
```

**Очистка поля:**
```
Режим ввода: Clear
Тип локатора: Id
Значение локатора: "textArea"
```

**Множественное нажатие клавиши:**
```
Режим ввода: SendKeys
Тип локатора: Id
Значение локатора: "list"
Специальная клавиша: ArrowDown
Количество повторений: 3
```

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `NoSuchElementException` | Элемент не найден | Проверить локатор и таймаут |
| `ElementNotInteractableException` | Элемент недоступен для ввода | Проверить видимость и enabled |
| `InvalidElementStateException` | Элемент не поддерживает ввод | Убедиться, что это input/textarea |
| `ArgumentException` | Текст пустой для TypeText | Указать текст для ввода |

## Лучшие практики

✅ **Рекомендуется:**
- Очищать поле перед вводом для надежности
- Использовать симуляцию печати для сложных форм
- Кликать перед вводом если поле не в фокусе
- Использовать Enter вместо клика по кнопке
- Проверять результат ввода после выполнения

❌ **Не рекомендуется:**
- Вводить пароли без очистки поля
- Использовать слишком большую задержку (>200мс)
- Отправлять Enter без проверки формы
- Игнорировать ошибки ввода
- Вводить в readonly поля

## Технические детали

- Таймаут операции: 10 секунд
- Задержка между символами: 1-1000 мс
- Количество повторений: 1-100
- Автоматическая очистка перед вводом (опционально)
- Поддержка Unicode символов

## Troubleshooting

**Текст вводится не полностью:**
- Увеличить задержку между символами
- Проверить, что поле не имеет maxlength
- Убедиться, что JavaScript не перехватывает ввод
- Использовать симуляцию печати

**Поле не очищается:**
- Использовать режим Clear перед вводом
- Проверить, что поле не readonly
- Попробовать CtrlA + Delete
- Проверить JavaScript обработчики

**Enter не работает:**
- Проверить, что форма поддерживает submit
- Использовать клик по кнопке вместо Enter
- Проверить JavaScript обработчики
- Добавить задержку после Enter

**Специальные клавиши не работают:**
- Проверить, что элемент в фокусе
- Убедиться, что клавиша поддерживается
- Попробовать кликнуть перед отправкой
- Проверить раскладку клавиатуры
