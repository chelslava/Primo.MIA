# Элемент: Получить информацию

> **Группа:** MIA → Браузер  
> **Класс:** `ElementGetInfoBack`  
> **Тип результата:** `void` (данные в выходных переменных)

## Назначение

Получает информацию об элементе: свойства, вычисленные CSS стили или размеры и позицию.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Режим** | `ElementInfoMode` | Да | Property, ComputedStyle или Rectangle |
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска |
| **Значение локатора** | `string` | Если нет ID | Значение для поиска |
| **Имя свойства** | `string` | Для Property/ComputedStyle | Имя свойства для получения |

### Режимы

| Режим | Описание |
|---|---|
| `Property` | Получить свойство (text, attribute:name, css:property) |
| `ComputedStyle` | Получить вычисленный CSS стиль |
| `Rectangle` | Получить размеры и позицию |

### Выходные

| Параметр | Тип | Описание |
|---|---|---|
| **Значение** | `string` | Для Property и ComputedStyle |
| **X, Y, Ширина, Высота** | `int` | Для Rectangle |

---

## Примеры использования

**Получение текста элемента:**
```
Режим: Property
Имя свойства: "text"
Значение: elementText
```

**Получение атрибута:**
```
Режим: Property
Имя свойства: "attribute:href"
Значение: linkUrl
```

**Получение CSS свойства:**
```
Режим: ComputedStyle
Имя свойства: "color"
Значение: textColor
```

**Получение размеров:**
```
Режим: Rectangle
X: posX
Y: posY
Ширина: width
Высота: height
```
