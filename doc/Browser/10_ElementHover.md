# Элемент: Навести курсор

> **Группа:** MIA → Браузер  
> **Класс:** `ElementHoverBack`  
> **Тип результата:** `void`

## Назначение

Наводит курсор мыши на элемент. Поддерживает наведение на центр элемента или с указанием смещения от центра.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **Режим наведения** | `HoverMode` | Да | Center или WithOffset |
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента (если уже найден) |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска элемента |
| **Значение локатора** | `string` | Если нет ID | Конкретное значение для поиска |
| **Смещение X** | `int` | Для WithOffset | Смещение по горизонтали (пиксели) |
| **Смещение Y** | `int` | Для WithOffset | Смещение по вертикали (пиксели) |
| **Таймаут ожидания** | `int` | Нет | Время ожидания элемента (сек), по умолчанию 10 |

### Режимы наведения

| Режим | Описание |
|---|---|
| `Center` | Навести на центр элемента |
| `WithOffset` | Навести с указанием смещения от центра |

## Примеры использования

**Наведение на меню для отображения подменю:**
```
Режим наведения: Center
ID сессии: browserSession
Тип локатора: Id
Значение локатора: "mainMenu"
```

**Наведение с смещением для точного позиционирования:**
```
Режим наведения: WithOffset
Тип локатора: ClassName
Значение локатора: "dropdown-trigger"
Смещение X: 10
Смещение Y: 5
```

**Активация tooltip:**
```
ElementHover (
  Режим: Center,
  Тип локатора: CssSelector,
  Значение: ".info-icon"
)
Delay (500мс)  // Ожидание появления tooltip
ElementGetInfo (...)  // Чтение tooltip
```

**Наведение на элемент перед кликом:**
```
ElementHover (Режим: Center, Локатор: "button")
Delay (200мс)
ElementClick (Локатор: "button")
```

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `NoSuchElementException` | Элемент не найден | Проверить локатор и таймаут |
| `ElementNotInteractableException` | Элемент недоступен | Проверить видимость элемента |
| `MoveTargetOutOfBoundsException` | Элемент за пределами viewport | Прокрутить к элементу перед наведением |
| `StaleElementReferenceException` | Элемент устарел | Найти элемент заново |

---

## Использование смещения

**Положительные значения:**
- X > 0: смещение вправо от центра
- Y > 0: смещение вниз от центра

**Отрицательные значения:**
- X < 0: смещение влево от центра
- Y < 0: смещение вверх от центра

**Примеры:**
```
Смещение (10, 0)   — 10px вправо от центра
Смещение (0, -5)   — 5px вверх от центра
Смещение (-10, 10) — 10px влево и 10px вниз
```

## Лучшие практики

✅ **Рекомендуется:**
- Добавлять задержку после наведения (200-500мс)
- Прокручивать к элементу перед наведением
- Использовать для активации выпадающих меню
- Проверять видимость элемента перед наведением
- Использовать Center для большинства случаев

❌ **Не рекомендуется:**
- Наводить на невидимые элементы
- Использовать большие смещения (>100px)
- Наводить без проверки результата
- Игнорировать ошибки наведения
- Использовать для элементов с display:none

## Troubleshooting

**Подменю не появляется:**
- Увеличить задержку после наведения
- Проверить CSS :hover правила
- Убедиться, что JavaScript обработчик работает
- Попробовать навести дважды

**Элемент не реагирует на наведение:**
- Проверить, что элемент видим
- Убедиться, что нет перекрывающих элементов
- Проверить z-index элемента
- Попробовать прокрутить к элементу

**Курсор наводится не туда:**
- Проверить смещение (должно быть в пределах элемента)
- Убедиться, что элемент не изменил размер
- Попробовать использовать Center вместо WithOffset
- Проверить координаты элемента

**Ошибка "Out of bounds":**
- Прокрутить к элементу перед наведением
- Проверить, что элемент в viewport
- Увеличить размер окна браузера
- Проверить позицию элемента на странице
