# Элемент: Загрузить файл

> **Группа:** MIA → Браузер  
> **Класс:** `ElementUploadFileBack`  
> **Тип результата:** `void`

## Назначение

Загружает файл через input[type=file] элемент. Автоматически проверяет существование файла перед загрузкой.

---

## Параметры

### Входные

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| **ID сессии** | `string` | Да | Идентификатор сессии браузера |
| **ID элемента** | `string` | Если нет локатора | ID элемента input[type=file] |
| **Тип локатора** | `ElementLocatorType` | Если нет ID | Способ поиска |
| **Значение локатора** | `string` | Если нет ID | Значение для поиска |
| **Путь к файлу** | `string` | Да | Полный путь к загружаемому файлу |
| **Проверить существование** | `bool` | Нет | Проверка файла (по умолчанию true) |
| **Таймаут ожидания** | `int` | Нет | Время ожидания (сек), по умолчанию 10 |

---

## Примеры использования

**Загрузка документа:**
```
Тип локатора: Id
Значение: "fileInput"
Путь к файлу: "C:\Documents\report.pdf"
```

**Загрузка изображения:**
```
Тип локатора: Name
Значение: "avatar"
Путь к файлу: "C:\Images\photo.jpg"
Проверить существование: true
```

**Загрузка с проверкой:**
```
filePath = "C:\Data\file.xlsx"
If (File.Exists(filePath)):
  - ElementUploadFile (
      Локатор: "#upload",
      Путь: filePath
    )
```

---

## Примечания

- Элемент должен быть input[type=file]
- Путь должен быть абсолютным
- Автоматическая проверка существования файла
- Поддержка всех типов файлов
