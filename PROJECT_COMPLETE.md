### Запуск всех тестов

```powershell
# 1. Соберите основной проект в Visual Studio
# (Primo.MIA.slnx → Build → Rebuild Solution)

# 2. Запустите тесты
cd Primo.MIA.Tests
dotnet test

# Ожидаемый результат:
# Пройдено: 198, не пройдено: 0, пропущено: 0
# Время: < 2 секунды
```

### Добавление новых тестов

```csharp
// 1. Создайте класс логики в Logic/
public class MyLogic
{
    public string DoSomething(string input) { ... }
}

// 2. Создайте тестовый класс
public class MyLogicTests
{
    [Fact]
    public void DoSomething_ValidInput_ReturnsExpected()
    {
        // Arrange
        var logic = new MyLogic();
        
        // Act
        var result = logic.DoSomething("test");
        
        // Assert
        result.Should().Be("expected");
    }
}
```
